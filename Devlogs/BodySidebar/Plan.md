# 51-B 우측 몸통·포탑 패널 계획

---

## 목표

게임 카메라와 기존 전투 HUD를 화면 왼쪽 76%에 맞추고 오른쪽 24%에 속성과 몸통별 포탑을 표시한다. 각 몸통은 머리에 가까운 순서대로 번호·포탑 이미지·한국어 속성·이름·등급을 표시하고 빈 슬롯은 `-`로 표시한다. 기본 공격력과 공격 간격 행은 표시하지 않는다.

---

## 검증

- [x] 카메라와 패널이 없던 기존 상태의 시험 실패를 확인한다.
- [x] 기존 전투 화면의 설정 버튼과 중복 속성 목록을 제거하고 메뉴 설정 기능을 유지한다.
- [x] 몸통 성장·손실·복구와 포탑 장착·합성·시너지 갱신을 검증한다.
- [x] 20번 몸통과 카메라·패널의 실제 픽셀 경계를 검증한다.
- [x] 보상 카드가 전체 화면의 약 70%를 유지하면서 패널과 겹치지 않게 한다.
- [x] 자연 전투와 씬·보상·합성·보스 회귀 결과를 기록한다.
- [ ] 51-B 변경을 커밋·푸시한다.
