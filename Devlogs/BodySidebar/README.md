# 51-B 우측 몸통·포탑 패널

---

## 변경 내용

전투 카메라와 기존 HUD를 화면 왼쪽 76%에 배치하고 오른쪽 24%에 속성별 보유 수·시너지 단계와 머리 뒤부터의 몸통 순서, 기존 포탑 이미지, 한국어 속성·이름·등급을 표시한다. 빈 몸통은 `-`로 표시한다. 포탑 이름은 가운데 정렬했으며 기존 기본 공격력·공격 간격 줄은 제거했다.

장착·교체·합성, 몸통 성장·손실·복구와 속성 집계 이벤트에 연결해 최대 20칸까지 즉시 갱신한다. 기존 전투 화면의 독립 `Settings` 버튼과 중복 영문 속성 목록은 실행 시 제거한다. 설정 화면 자체는 메인 메뉴와 일시정지 메뉴를 통해 계속 사용할 수 있다.

카메라·HUD·패널의 실제 픽셀 경계를 맞추고 보스 체력 바도 전투 영역 중앙으로 이동했다. 기존 보상 카드 묶음은 우측 패널을 침범하지 않으면서 전체 화면 너비의 약 70%를 유지하도록 조정했다. 포탑 데이터의 기존 이미지와 속성 색상을 사용하며 임의의 새 에셋은 추가하지 않았다.

---

## 검증과 한계

Unity 6000.3.21f1의 격리 사본에서 실제 화면 경계, 20번 몸통까지 이미지와 순서, 빈 슬롯, 중앙 정렬, 포탑 교체·합성·단계, 성장·손실·복구 및 중복 요소 제거와 설정 열기를 확인했다. 실제 보스 체력 바의 계산 영역과 보상 카드의 전체 화면 대비 너비도 검사했다. 씬 전환, 기존 메뉴, 보상, 합성, 보스 돌진과 몸통 성장 회귀 로그는 모두 자체 통과를 기록했다. 일부 실행에서는 Unity Editor Search 초기화 예외가 별도로 발생했다.

패널 기본 배치와 카메라 분리 상태의 자동 조종 자연 전투는 시드 5101로 게임 시간 300초까지 진행해 레벨 13, 누적 획득 XP 265, 처치 191, 현재 몸통 15, HP 100, 엘리트 보상 1회를 기록했고 Unity 종료 코드는 0이었다. 이후 중복 HUD 제거·빈 슬롯·글자 정렬은 별도 통제 배치로 확인했다. 이 결과는 사람의 수동 플레이나 실제 화면의 가독성을 증명하지 않는다.

원본 `Game.unity`는 외부 변경을 보존하고 이 커밋에 포함하지 않았다. 실제 게임에서 해상도별 글자 크기, 20칸의 가독성, 이미지와 보상 카드 배치를 직접 확인해야 한다.
