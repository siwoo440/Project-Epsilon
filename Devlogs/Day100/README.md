# 100일차: 적 투사체의 고속 충돌 보완

- 적 탄의 실제 물리 이동 구간을 충돌 거리순으로 검사한다. 기존 공용 체력 피해 예약, 몸통 판정, 엄폐, 무적과 물리 충돌 우선순위를 재사용한다.
- 검사 거리는 실제 물리 단계 최대 이동 거리로 제한한다. 극단적인 시험 속도에서의 누락을 재현했으며 평상시 발생 빈도는 확인되지 않았다.
- 현재 즉시 합성 규칙과 맞지 않던 보스 전환 배치 시험을 갱신했다. 수정 전 코드에서도 이전 시험의 합성 화면 조건이 실패했음을 별도로 확인했다.

## Unity 비대화형 배치

- `AutomatedDay100EnemyProjectileSweepVerification`: 수정 전 고속 탄의 머리 통과 피해 누락을 재현했다. 수정 후 머리·몸통, 단일 피해, 엄폐, 무적, 일시정지와 물리 이동 상한 밖의 조기 피해 방지를 통과했다.
- `AutomatedCollisionPriorityVerification`, `AutomatedMapCoverVerification`, `AutomatedBossFanVerification`: 기존 충돌 우선순위·실제 엄폐·보스 부채꼴 사격 회귀를 통과했다.
- `AutomatedBossTransitionVerification`: 즉시 합성 결과 보존, 가속된 20분 전환, 투사체 정리와 강제 보스 처치 승리를 통과했다. 실제 자연 20분 플레이는 아니다. 시험이 충돌 처리기를 끈 상태에서 기존 피해 대체 처리 오류 로그가 발생했다.
- Unity 시작 시 기존 검색 데이터베이스 `ArgumentOutOfRangeException`이 기록됐다. 원인은 별도 확인이 필요하다.

## 남은 사항

- 실제 화면에서 낮은 프레임의 적 탄, 빠르게 움직이는 뱀과 다수 탄의 시각적 충돌 및 성능은 확인하지 못했다.
