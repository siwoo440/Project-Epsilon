# 112일차: 적 직접 충돌 보호 표시

- 적 직접 충돌 후 약 1초의 제한적 보호를 기존 몸통 손실 이미지와 주황색 표시로 나타낸다. 완전 무적의 원형 표시와 독립적으로 시작하고 종료한다.
- 표시 위치는 머리 위에 고정하고 회전에 따라 돌아가지 않게 했다. 기존 피해·충돌·무적 규칙은 변경하지 않았다.

## Unity 비대화형 배치

- `AutomatedDay112ContactProtectionVisualVerification`: 수정 전 표시 누락이 재현됐고, 수정 후 실제 적 직접 충돌과 두 보호 표시의 시작·중첩·개별 종료가 통과했다.
- `AutomatedDay83VfxVerification`, `AutomatedDay94BurnFlashVerification`, `AutomatedBossOutcomeRaceVerification.RunVictory`: 기존 속성·피격·무적 표현과 보스 승리 경계가 통과했다.
- 자연 전투 시험 3회 중 한 회는 고정 시드 112에서 능력치·속도 변경 없이 30.7초에 11킬과 레벨 2, 포탑 선택을 확인했다. 시험은 첫 성장 확인 시 종료하므로 5분 시험은 아니다. 나머지 두 회는 각각 약 28.9초와 34.7초에 패배했다.
- 고정 시드 999의 실제 피해 기록은 적 직접 충돌에 따른 몸통 손실과 별도 근접 피해를 보여줬다. 이는 현재 기획서의 분리된 판정과 일치하며 자동 입력 패배만으로 밸런스나 버그 여부를 확정할 수 없다.
- Unity 시작 시 기존 검색 데이터베이스 `ArgumentOutOfRangeException`이 기록됐다. 원인은 별도 확인이 필요하다.

## 남은 사항

- 실제 게임 화면에서 제한 보호 표시의 가독성·크기와 경고 표시의 겹침을 확인하지 못했다. 현재 구성의 직접 조작 5분 전투도 미확인이다.
