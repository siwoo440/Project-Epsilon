# 114일차: 장면별 배경음 교체

- 메뉴, 평원, 폐허, 습지, 보스의 임시 합성음 참조를 공개 CC0 반복 음원 다섯 곡으로 교체했다. 기존 음원 파일은 보존하고 기존 장면별 선택·반복·전체 음량 설정을 유지한다.
- 제작자, 원본 제목, 출처와 라이선스는 `Assets/Audio/BGM/CREDITS.md`에 기록했다. 게임 분위기와 음량의 실제 청취 및 최종 곡 선정은 미완료다.
- 별도 음악 생성 도구는 활성 구독이 없어 실행되지 않았다. 따라서 생성 음원이 아니라 공개 음원을 사용했다.

## Unity 비대화형 배치

- `AutomatedDay114LicensedMusicVerification`: 교체 전의 기존 음원 경로가 실패했고, 교체 후 서로 다른 다섯 OGG의 실제 가져오기·길이·참조가 통과했다.
- `AutomatedDay77MusicVerification`: 맵·보스·메뉴·준비 씬 전환, 반복과 전체 음량 연결이 통과했다.
- `AutomatedDay76GameplaySoundVerification`: 기존 공격·피격·몸통·합성·레벨업·엘리트·보스 효과음 연결이 통과했다. 처음 지정한 `AutomatedDay76SoundVerification`은 존재하지 않는 진입점이어서 실패한 뒤 실제 진입점으로 재실행했다.
- Unity 시작 시 기존 검색 데이터베이스 `ArgumentOutOfRangeException`이 기록됐다. 원인은 별도 확인이 필요하다.

## 남은 사항

- 음원의 실제 청취, 전환 순간·반복 경계·전투 효과음과의 음량 균형은 확인하지 못했다. 효과음은 기존 임시 합성음이다.
