# 118일차: 물리 포탑 등급 효과와 머리 위치

- 물리 포탑 6종 중 기존 강철 근접의 ★3 두 대상·★5 주기 강타는 유지했다. 나머지 다섯 포탑에는 역할별 시험 효과를 추가했으며 기존 공통 등급 효과도 유지한다.
- 강철 관통: ★3 관통 +1, ★5 +2. 물리 속사 근접: ★3 공격속도 1.15배, ★5 1.25배. 물리 속사 직사: ★3 네 번째 공격 1.2배, ★5 세 번째 공격 1.35배.
- 강철 충격파: ★5 생존 대상 넉백 0.4. 물리 중파동: ★3 세 번째 공격 1.2배, ★5 두 번째 공격 1.35배. 넉백 시간은 0.2초이며 기존 보스 면역·일반 적 저항을 따른다.
- 모든 새 수치는 데이터 시험값이며 최종 밸런스가 아니다. 주기 횟수는 장착 슬롯별로 관리하고 재장착 시 초기화한다. 상위 등급은 하위 등급의 관통·속도를 잃지 않는다.
- 사용자 요청에 따라 캐릭터 선택 초상화의 Y 좌표를 -210에서 -165로 올렸다. 기존 여섯 캐릭터의 이미지와 게임 중 머리 위치는 유지했다.

## Unity 비대화형 배치

- `AutomatedDay118PhysicalTurretVerification`: 수정 전 강철 관통 ★3 명중 수가 실패했고, 수정 후 실제 접촉 피해·속사·주기 피해·넉백과 면역이 통과했다. 최초 중파동 수치 비교는 부동소수점 오차로 실패해 0.001 이내 오차 기준으로 다시 확인했다.
- `AutomatedGradeFiveVerification`, `AutomatedEarlyWeaponVerification`, `AutomatedDay47UniqueEffectsVerification`, `AutomatedDay92ProjectileSweepVerification`, `AutomatedInstantMergeVerification`: 48종 기존 공격과 등급, 기존 고유 효과, 투사체 경로와 즉시 합성·시너지가 통과했다.
- `AutomatedDay85CharacterPortraitVerification`: 여섯 캐릭터의 기존 초상화와 바뀐 Y 좌표가 통과했다. `AutomatedDay90MapStartingSelectionVerification`은 직접 게임 씬 시작 옵션을 잘못 지정한 실행에서 실패했고, 옵션 제거 후 메뉴·맵 진입과 시작 선택이 통과했다.
- 포탑 변경 전 현재 시작 흐름에 맞춘 독립 자동 입력 시험에서 시드 4501로 게임 시간 300초까지 생존했다. 적 201마리, 레벨 12, 몸통 14, HP 100, 엘리트 보상 선택 1회를 기록했다. 능력치·시간 배율을 바꾸지 않은 가상 입력 한 회이며, 새 포탑 효과 적용 후의 결과나 사람의 직접 조작 결과는 아니다.
- 5분 시험의 시작 선택 지원을 현재 맵 진입 후 후보 선택 방식으로 갱신했다. Unity 시작 시 기존 검색 데이터베이스 `ArgumentOutOfRangeException`이 기록됐으며 원인은 별도 확인이 필요하다.

## 남은 사항

- 물리 이외 42종은 기존 공통 효과 또는 기존 화염탄 예시를 유지하며 순차적으로 시험안을 적용해야 한다. 모든 포탑의 최종 밸런스와 실제 화면은 미확인이다.
- 5분 시험의 레벨 12는 기획서의 시험 목표 Lv.5~7을 넘는다. 한 시드의 자동 입력 결과만으로 수치를 확정하지 않는다.
