# 120일차: 냉기 포탑 등급 효과 시험안

- 냉기 근접은 냉기 대상 직접 피해 ★3 1.2배·★5 1.35배, 냉기 범위는 냉기 지속시간 ★3 1.2배·★5 1.4배를 시험한다.
- 냉기 속사 근접은 공격속도 ★3 1.12배·★5 1.2배, 냉기 직사는 ★3 네 번째 공격 1.2배·★5 세 번째 공격 1.35배를 시험한다.
- 냉기 관통은 ★3 관통 +1·★5 +2와 냉기 대상 피해 1.1배를 시험한다. 냉기 파동은 냉기 지속시간 ★3 1.1배·★5 1.2배와 ★3 세 번째 공격 1.2배·★5 두 번째 공격 1.35배를 시험한다.
- 기존 공통 등급 효과와 냉기 시너지·빙결 조건·보스 저항을 유지한다. 냉기 대상 추가 피해는 명중 전 실제 냉기 상태에만 적용하며 수치는 포탑 데이터에서 조정한다.

## Unity 비대화형 배치

- `AutomatedDay120ColdTurretVerification`: 수정 전 냉기 대상 등급 피해가 없어 실패했다. 수정 후 첫 명중, 상태 대상 피해·지속시간, 시너지 결합, 관통과 속사·주기 공격이 통과했다.
- `AutomatedColdFreezeVerification`, `AutomatedColdElectricReactionVerification`: 기존 빙결·보스 저항·정지와 냉기·전기 반응이 통과했다.
- `AutomatedDay119FireTurretVerification`, `AutomatedDay118PhysicalTurretVerification`: 기존 화염·물리 포탑 시험 효과가 통과했다.
- Unity 시작 시 기존 검색 데이터베이스 `ArgumentOutOfRangeException`이 기록됐다. 원인은 별도 확인이 필요하다.

## 남은 사항

- 전기·독·폭발·신성·암흑 30종의 개별 시험 효과와 전체 빌드 밸런스, 실제 화면·자연 전투 확인이 남았다.
