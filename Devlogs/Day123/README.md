# 123일차: 폭발 포탑 등급 효과 시험안

- 폭발 근접은 중심 절반 범위의 피해를 ★3 1.2배·★5 1.35배로 시험한다.
- 폭발 범위는 폭발 범위를 ★3 1.1배·★5 1.2배로 시험한다.
- 폭발 속사는 공격속도 ★3 1.1배·★5 1.2배, 폭발 직사는 ★3 네 번째 1.2배·★5 세 번째 1.35배 및 폭발 범위 1.1배를 시험한다.
- 폭발 관통은 ★3 관통 +1·★5 +2와 중심 피해 1.1배, 폭발 파동은 범위 ★3 1.1배·★5 1.2배와 ★3 세 번째 1.2배·★5 두 번째 1.35배를 시험한다.
- 기존 폭발 거리별 피해, 시너지 범위, 중복 방지, 넉백과 보스 면역을 유지한다. 수치는 데이터에서 조정할 수 있는 시험안이다.

- `AutomatedDay123ExplosionTurretVerification`: 실제 중심 피해, 범위 경계, 중복 피해 방지, 속사·주기 공격과 관통 시험 통과.
- `AutomatedDay40StatusVerification`: 폭발 넉백과 보스 면역 회귀 시험 통과.
