# 126일차: 공통 UI 프레임과 속성 아이콘

- 기존 씬과 UI 제어기의 화면을 확인해 메인 메뉴·영구 성장·캐릭터·맵·시작 포탑·전투 HUD·레벨업·정예 보상·보상 처리·슬롯 교체·일시정지·설정·키 설정·조작 안내·승패 결과의 개별 시안을 만들었다.
- 시안은 디자인 참고이며 일부 예시 이미지와 데이터가 실제 에셋과 다르다. 맵 잠금 조건은 평원·폐허 보스 처치다.
- 생성한 `ButtonFrame.png`, `RewardCardFrame.png`, `BarFrame.png`를 기존 버튼·보상 카드·맵 카드·정보 패널·HUD 막대와 우측 몸통 행에 재사용한다. 기존 화면 구조와 입력을 유지한다.
- `AttributeIcons.png`는 물리·화염·냉기·전기·독·폭발·신성·암흑 순서로 우측 패널에 연결한다. 원본 픽셀 크기가 격자 크기로 나누어떨어지지 않아 정수 경계로 분할한다.
- 에셋이 없을 때 기존 화면을 유지한다. 영구 성장의 IMGUI 화면은 색상을 공통 계열로 조정한다.
- 개별 시안 전체의 일러스트, 카드 배치와 애니메이션을 그대로 구현한 것은 아니다. Unity 실제 화면에서 크기·대비·테두리·아이콘 가독성 확인이 필요하다.

## Unity 비대화형 배치

- `AutomatedDay126UiSkinVerification`: 변경 전 보상 프레임 누락으로 실패했다. 속성 아틀라스 검증에서는 격자 경계와 Unity 표시 영역 검사에서 실패해 정수 경계·전체 사각형과 원본 영역 기준으로 수정한 뒤 통과했다. 카드, 일시정지, 몸통 행, 게이지, 8속성 순서와 입력 차단 여부를 확인했다.
- `AutomatedDay90MapStartingSelectionVerification`: 실제 메인 버튼·맵 카드 프레임, 캐릭터·맵 이동, 시작 포탑, 재시도 및 선택 잠금이 통과했다.
- `AutomatedBodySidebarVerification`: 화면 분리, 몸통 순서와 포탑 이미지, 교체·합성·시너지·성장·손실·복구가 통과했다.
- `AutomatedEliteRewardVerification`: 정예 보상 세 후보, 일시정지, 실제 보상 선택과 전투 재개가 통과했다.
- Unity 초기화가 멈춘 격리 배치 한 건을 종료하고 재실행해 통과했다. 기존 Unity 검색 데이터베이스 예외 원인은 추가 확인이 필요하다.
