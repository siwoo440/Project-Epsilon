# 128일차: 세 맵 선택 미리보기

- 개방 평원·폐허 회랑·변이 습지의 선택 카드용 풍경 이미지 세 장을 생성했다. 이미지는 맵 분위기를 나타내는 시안이며 실제 무작위 배치와 동일한 지형도가 아니다.
- 맵 프로필에 선택 미리보기 항목을 추가하고 선택 카드의 이미지 영역을 넓혔다. 별도 미리보기가 없는 기존 데이터는 바닥 이미지를 사용한다.
- 실제 맵 바닥, 장애물 배치, 해금과 게임 시작 규칙은 유지한다.

## Unity 비대화형 배치

- `AutomatedDay90MapStartingSelectionVerification`: 변경 전 기존 바닥 이미지를 보여 미리보기 시험이 실패했고, 변경 후 세 이미지·화면 비율·입력, 기존 바닥 대체, 실제 맵 진입·시작 선택·재시도가 통과했다.
- `AutomatedRandomMapLayoutVerification`: 세 맵에서 각각 32개 시드의 랜덤 장애물 수·연결 통로·맵 이미지·플레이어 보호가 통과했다.
- `AutomatedBodySidebarVerification`: 기존 카메라 분리·몸통 패널과 성장·합성 흐름이 통과했다.
- 실제 화면에서 미리보기 크기와 이미지 잘림은 확인하지 못했다.
