# 129일차: 결과 화면 캐릭터 표시

- 승리·패배 결과 화면에 실제 전투 캐릭터의 기존 초상화를 표시하고 성과 기록을 옆에 배치한다.
- 분리된 결과 씬에서 전투 캐릭터 참조가 정리된 경우 보존된 선택 캐릭터를 사용한다. 초상화가 없으면 기존 중앙 기록 배치를 유지한다.
- 초상화에는 클릭 판정을 넣지 않으며 기록·저장·재도전 동작은 그대로 유지한다.

## Unity 비대화형 배치

- `AutomatedDay90MapStartingSelectionVerification`: 변경 전 결과 초상화 누락을 확인했고, 변경 후 선택한 중장형의 실제 초상화와 입력 차단 여부, 분리 씬 결과·재도전·캐릭터와 맵 유지가 통과했다.
- `AutomatedDay85CharacterPortraitVerification`: 여섯 캐릭터 선택 초상화와 해금 규칙이 통과했다.
- `AutomatedDay126UiSkinVerification`: 기존 공통 UI 프레임과 속성 아이콘이 통과했다.
- 실제 결과 화면에서 이미지와 글자의 크기·겹침은 확인하지 못했다.
