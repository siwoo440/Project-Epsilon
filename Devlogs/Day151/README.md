# 151일차 자연 전투 검증 복구

캐릭터 전투 외형과 적 성장 상한 브랜치의 커밋 `ba60933` 위에서 작업했다. 자연 전투 배치는 메인 메뉴에서 캐릭터와 맵을 선택하고, 출격 후 시작 포탑과 첫 안내를 실제 버튼으로 처리한다. 게임 속도와 플레이어 능력치, 적 출현, 경험치는 게임 코드가 처리한다.

기존 검증기에 고정되어 있던 시작 몸통과 포탑 ID 비교를 선택 데이터 기준으로 바꿨다. 보스의 안전한 출현 시점까지 기다리고, 20분 경계와 보스 대기에 실제 시간 제한을 적용한다. 즉시 합성은 완료 이벤트가 동기적으로 발생하므로 이벤트 전에 시도를 등록한다.

- `-epsilonFightBoss -epsilonRecord`로 20분 경계와 보스 승리 기록을 수집한다.
- `-epsilonSeed 15101 -epsilonMap 0 -epsilonCharacter 0 -epsilonStartOption 2`로 평원과 균형형, 두 번째 포탑을 선택한다. 맵과 캐릭터 번호는 0부터, 포탑 번호는 1부터 시작한다.
- `-epsilonAutoMerge`는 실제 합성 기능을 사용한다. `-epsilonAttribute Fire`를 지정하면 레벨업에서 해당 속성의 제안 후보를 우선한다.
- `-epsilonRecord`에서 5분 표본을 실행 중 로그의 `MILESTONE`에 출력한다. 전체 승리 판별은 기존 `Tools/check_full_run.py`로 확인한다.
- 원본 저장과 분리하기 위해 Unity 사본의 제품 이름은 `-Isolated`로 끝나야 한다.
