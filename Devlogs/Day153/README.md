## 153일차 경험치 성장 곡선

평원 기준 기록은 5분에 레벨 13, 20분에 레벨 30이었다. 초반에는 시작 포탑 이후 선택을 빠르게 경험하고 중반부터는 장착과 합성 사이에 플레이 시간이 늘어나도록 상승 곡선을 조정했다.

| 구간 | 레벨업 요구 경험치 |
| --- | --- |
| 현재 레벨 1~3 | 10, 14, 24 |
| 현재 레벨 4 이상 | 기본 52, 레벨당 배율 1.062 |

5분 레벨 5~7, 20분 레벨 20~24를 출시 시험 목표로 사용한다. 기존 평원에서 얻은 경험치 275와 2,213을 그대로 대입하면 레벨 7과 25다. 전투에서 실제 획득량과 목표 도달 여부는 포탑 성장에 따라 달라진다.
