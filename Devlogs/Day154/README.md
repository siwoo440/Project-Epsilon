## 154일차 등급·합성 비교

평원 기준 전투에서 자동 합성이 11회 완료됐다. 장착 포탑의 최고 관찰 등급은 5분 ★3, 10·15분 ★4, 20분 ★2였다. 어느 표본에도 ★5 장착은 없었다. 합성 도달률은 여러 전투의 표본이 필요하다.

`Tools/summarize_early_run.py`가 각 주요 시점의 장착 등급·속성 분포, 합성 완료 횟수와 첫 ★5 관찰 시각을 출력한다. 별도의 통제 시험은 동일 포탑 두 개가 같은 대상에 가하는 피해와 합성 후 한 포탑의 피해를 비교하며, 빈 슬롯과 속성 단계 감소를 확인한다.

Unity 통제 시험에서 강철 근접 포탑 두 개는 0.8초 주기에 합계 22 피해를 줬다. 공격력 강화로 합친 ★2 한 개는 같은 주기에 13.125 피해를 줬다. 물리 단계는 2에서 미활성으로 내려갔다. 빈 슬롯을 다시 채운 이후의 피해량은 별도 비교 대상이다.
