## 155일차 여덟 속성 효과 비교

Unity에서 기본 피해 10, ★1, 속성 6단계, 6번 명중 및 같은 관찰 시간으로 속성 효과를 비교했다. 각 속성에는 보상 목록의 근접 포탑과 체력 1,000의 인접 표적 두 개를 사용했다.

| 속성 | 주 대상 피해 | 보조 대상 피해 | 관찰한 생존 효과 |
| --- | ---: | ---: | --- |
| 물리 | 66.00 | 0 | 해당 없음 |
| 화염 | 63.05 | 0 | 해당 없음 |
| 냉기 | 60.00 | 0 | 적 이동 ×0.66 |
| 전기 | 60.00 | 60.00 | 해당 없음 |
| 독 | 62.50 | 0 | 적 공격 ×0.95 |
| 폭발 | 75.00 | 71.46 | 해당 없음 |
| 신성 | 64.80 | 0 | 보호막 15 |
| 암흑 | 69.00 | 0 | 체력 3 회복 |

화염·독, 냉기·전기, 물리·폭발, 신성·화염, 암흑·독, 신성·암흑 반응의 양쪽 공격 순서도 배치에서 통과했다. 단일 대상과 두 대상에서 속성의 이점이 다르므로, 자연 전투 빌드별 생존율과 수치 조정은 별도 표본이 필요하다.

재실행에는 `ProjectEpsilon.Editor.AutomatedDay41AttributeVerification.Run -epsilonCompareAttributes`를 사용한다.
