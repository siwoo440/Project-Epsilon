## 156일차 시간대별 적 피해 분석

| 평원 기준 구간 | 적 투사체 체력 피해 | 적 근접 체력 피해 | 적 직접 충돌로 잃은 몸통 |
| --- | ---: | ---: | ---: |
| 0~5분 | 9 | 0 | 0 |
| 5~10분 | 0 | 0 | 0 |
| 10~15분 | 180 | 0 | 0 |
| 15~20분 | 3,128 | 302 | 13 |

기준 시드의 주기 표본에서 10~15분 동시 적 수는 최대 9마리, 15~20분에는 최대 51마리였다. 이 전투의 후반 압박은 500마리 상한에 도달하기 전에 나타났다. 현재 확인된 수치로는 후반 투사체의 밀도와 회피 경로가 우선 비교 대상이다. 일반 적·엘리트의 확정된 분당 성장 기준은 유지했다.

배치 기록 요약은 5분 구간별로 원인별 실제 공용 체력 피해와 직접 몸통 손실을 출력한다. 로그 전체를 메모리에 올리지 않고 기록과 주기 표본만 읽는다.
