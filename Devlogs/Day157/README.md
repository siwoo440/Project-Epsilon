## 157일차 세 맵의 보스 전환

맵 선택 배치가 청크 생성 전에 일반 출격 흐름으로 맵을 지정하도록 고쳤다. 평원·폐허·습지에서 진행 시간을 1,190초로 옮긴 통제 시험을 실행했다.

세 맵 모두 1,200초 전환 한 번, 일반 적과 투사체 정리, 경험치 보석과 회복 아이템 보존, 보스별 최대 체력, 소환수 포함 500마리 상한, 절반 체력의 2단계 전환과 처치 시 승리를 통과했다. 보스 기본 체력은 평원 600, 폐허 700, 습지 650이다.

평원 기준 자연 전투에서는 보스 등장부터 승리까지 게임 시간 약 12.8초가 걸렸다. 폐허와 습지의 처치 시간 비교는 강제 피해를 쓰지 않는 자연 전투 기록이 필요하다.
