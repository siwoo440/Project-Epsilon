## 158일차 맵 환경과 긴 몸통

Unity 배치에서 평원·폐허·습지의 실제 맵 데이터를 사용했다. 청크당 장애물을 세 개 고정한 통제 조건에서 20칸 몸통이 지정 통로에 진입하고, 회전하고, 마지막 칸까지 빠져나왔다. 각 맵에 활성 청크 9개가 생성됐고 전후 몸통 수와 공용 체력이 같았다.

기존 환경 시험은 방전 바닥, 회로 스위치, 독성 포자, 개미굴 소환과 붕괴 잔해가 머리 및 몸통을 즉시 가두지 않는 동작을 확인했다. 별도 황충 시험에서는 경고 범위 안의 빈 곳은 피해가 없고 벌레에 닿을 때만 피해를 받으며, 대열이 나뉘어 통과하는 동작을 확인했다. 무작위 시드 전수와 보스전 중 수동 조작은 별도 확인 대상이다.
