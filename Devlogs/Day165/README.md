## 165일차 적 밀집 충돌 최적화

일반 적, 정예, 소환수, 보스가 `EnemyContact` 레이어를 사용한다. 이 레이어끼리의 충돌만 제거하고 기존 플레이어 및 다른 레이어의 충돌표 연결을 유지한다.

Unity 비대화형 배치에서 실제 적 500마리를 같은 밀집 좌표에 놓고, 적 이동을 정지한 뒤 20개 물리 스텝을 측정했다. `ProfilerRecorder` 기록은 적끼리 접촉을 허용했을 때 스텝당 103.772ms, 차단했을 때 0.006ms였다. 이 수치는 통제된 물리 구간이며 렌더링과 실제 전투 입력을 포함하지 않는다.

동일 배치에서 실제 스폰의 500마리 상한, 엘리트 대기 후 출현, 분당 능력치 소급 반영과 체력 비율 보존을 확인했다. Direct3D 12를 활성화한 별도 Unity 배치의 30개 프레임 동안 적 500마리가 유지됐다. 프레임 간격 중앙값은 0.94ms, 95백분위는 1.51ms였다. 플레이어가 정지해 있고 포탑이 꺼진 통제 상태의 수치다.
