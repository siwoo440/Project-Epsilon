# 167일차 정상 전투와 피해 원인 분석

---
## 개발 목표

기존 평원 정상 시간 전투를 재현하고 경험치 요구량과 적끼리의 충돌 설정을 따로 비교한다. 체력이 소진돼 사라진 몸통도 해당 피해 원인과 함께 기록한다.

---
## 확인된 원인과 변경 사항

`SnakeHealth.TakeDamage`는 직접 제거된 몸통과 달리 체력 초과 피해로 제거된 몸통을 0칸으로 기록했다. 예를 들어 공용 체력 100인 6칸 몸통에 피해 223을 주면 몸통은 4칸, 체력은 77이지만 기존 투사체 기록의 손실은 0이다. 제거된 몸통을 합산해 피해 적용 전 체력과 몸통 수와 함께 기록하고, 마지막 몸통이 사라졌을 때는 해당 기록을 남긴 뒤 패배를 알린다.

`RunTelemetry.cs`에 실제 적끼리의 충돌 상태와 고정 프레임 설정, 몸통 집계 형식을 추가했다. `EarlyEnemyWaveSpawner.cs`의 계층 이름을 재사용한다. `Tools/summarize_early_run.py`는 패배로 5분 구간이 끝나지 않아도 관찰된 후반 피해와 원인별 몸통 손실을 표시한다. `Tools/compare_run_records.py`에는 새 실행 설정 비교를 추가했다. 이전 로그의 몸통 손실 집계는 직접 손실로 표시한다.

---
## 기준 기록

167일차의 출발점인 `12adae9`의 기존 정상 시간 평원 기록은 시드 `15101`에서 1,059.2초에 패배했다. 15분 이후 공용 체력 피해는 적 투사체 1,746, 적 근접 공격 167, 특수 지역 40, 장애물 25였다. 적 직접 접촉의 몸통 손실은 6칸이었다. 당시 피해 전 체력과 피해량으로 계산한 참고 추정치는 투사체 17칸, 근접 공격 2칸이다. 당시 기록에는 체력 소진으로 사라진 몸통의 실측값이 없다.

별도 사본에서 시드 `15101`, 평원, 균형형, 시작 포탑 두 번째 후보로 `-epsilonRecord -epsilonFightBoss -epsilonAutoMerge`를 사용한다. 비교 조건은 166일차 기준, 이전 XP 곡선만 복원한 조건(기본 10, 레벨당 1.12), `EnemyContact`의 자기 계층 충돌만 복원한 조건이다. 같은 시드라도 정상 시간 배치는 프레임 시점에 따라 행동이 달라질 수 있으므로 여러 표본으로 비교한다.

---
## 검증

`AutomatedBodyGrowthVerification.cs`의 `-epsilonRecord` 실행에 두 칸을 잃는 투사체 피해와 마지막 몸통을 잃는 초과 피해의 기록 검증을 추가했다. 같은 `SnakeHealth` 코드에 시험용 의존성을 연결한 회귀는 수정 전 몸통 손실 누락으로 실패했고, 수정 후 두 칸 손실과 패배 콜백 전 최종 손실 기록을 통과했다. Unity 6000.3.21f1 참조로 런타임 및 에디터 C#을 컴파일했고 Python 테스트 14개도 통과했다. 기존 166일차 패배 로그의 부분 구간 요약도 확인했다.

Unity 에디터 배치는 실제 씬 실행 전 초기화 단계에서 대기했고, 준비된 패키지 사본에서도 회귀가 제한 시간 안에 시작되지 않았다. 새 정상 시간 재현, 두 변수의 개별 전투 비교, 실제 씬의 회귀 실행은 미검증이다. 초기화가 정상화되면 `Tools/check_full_run.py`와 구간 요약으로 결과를 대조한다.
