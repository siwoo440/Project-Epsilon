# 168일차 후반 원거리 사격 간격 시험안

---
## 개발 목표와 변경 사항

정상 시간 평원 기준 기록에서 가장 큰 후반 공용 체력 피해 원인인 투사체의 연속 사격 압력을 조정한다. `EnemyWaveSettings.asset`의 기존 웨이브 단계에 일반 원거리 사격 간격 배율을 추가했다. `EarlyEnemyWaveSpawner.cs`는 신규 적과 생존 적의 다음 사격 주기에 원본 간격 기준 배율을 적용한다. 이미 시작한 대기 시간은 보존한다.

| 시간 | 배율 | 일반 말벌 발사 간격 | 일반 개미귀신 발사 간격 |
| --- | ---: | ---: | ---: |
| 15분 이전 | 1.00 | 2.00초 | 2.50초 |
| 15~18분 | 1.15 | 2.30초 | 2.875초 |
| 18~20분 | 1.25 | 2.50초 | 3.125초 |

대상은 두 일반 원거리 적이다. 적의 체력·피해·생성 간격과 동시 상한, 기존 원거리 정예와 강화형의 전용 공격 주기는 기존 값을 사용한다. 같은 적이 계속 사격할 수 있다는 조건에서 발사 빈도는 15분에 약 13%, 18분에 20% 감소하는 시험안이다.

---
## 검증과 남은 비교

`AutomatedEnemyWaveStagesVerification.cs`에 기존 15분 전 사격 간격, 후반 경계 배율 및 이미 출현한 말벌에 원본 간격 기준으로 배율이 적용되는 사례를 추가했다. 실제 코드와 에셋 값을 사용하고 Unity 의존성만 대체한 검증에서 발사 간격 경계와 예외 대상을 확인했다. Unity 6000.3.21f1의 참조를 사용한 런타임 및 에디터 C# 컴파일도 통과했다.

에디터 초기화 문제로 실제 씬에서 발사가 시작되는 것과 정상 시간 전투는 미검증이다. 실제 투사체 밀도, 몸통 손실, 20분 생존율, 회복·복구 발생량, 정예 보상과 출현 가중치는 정상 시간 반복 표본을 수집해 판단한다. 이 수치는 출시 밸런스 확정값이 아니다.

다음 일정은 169일차 캐릭터별 시작 능력과 생존율 비교다.
