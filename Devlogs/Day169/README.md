## 검증과 수집할 자료

캐릭터 에셋의 시작 포탑 참조 18개와 실제 표시 이름을 대조했다. 배율 범위를 벗어난 임시 에셋의 회전·이동 값도 검사하도록 기존 Unity 검증을 확장했다. Unity 6000.3.21f1 참조를 사용한 런타임과 에디터 C# 컴파일은 통과했다. 실제 전투 생존율 비교에는 맵·시드·개방된 영구 성장 상태와 시작 선택 인덱스를 고정한 기록이 필요하다. 20분 도달률, 피해 출처별 몸통 손실, 처치와 경험치, 회피 입력 변화량을 비교한다.
