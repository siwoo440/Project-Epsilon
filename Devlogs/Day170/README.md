# 170일차 최종 보스 돌진 예고 범위

평원·폐허·습지 보스의 기본 체력은 각각 600·700·650, 기본 투사체 피해는 15다. 체력 절반에서 2단계로 넘어가고 첫 단계의 돌진 피해가 몸통 절단으로 바뀐다. 습지는 예고 중 머리 방향을 계속 추적한다. 소환 간격은 12초이며 보스당 동시에 4마리까지 유지한다.

기존 돌진 예고는 고정 폭 0.18이어서 보스의 실제 접촉 범위보다 좁았다. 돌진 표시 폭을 실제 월드 충돌체 지름과 맞추고, 방향을 추적하는 습지도 동일한 경로 계산을 사용한다. 상태 이상이 중간에 풀릴 수 있으므로 예고 길이는 감속 전 기준 속도로 계산한다. 붉은 예고와 보라색 절단 예고에 투명도를 적용해 바닥과 포탑을 함께 볼 수 있게 했다.

기존 배치 검증에 충돌체와 예고 폭을 대조하는 검사를 추가했다. Unity 6000.3.21f1 참조를 사용한 런타임과 에디터 C# 컴파일은 통과했다. 세 맵의 실제 보스 처치 시간과 회피율은 정상 속도 전투를 재실행한 뒤 비교한다. 체력과 공격 주기를 조정할 근거로는 기존 1회 기록만으로 부족하다.
