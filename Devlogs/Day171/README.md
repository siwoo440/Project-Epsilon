# 171일차 포탑 합성 후 공격 진행 유지

합성 재료에서 제외된 포탑의 쿨다운과 주기 공격 횟수를 보존한다. 기존에는 합성 후 모든 슬롯을 초기화하고 다시 장착했으므로 합성과 신규 포탑 삽입에 영향받은 다른 포탑도 즉시 발사할 수 있었다. 이제 합성 결과만 새 포탑으로 처리하며 남은 포탑은 기존 공격 진행 상태를 가진 채 순서대로 옮긴다.

상위 등급, 합성 강화 계승, 빈 슬롯, 즉시 시너지 재계산 규칙은 기존 값으로 테스트한다. 기존 즉시 합성 배치에 세 번째 포탑의 재사용 대기 검사를 추가했다.
