# 172일차 속성 시너지와 조합 효과 대조

속성 패널의 2·4·6·8개 경계에서 새 효과가 없는 경우 이전 효과 유지로 표시한다. 신성의 명중 회복 확률, 보호막 주기·양·지속 시간, 보호막 종료 회복·피해·반경을 같은 전투 규칙에서 읽어 표시한다.

| 역할 | 적용 효과 |
| --- | --- |
| 물리·화염 | 직접 피해와 치명타, 화상 초당 피해와 지속 시간 |
| 냉기·전기 | 감속과 빙결, 추가 대상 연쇄 |
| 독·폭발 | 적 공격과 피격 피해 변화, 범위와 밀치기 |
| 신성·암흑 | 명중 회복과 보호막, 저주·흡수·처치 회복 |

화염·독, 냉기·전기, 물리·폭발, 신성·화염, 암흑·독, 신성·암흑의 여섯 반응을 실제 조합 판정과 대조했다. 단계별 발동률과 다중 대상 생존 효율은 정상 전투 표본으로 비교한다.
