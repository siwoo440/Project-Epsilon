# 173일차 점수 경계의 정확한 계산

경험치·일반 처치·종료 체력·남은 몸통 비율에서 생기는 소수 계산 오차를 제거했다. 경험치 43 / 2,000의 430점과 일반 적 228 / 1,600의 1,425점이 각각 1점 적던 사례를 기존 점수 검사에 추가했다. 항목 만점에 도달하면 곱셈 전에 상한을 반환한다.

시험 기준인 총 100,000점, 경험치 2,000, 일반 적 1,600, 회복 아이템 초과 획득 100점과 개인 최고점 저장 방식은 사용 중인 설정을 기준으로 검토했다. 재시도 시 런 식별자로 중복 보상을 방지하는 처리를 확인했다. 영구 성장 비용은 일반 단계별 3·5·8·12·18코어, 최종 강화 25코어다. 코어 획득 흐름과 성장을 사용하지 않은 정상 시간 플레이는 추가 표본으로 검증한다.
