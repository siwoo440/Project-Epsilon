# 174일차 적 밀집 구간의 황충 접촉

황충 접촉을 검색할 때 공통 적 레이어를 먼저 제외한다. 256개 결과 배열에 적이 먼저 들어와 뱀의 충돌이 누락될 수 있었던 경로를 제거했다. 실제 벌레의 원형 접촉, 물리 이동 경로 검사, 몸통 판정, 충돌 우선순위와 무적은 기존 규칙을 사용한다. Unity가 권장하는 배열 재사용 물리 쿼리 오버로드를 사용한다.

기존 황충 배치 시나리오에 적 레이어 충돌체 300개와 플레이어가 겹치는 조건을 추가했다. 벌레 사이 빈 공간의 무피해와 2~5회 대열 추첨도 기존 검증에 포함된다. 세 맵의 길·장애물 배치, 황충·낙석 경고, 20칸 몸통의 회피와 보스전 출구는 실제 움직이는 전투에서 확인한다.
