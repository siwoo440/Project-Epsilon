# 176일차 적 이동 모션 타이밍 분산

같은 유형의 적이 동시에 화면에 몰릴 때 모두 같은 시점에 이미지가 확대·회전하는 현상을 줄였다. 적 출현 좌표로 개별 타이밍을 계산하며 전투 난수에 영향을 주지 않는다. 크기와 회전에 같은 파형을 써서 중복 삼각함수 계산을 줄였다. 출현 타이밍 차이는 기존 적 이미지의 이동 모션에 적용한다.

기존 적 모션 검증에 서로 다른 위치에서 출현한 적의 모션 시작점 비교를 추가했다. 충돌체·머리 방향과 이미지 변형의 독립성은 기존 검사에서 다룬다. 실제 적 무리, 엘리트 공격과 보스 경고의 가독성은 렌더링 실행에서 검증한다.
