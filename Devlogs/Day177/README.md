# 177일차 전투 중요 효과음 우선순위

반복 공격음과 피격·몸통 손실·합성·레벨업·정예·보스 등장 알림을 서로 다른 재생기로 처리한다. Unity 오디오 보이스가 부족한 상황에서 중요 효과음에 높은 우선순위를 부여했다. 전체 음량과 기존 공격음 반복 간격은 같은 설정으로 관리하며 비활성화 때 두 재생기를 정지한다.

기존 효과음 검증에 두 재생기의 실제 우선순위 검사를 추가했다. 음원은 저장소의 효과음·배경음 출처 표에 기록한 에셋을 사용한다. 실제 장치에서 들리는 음량, 소리 겹침, 메뉴·맵·보스 전환과 정지 시 청취 품질은 별도 검증 대상으로 남긴다.
