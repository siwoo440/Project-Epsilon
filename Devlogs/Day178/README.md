# 178일차 Windows 전투 성능 측정 준비

기존 Windows 빌드 검증에 `-epsilonPerformanceBuild` 옵션을 추가했다. 기존 아이콘 시험과 분리된 `Day178Build` 폴더에 Unity Profiler 연결이 가능한 Windows 개발 빌드를 생성한다. 포탑 최근접 대상 탐색에는 `ProjectEpsilon.Turret.FindClosest` 표식을 추가했다.

1920×1080에서 60FPS를 시험 목표로 사용한다. 정상 속도의 전투에서 플레이어 이동과 포탑, 사격, 보석, 상태 이상과 시각 효과가 활성화된 상태로 적 수와 CPU·GPU 프레임 시간, p95, 프레임당 GC, 메모리를 함께 수집한다. 500마리와 보스 전환·재도전은 각각 실제로 도달한 표본으로 확인한다. 기존 정지 적 프레임 검사는 전투 성능 결과에서 제외한다.

169~178일차 런타임과 수정한 배치 검증 소스는 Unity 6000.3.21f1 참조를 사용해 C# 컴파일을 통과했다. 캐릭터 에셋·경험치 집계·전투 기록 검증의 Python 테스트 14개가 통과했다.
