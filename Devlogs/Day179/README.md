# 179일차 분리 씬의 화면 배율 검증 보완

175일차의 메뉴 배율 검사를 현재 출시 경로를 검증하는 `AutomatedSceneFlowVerification.cs`로 옮겼다. 이전 `AutomatedDay49FrontendVerification.cs`는 메인 메뉴에 전투 관리자가 존재하는 조건을 기다려 시간 초과했다. 실제 메인 메뉴와 키 설정을 열고 두 캔버스의 기준 해상도와 화면 비율 설정을 검사한다.

179일차 변경은 테스트 소스에 적용했다. Windows 개발 빌드는 178일차의 게임 코드를 대상으로 생성했고 비대화형 엔진 시작을 확인했다.

Unity 배치에서 메뉴와 키 설정 배율, 준비 씬, 실제 시작 포탑 장착, 저장 실패 후 재시도 및 메인 메뉴 복귀가 통과했다. 별도 배치로 적 500마리 상한과 정예 대기, 세 맵의 20칸 몸통 회전과 출구 도달을 확인했다.

1920×1080에서 실제 적 무리와 투사체, 포탑, 보석 및 VFX가 움직이는 전투의 CPU·GPU 프레임 시간과 해상도별 화면 가독성은 별도 확인 대상으로 남는다.
