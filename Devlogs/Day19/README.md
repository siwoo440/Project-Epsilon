# 19일차: 성장과 경험치 기준 정리

---

## 개발 방향

18일차 구현을 바탕으로 기획서의 초반 5분 핵심 루프를 검증한다. 몸통 성장과 경험치 기준을 먼저 맞추고 시험 무기, 합성 입력, 적 출현과 보상 선택을 이어서 연결한다.

---

## 변경 사항

- 경험치 요구량에 기획서의 반올림을 적용했다.
- 몸통의 절대 상한을 설정값과 직렬화 초기화 양쪽에서 20으로 제한했다.
- 성장 상한과 현재 몸통 수의 구분을 검증하는 편집기 검증 코드를 추가했다.

---

## 검증 상태

- 실제 경험치 계산 코드의 1~5레벨 기준값 10, 11, 13, 14, 16을 별도 .NET 실행으로 확인했다.
- Unity 편집기 배치 실행은 라이선스 클라이언트의 액세스 토큰 오류로 시작하지 못했다. 몸통 및 씬 내 동작은 편집기에서 확인해야 한다.
