# 20일차: 초반 전투 루프 연결

---

## 개발 방향

기존 몸통·무기·경험치 구조를 유지하고 0~5분 시험 전투를 위한 무기, 적 출현, 합성 조작과 패배 전환을 연결한다. [최신 기획서](https://docs.google.com/document/d/1Er6Ud6qxj7jfXhEGz2DRh053vn8Q6dv93-uluDrfius)의 시험 수치는 밸런스 확정값이 아니다.

---

## 변경 사항

- 시험 무기 6종의 피해·공격 주기·속성과 창 관통 수를 데이터에 반영했다.
- 화염 기본 화상과 물리·화염의 일부 시너지 수치를 수정했다.
- E 합성, ESC 취소 우선, 전체 게임 속도 70%, 공통 강화 선택과 Space 가속을 연결했다.
- 레벨업 시 가득 찬 슬롯의 교체 대상 선택과 신규 무기 거절을 제공한다.
- Game 씬에 추적자, 측면 포식자, 사수와 4분 엘리트 출현 설정을 연결하고 고정 시험 표적을 비활성화했다.
- 마지막 몸통 손실을 패배 상태와 연결했다.

합성 시 기존 강화 상속 규칙은 문서에 명시되지 않아 첫 번째 무기의 강화만 보존하고 신규 강화를 추가하는 임시 방식이다. 적 생성 간격과 엘리트 능력치는 조정 가능한 가정값이다.

---

## 검증 및 미완료

경험치와 무기 계산은 `Tests`의 독립 실행 프로그램으로 검증한다. Unity 라이선스 오류로 에디터 검증 및 실제 플레이는 실행하지 못했다. 씬 로딩, 5분 전투, 물리 충돌, UI 흐름과 밸런스 확인이 남았다.

엘리트의 별도 3지선다 보상, 보석 병합, 시작 무기 3지선다, 일부 고등급 무기와 시너지 효과, 장애물 이탈 처리, 최종 보스와 승리 처리는 아직 구현하지 않았다.
