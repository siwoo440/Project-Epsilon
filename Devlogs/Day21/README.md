# 21일차: 엘리트 보상 선택

---

## 개발 방향

엘리트 경험치 보석과 별개로 보상 선택을 대기열에 보관하고, 연속 레벨업과 기존 합성이 끝나는 순서를 고려한다. 세 후보 화면과 무기 슬롯 교체 화면은 기존 UI를 재사용한다.

---

## 시험용 보상 정책

- 회복, 몸통 1칸 복구, ★1~★2 무기, 즉시 합성 중 서로 다른 세 종류를 제시한다.
- 현재 적용할 수 없는 후보는 비활성화하며, 선택 가능한 후보가 하나 이상 포함되도록 추첨한다. 모두 불가능하면 보상을 보류한다.
- 체력 회복량 15와 ★2 무기 확률 25%는 기획 확정값이 아닌 Inspector 조정용 임시값이다.
- 합성을 취소하거나 레벨업으로 선택을 중단해도 보상을 보존한다. 후보가 모두 무효화되지 않는 한 기존 후보도 유지한다.
- 무기 교체를 거절해도 최초 추첨한 무기와 등급을 유지하며, 해당 무기가 더는 유효하지 않을 때만 재추첨한다.
- 대형 경험치 보석은 기존 적 보상 처리에서 별도로 생성한다.
- 등급 디버그 입력은 Shift+3 또는 Shift+5이며 합성 화면에서는 동작하지 않는다.

---

## 검증 상태

Unity Personal 라이선스 할당을 확인했고, 20일차 사본에서 성장 규칙 편집기 검증이 통과했다. 사용자 중지 신호로 Unity 화면 조작을 종료했으므로 실제 5분 플레이는 확인하지 못했다.

엘리트 보상 컨트롤러의 독립 테스트는 주변 Unity 컴포넌트를 대체한 상태에서 대기열, 회복·복구, 무기 교체, 합성 취소·성공 및 일시정지 경합을 확인한다. 실제 Unity 씬과 입력 장치에서의 통합 검증은 별도로 남았다.
