# 23일차: 물리 스텝 충돌 우선순위와 자연 전투 검증

---

## 개발 방향

한 물리 스텝에서 발생한 몸통 손실과 HP 피해를 수집하고, 해당 물리 스텝이 끝난 직후 정해진 순서로 처리한다. 기존 전체 무적을 먼저 확인하고, 자기·적 직접 충돌 및 엘리트 절단을 장애물 피해보다 먼저 처리한다. 장애물 피해로 새 전체 무적이 생기면 같은 스텝의 후속 HP 피해에도 적용한다.

기존 직접 호출 API와 보호막 처리 경로는 유지한다. 적 투사체가 같은 스텝에서 파괴돼도 명중 피해가 보존돼야 하며, 일시정지·씬 변경·비활성화 및 도메인 재시작 때 대기 피해가 잘못 남지 않아야 한다.

---

## 검증 계획

- 적·장애물 콜백의 양쪽 순서, 기존·신규 무적, 자기충돌, 중복 접촉을 검사한다.
- 투사체와 근접 피해, 보호막, 피해 초과와 패배, 여러 물리 스텝 및 정지·파괴 상황을 Unity 배치에서 검증한다.
- 실제 가상 키 입력과 자연 적 출현을 사용해 처치·경험치·레벨업을 확인한다. 시간 배율, 자동 선택과 시험 조건은 결과에 명시한다.
- 기존 22일차 자동 생존·엘리트·HUD·설정 및 통제 전투 검증과 독립 회귀 테스트를 다시 확인한다.

---

## 검증 결과

- 수정 전 Unity 실제 물리 검증에서 장애물 충돌이 적 직접 충돌보다 먼저 들어오면 몸통 손실이 누락되는 현상을 재현했다.
- 수정 후 Unity 6000.3.21f1 비대화형 배치에서 실제 동시 충돌, 양쪽 인위 콜백 순서와 무적·자기 충돌·투사체·보호막·근접 피해·엘리트 절단·여러 물리 스텝·일시정지·패배를 검증했다. 실제로 관찰한 동시 콜백 순서는 장애물 다음 적 직접 충돌이었다.
- 독립 충돌 회귀 12개와 기존 독립 회귀 테스트 8개가 통과했다.
- Unity Editor의 Search 인덱싱 과정에서 `ArgumentOutOfRangeException`이 기록됐다. 로그에서 게임 코드 예외는 확인되지 않았다.
- 자연 출현과 정상 속도에서 가상 입력으로 전투한 첫 시도는 적 6회 처치와 경험치 6/10 획득 후 57.2초에 패배했다. 몸통 위험을 반영한 두 번째 시도는 적 1회 처치와 경험치 1/10 획득 후 12.6초에 패배했다. 두 시도 모두 레벨업은 검증하지 못했으며, 자동 조종과 실제 난이도의 영향은 구별되지 않았다.
