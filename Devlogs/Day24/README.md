# 24일차: 합성 재료 선택과 강화 계승

---

## 개발 방향

같은 무기와 등급의 합성 재료 두 개를 몸통 슬롯에서 직접 선택한다. 두 재료의 기존 공통 강화 내역을 표시하고 한쪽을 계승한 뒤 새 공통 강화 하나를 선택한다. 확정 전 취소와 외부 슬롯 변경은 재료를 보존한다.

---

## 검증 결과

- 독립 시험에서 두 번째 재료 계승, 네 번째와 스무 번째 슬롯 선택, 외부 슬롯 변경 및 취소를 확인했다.
- Unity 6000.3.21f1 실제 Game 씬 배치는 통제된 몸통·무기와 가상 입력, 실제 버튼 이벤트로 20번 슬롯 선택, 강화 계승, 공통 강화, 장착 무기 2개에서 1개로 감소할 때의 시너지 즉시 갱신을 검증했다.
- 같은 배치에서 E·ESC, 각 선택 단계의 취소, 70% 게임 속도와 자동 직진, 몸통 손실·레벨업·엘리트 보상에 따른 처리도 확인했다. 최종 재실행은 종료 코드 0이다.
- 속성 무기 2~9개에서 합성 전후 시너지 단계 미리보기와 취소 시 보존을 검증했다. 실제 4→3 합성 결과는 미리보기와 일치했고, 대표 문구의 측정 크기 462.46×15.59는 620×32 영역 안에 들어갔다. Unity 배치 종료 코드는 0이다.
- 자연 전투 자동 조종은 정상 속도로 300초를 생존했지만 적 처치와 경험치가 없어 레벨업 검증에 실패했다. 적 체력 감소는 관찰됐으며 시험 조건은 Unity 배치 검증 안내에 기록했다.
- 초기 배치는 시험 코드의 입력 설정 정리 예외로 종료하지 못해 해당 배치만 중단했으며, 시험 코드를 수정해 재실행했다. Unity Editor Search 인덱싱 예외는 별도로 기록됐다.

---

## 남은 작업

- 미장착 레벨업 보상을 합성 재료로 사용하는 흐름과 일시정지·취소·연속 레벨업 인계를 구현한다.
- 자연 출현 적과의 전투에서 경험치 획득 후 레벨업까지 이어지는 경로를 추가 검증한다.
