# 25일차: 미장착 보상 무기 합성

---

## 개발 방향

레벨업으로 받은 미장착 무기와 장착된 같은 무기·같은 등급을 합성하는 기반을 추가한다. 새 보상 무기는 기존 공통 강화가 없는 것으로 취급한다. 두 재료 중 장착 무기 또는 새 보상의 강화를 선택해 계승하고, 결과 무기를 머리 뒤에 배치한다.

미장착 보상은 합성 전 속성 집계에 포함되지 않으므로 성공 후 장착 무기 수와 해당 속성 무기 수는 유지돼야 한다. 화면에서 보상을 한 번만 소비하고, 취소 시 보상 선택으로 돌아가는 흐름은 별도로 연결한다.

---

## 검증 결과

- 독립 시험에서 빈 슬롯·만석, 양쪽 강화 계승, 잘못된 재료와 강화 선택 거절, 장착 수·시너지 유지 및 기존 장착 무기 2→1 합성 회귀가 통과했다.
- 실제 Unity 게임 씬에서 24일차 기준은 API 부재로 종료 코드 1, 25일차 수정본은 동일 시험에서 종료 코드 0을 기록했다. 몸통과 무기는 통제해 구성했다.
- Unity Editor Search의 시작 인덱싱 예외가 별도로 기록됐다.
- 자연 전투 자동 조종에서는 두 추적자에게 각각 연속 피해를 줬지만, 300초 생존 동안 처치·경험치·레벨업은 발생하지 않았다. 조종 대상이 무기 사거리 밖으로 벗어난 원인은 추가 진단 중이다.

---

## 남은 작업

레벨업 화면에서 보상 합성을 선택하고, 70% 속도 진입·취소 후 일시정지 복귀·성공 시 한 번만 보상 소비·연속 레벨업을 연결한다. 현재 낮은 수준 API만으로는 보상이 소비되지 않는다.
