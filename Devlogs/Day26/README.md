# 26일차: 레벨업 보상 무기 합성 연결

---

## 구현 내용

레벨업에서 합성 가능한 무기를 선택하면 장착·교체, 보상 합성, 후보 재선택 중 하나를 고른다. 미장착 보상과 같은 무기·등급의 장착 재료를 고르고, 계승할 강화와 새 공통 강화를 선택한다. 합성 중에는 게임을 70% 속도로 진행하고 자동 직진한다.

취소하면 선택한 보상으로 돌아가 레벨업 일시정지를 복구한다. 성공 시 보상을 한 번만 완료하고 대기 중인 연속 레벨업을 이어 간다. 마지막 재료가 없어지면 합성을 비활성화하며, 초과 피해로 패배하면 남은 선택 화면을 닫는다.

---

## 검증 결과

- 독립 시험에서 취소, 중복 확정 방지, 연속 레벨업, 패배, 제어기 비활성화, 외부 일시정지와 마지막 재료 손실을 확인했다.
- 실제 Unity Game 씬의 통제 시험에서 가상 입력과 실제 UI 버튼으로 70% 직진, 빈 슬롯과 만석, 재료·강화 선택, 취소, 연속 레벨업과 대기 엘리트 보상을 확인했다.
- 실제 2D 적 접촉으로 몸통 손실 후 보상 선택에 복귀하고, 별도의 치명적 초과 피해 후 패배·시간 정지·화면 정리·미완료 보상 보존을 확인했다.
- 숫자 2의 같은 프레임 중복 입력, 합성·레벨업 제어기 비활성화 복구, 마지막 호환 재료 손실 시 버튼 상태를 실제 씬에서 재현한 뒤 수정했다. 최종 통합 배치는 종료 코드 0이며 종료 시 UI 참조 예외가 재발하지 않았다.
- Unity Editor Search의 시작 인덱싱 예외가 별도로 기록됐다. 통제된 배치는 자연 전투 레벨업 검증을 대신하지 않는다.

## 남은 작업

자연 출현 적과의 전투에서 경험치 획득이 레벨업과 보상 선택으로 이어지는 경로를 검증하고, 5분 이후 적·보스와 승리 흐름을 개발한다.
