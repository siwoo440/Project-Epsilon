# 27일차: 시작 무기 선택

---

## 개발 방향

게임 시작 전에 시작 무기 후보 3개 중 하나를 선택한다. 선택 중에는 게임 시간과 이동·적 출현이 정지하며, 확정한 무기를 첫 몸통에 장착한 뒤 전투를 시작한다.

---

## 임시 데이터

기획서에서 캐릭터별 최종 시작 무기 후보는 아직 미정이다. 시험을 위해 기존 강철 검, 강철 창, 화염 고리를 `PrototypeStartingWeaponOptions` 데이터에 임시로 연결했다. 세 참조는 Unity Inspector에서 조정할 수 있으며 최종 캐릭터 설정으로 확정한 값이 아니다.

---

## 검증 상태

독립 실행 테스트 9개는 실제 게임 관리자와 시작 선택기를 사용하고 Unity 객체를 대체해 선택 전 시간 정지, 단일 장착, 후보 누락·중복 방지, 설정 입력 우선, 선택기 비활성 복구 및 선택기가 없는 씬의 기존 시작 동작을 확인했다. 종료 코드는 0이다.

비활성 `Configure` 수정 전 제품 사본의 Unity 실제 씬 배치는 종료 코드 0으로 세 후보를 각각 검증했다. 선택 전 실제 시간 0.25초 동안 게임 시간·위치·회전·적 출현이 정지했고, 실제 버튼 1·3과 가상 숫자 2로 선택한 무기가 첫 몸통의 유일한 ★1 무기로 장착됐다. 설정 중 선택은 차단됐고 선택 후 위치와 출현기 경과 시간이 증가했다. 이 배치는 무기 공격 자체를 측정하지 않았다.

시작 전 비활성 선택기와 비활성 중 `Configure` 경계는 각각 Unity 실제 씬에서 수정 전 실패를 재현하고 수정 후 선택 화면 복구와 첫 후보 확정을 확인했다. 두 수정 후 배치의 종료 코드는 각각 0이다. 최종 제품 사본의 세 후보 재검증과 공용 시작 버튼 헬퍼를 사용하는 기존 배치 결과는 별도로 확인한다.

Unity 에디터 배치가 초기화 단계에서 지연되는 동안 전체 런타임 스크립트를 Unity 6000.3.21f1 엔진과 프로젝트 InputSystem·UI 어셈블리 참조로 별도 컴파일했다. 오류 0개이며 씬에서 직렬화되는 엘리트 보상 필드에 대한 정적 할당 경고가 1개였다. 변경된 Unity 배치 스크립트와 공용 헬퍼의 사본 18개도 같은 방식으로 컴파일해 경고·오류 없이 완료했다. 이름이 같은 자연 전투 시험 변형은 임시 사본에서만 클래스 이름을 구분했다. 두 결과는 Unity 실행이나 게임 동작 검증이 아니다.


---

## 남은 작업

이번 시작 선택은 새 플레이 세션에서 `Starting` 상태로 진입하는 경로를 대상으로 한다. 현재 `DontDestroyOnLoad` 게임 관리자의 기존 `Playing` 상태를 씬 재진입 시 새 런으로 초기화하는 흐름은 없어, 재시작·씬 재진입 시 선택 화면을 다시 여는 작업이 남았다.
