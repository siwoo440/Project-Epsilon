# 28일차: 강철 검 ★3 근접 공격

---

## 개발 방향

강철 검은 ★1·★2에서 단일 대상을 공격하고, ★3부터 몸통 위치의 공격 범위 안에서 가장 가까운 적 최대 2명을 벤다. 기존 공격 주기와 속성 명중 처리 경로를 유지한다.

---

## 변경 사항

무기 데이터에 ★3 근접 공격의 최대 대상 수를 추가하고, 시험용 강철 검에 2를 설정했다. 다른 무기의 기본값은 1이다. 첫 대상과 다른 두 번째 최근접 대상을 공격 전에 고르고, 첫 명중 중 두 번째 대상이 죽거나 비활성화되면 추가 명중을 생략한다.

기획서의 강철 검 ★5 넓은 강타는 발동 횟수·범위·피해 수치가 정해지지 않아 구현하지 않았다. ★5에서도 ★3의 최대 2명 공격은 유지한다.

---

## 검증 상태

실제 무기 관리자 코드를 사용하고 Unity 객체와 적을 대체한 독립 시험은 ★1·★2 단일 공격, ★3~★5 최대 두 명, 다른 무기와 범위 제한, 몸통 원점과 속성 명중, 공격 주기·등급 알림 1회, 첫 적 사망과 첫 명중 중 두 번째 적 사망을 확인했다. 총 6개 시나리오의 종료 코드는 0이다.

기존 보상 합성 독립 시험과 속성 무기 규칙 시험도 통과했다. Unity 6000.3.21f1 엔진과 프로젝트 패키지를 참조한 전체 런타임 스크립트 별도 컴파일은 오류 0개, 씬 직렬화 필드의 정적 할당 경고 1개로 완료했다. 이는 Unity 실행 결과가 아니다. Unity 실제 씬 시험은 27일차 코드에서 ★1·★2 단일 공격은 통과하고 ★3이 한 명만 공격해 종료 코드 1로 실패했다. 수정 후 같은 배치는 종료 코드 0으로 통과했으며 ★1~★5, 최근접 최대 두 명과 단일 공격 주기, 다른 화염 근접 무기, 첫 대상 사망 중 대상 재등록·비활성·추가, 물리 ×2 실제 피해를 확인했다.
