# 30일차: 화염탄 ★3 추가 전달

---

## 개발 방향

시험용 화염탄은 ★1·★2에서 최초 대상 한 명을 공격하고, ★3부터 최초 적 근처의 다른 적 최대 한 명에게 공격을 전달한다. 기존 등급 피해와 화상·속성 효과 경로를 사용한다.

---

## 임시 수치와 처리

기획서는 전달 반경과 전달 피해 비율을 확정하지 않았다. 시험용 `DebugBlaster` 데이터에 반경 2.0, 직접 피해 배율 1.0을 임시로 설정했으며 Inspector에서 변경할 수 있다. 다른 무기의 기본 전달 반경은 0으로 기존 동작을 유지한다. 한 발의 투사체는 최초 명중 시 한 번만 전달을 시도하고, 최초 적 위치의 반경 안에서 가장 가까운 다른 적을 고른다.

발사 때 전달 반경·배율과 공격의 무기·원점·등급·속성 단계 정보를 보관한다. 최초 명중 중 추가 대상이 죽거나 비활성화되면 전달하지 않으며, 실제로 맞지 않은 대상은 이후 직접 관통 명중이 가능하다. 전달된 대상은 중복 명중 목록에 포함해 관통 중 다시 맞지 않는다.

동기 명중 콜백 중 투사체가 비활성화되거나 `Configure`로 새 발사로 재설정되면 이전 발사의 후속 전달과 파괴를 중단한다. 비활성 구성 요소의 물리 콜백도 피해·명중 횟수를 소비하지 않는다. 외부 코드가 투사체 GameObject에 직접 `Destroy`를 호출하는 같은 프레임의 파괴 예약 여부는 별도 표식 없이 확인할 수 없으며, 현재 제품의 명중·사망 구독자에는 그런 호출이 없다.

기획서의 ★5 화상 적 처치 폭발은 범위·피해 등 세부 수치가 정해지지 않아 구현하지 않았다.

---

## 검증 상태

실제 투사체 스크립트에 Unity 구성과 표적을 대체한 독립 시험 13개는 ★1·2와 다른 무기 유지, ★3~5의 최대 한 명 전달, 발사 스냅샷과 피해 배율, 화상 경로, 후보 부재, 대상 사망·비활성, 관통·동기 재진입, 발사 중 데이터 변경과 재설정, 투사체 비활성·재활성을 확인했다. 종료 코드는 0이다.

기존 강철 검, 보상 합성, 속성 무기 규칙 독립 시험과 `git diff --check`도 통과했다. Unity 6000.3.21f1 엔진과 프로젝트 패키지를 참조한 전체 런타임 별도 컴파일은 오류 0개와 씬 직렬화 필드 경고 1개로 완료했다. 참조 컴파일은 Unity 실행이 아니다. Unity 실제 Game 씬에서 29일차 코드는 ★1·2 단일 공격은 통과했지만 ★3 추가 전달이 없어 종료 코드 1이었다. 같은 시험의 30일차 배치는 종료 코드 0으로 통과했다. 실제 2D 물리 접촉으로 ★등급별 전달, 임시 반경 2.0의 1.99/2.01 경계, 강철 창의 기존 관통, 화염 ×2에서 두 대상 직접 피해 10.5와 화상 초당 1.2, 최초 적·전달 대상 사망 및 비활성, 메모리에서 관통을 2회로 조정한 중복 명중, 발사 뒤 설정 변경, 투사체 비활성 접촉과 재활성 재접촉을 확인했다. 명중 콜백 안에서 `Configure`를 재호출하는 경계는 독립 대체 시험으로 확인했으며 현재 제품에 그런 호출 경로는 없다.
