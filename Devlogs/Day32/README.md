# 32일차: 사수 조준과 화면 밖 적 출현

---
## 확인한 차이

기획서는 사수가 몸통 방향으로 발사하고 적의 화면 밖 출현을 확인하도록 요구한다. 기존 사수는 머리를 조준했고 적은 화면 크기와 관계없이 플레이어로부터 반경 9의 원 위에 출현해 카메라 안에 생길 수 있었다.

---
## 변경 내용

- 사수는 기존처럼 머리까지의 거리로 접근·정지·후퇴하며, 발사할 때 활성 몸통 중 가장 가까운 위치를 조준한다. 유효한 몸통이나 발사 방향이 없으면 머리로 대체한다.
- 일반 적과 4분 엘리트는 기존 무작위 방향과 최소 출현 거리를 유지하면서 직교 주 카메라의 화면 밖으로 생성한다. 화면 경계에서 0.5 월드 단위를 더하는 설정은 시험용 임시값이며 씬에서 조정할 수 있다. 카메라가 없거나 직교 카메라가 아니면 기존 최소 거리로 생성한다.
- 출현 및 정리 갱신을 기본 순서의 카메라 추적 이후 `LateUpdate`로 옮긴다. 출현 순서와 간격, 일시정지와 일반 적 상한은 유지한다.
- 아주 넓은 화면이나 이동한 카메라에서 새로 생성한 적이 정리 거리 22를 넘어 즉시 사라지지 않도록 카메라 화면과 여유를 포함하는 정리 거리를 계산한다. 이 경우 정리 범위가 넓어지지만 동시 적 상한은 유지된다.

---
## 검증

- 제품 코드 참조 독립 시험 13개가 종료 코드 0으로 통과했다. 세로 9:16부터 종횡비 6까지 네 화면 비율과 각각 16방향, 이동한 카메라, 화면 여유·생성 후 유지, 카메라 부재, 0/60/120/240초 출현·만석, 일시정지 및 사수의 몸통/머리 조준을 통제했다. 독립 시험은 Unity 물리나 렌더링을 실행하지 않는다.
- 변경 전 31일차 실제 Unity 씬 red는 종료 코드 1이었다. 사수는 몸통 대신 머리를 조준했고, 화면 비율 32:9에서 일반 적 16개가 모두 요구 여유 안에 생성됐으며 4분 엘리트도 화면 안에 생성됐다. 같은 프레임 카메라가 9.848 이동한 뒤 화면 안에 노출되는 경계도 재현했다. 몸통이 없을 때 머리 대체, 기존 사수 접근·유지·후퇴 및 카메라 부재의 거리 9는 통과했다.
- 생성 프레임의 위치와 정확한 정수 좌표 동률을 확인하도록 보정한 동일 실제 Unity 씬 스크립트는 31일차에서 종료 코드 1, 32일차에서 종료 코드 0이었다. 사수의 최근접·동률 몸통 선택, 몸통 부재 머리 대체와 머리 거리별 이동, 일반 적 16개와 4분 엘리트의 화면 여유 밖 출현, 기존 정리 거리 밖 4개를 포함한 16개 전원의 생성 직후 유지, 카메라가 같은 프레임 15.593 이동한 뒤의 렌더 직전 화면 위치를 확인했다. 별도 실제 씬 회귀도 종료 코드 0으로, 시간 배율 8에서 0→240초를 누적하며 추적자·포식자·사수·엘리트를 각각 0.350/60.044/123.064/240.001초에 처음 관찰했다. 엘리트 보석 XP20 수집 후 연속 레벨 2·3, 보상 선택과 재개를 확인했다. 일반 적 종류는 무작위 추첨하므로 해금 시각과 첫 관측 시각은 다를 수 있다. 실제 0→240초 회귀에서 플레이어 이동과 자동 공격을 끄고 관측한 일반 적을 보상 없이 제거했으며, 엘리트는 강제 처치했다. XP 요구량 10·배율 1.0과 회복·몸통 아이템 드롭 확률 0도 시험 통제이고 레벨업·엘리트 보상은 실제 UI 버튼으로 선택했다. 따라서 자연 전투나 자연 속도 5분 결과는 아니다.

## 남은 작업

- 화면 여유 0.5와 출현 간격·거리는 시험용 값으로 유지하고 실제 게임 밸런스와 성능을 검증한다.
