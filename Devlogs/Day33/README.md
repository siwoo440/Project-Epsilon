# 33일차: 엘리트 출현 일정과 동시 관리

---
## 변경 내용

- 기존 첫 엘리트 출현 시각 240초를 유지하고, 480·720·960초 후속 회차를 씬에서 조정할 수 있도록 추가했다.
- 살아 있는 엘리트를 각각 추적해 개별 처치에 따른 XP 보석과 선택 보상이 한 번씩 발생하도록 했다. 4분부터 12분 이전까지 동시 1마리, 12분부터 동시 2마리를 임시 상한으로 사용한다.
- 예정 시각에 동시 상한이나 전체 적 상한 때문에 자리가 없으면 해당 회차를 도착 순서대로 보류하고, 자리가 생긴 후 한 번 생성한다. 이 대기 규칙은 기획에서 미처치 엘리트와 정시 출현이 겹칠 때의 처리가 명시되지 않아 적용한 임시 가정이다.
- 전체 적 40마리가 가득 차면 기존 엘리트는 보존하고 가장 먼 일반 적을 보상 없이 제거해 자리를 확보한다. 제거 대상은 지연 파괴 전에 비활성화해 드롭 구독과 공격 대상 등록을 먼저 해제한다.
- 기획에서 후속 엘리트의 세부 능력치와 출현 풀이 미정이므로 네 회차 모두 현재 4분 시험용 돌진·절단형을 재사용한다. 20분 보스 전환에서 미처치 엘리트와 대기 회차를 처리하는 규칙은 별도 개발 과제로 남긴다.

---
## 검증

- 기존 제품 코드에 대한 독립 선행 시험은 480초 이후 출현과 동시 대기 경계에서 실패했다. 수정한 제품 코드를 참조하는 독립 시험 7개는 종료 코드 0으로 네 회차와 개별 보상·XP, FIFO 순서, 동시 상한, 만석, 중복 사망, 정지·재개, 축소 시간, 여러 경계를 한 번에 넘는 경우를 확인했다.
- 만석에서 제거한 일반 적에 파괴 완료 전 같은 프레임에 직접 사망을 유도했을 때 경험치가 발생하는 독립 선행 실패를 확인했다. 제거 전 비활성화한 수정본은 같은 대조를 통과했다. 이 인위적 재진입은 자연 전투에서 발생한 것으로 확인하지 않았다.
- 32일차 사수 조준·화면 밖 출현 독립 회귀 13개는 수정된 출현기를 참조해 종료 코드 0으로 통과했다. 독립 시험은 Unity 물리나 실제 씬을 실행하지 않는다.
- 32일차 실제 Unity 씬 red는 종료 코드 1이었다. 240.003초의 첫 엘리트 출현, 40마리 상한과 가장 먼 일반 적 제거는 확인됐지만 첫 엘리트 처치 후 8분 회차가 나오지 않았다. 수정본의 동일 실제 씬 시험은 종료 코드 0으로 4분 240.001초, 보류된 8분 회차 481.019초, 12분 720.007초의 두 엘리트와 보류된 16분 회차 961.017초를 확인했다. 일반 적 만석 자리 확보, 제거 직후 같은 프레임의 직접 피해 무보상, 네 엘리트 사망과 XP·선택 보상 각 4회, 연속 레벨업 우선 및 실제 UI로 보상 4회 소비가 통과했다. 시험은 출현기 시간 직접 주입 없이 시간 배율 32로 진행했다. 플레이어 이동·몸통 추적·충돌·무기 공격과 생성된 적 행동을 정지하고 일반 적 40마리를 유지했으며, 엘리트를 직접 치명 피해로 강제 처치했다. 회복·몸통 드롭 확률 0, 레벨 요구량 10·배율 1.0으로 통제하고 실제 생성된 대형 보석 하나를 플레이어 위치로 옮겨 수집했다. 따라서 자연 속도 플레이 결과는 아니다. FIFO 보류는 미처치 엘리트가 있는 상황의 임시 가정이다. 별도 외부 파괴 시험은 같은 32배 가속·적 만석 등 통제 조건에서 첫 엘리트를 `Destroy`로 제거했고, 실제 파괴 완료 후 사망 이벤트·XP 보석·선택 보상은 0이며 보류된 다음 엘리트가 481.041초에 출현하고 전체 적 40이 유지됐다. 같은 시험은 32일차에서 종료 코드 1, 수정본에서 종료 코드 0이었다.
- 내부 필드 참조를 갱신한 기존 사수·출현 시험은 실제 씬에서 32:9 카메라와 강제 240초 등 통제 조건으로 다시 실행해 종료 코드 0이었다. 기존 엘리트 에디터 검증도 편집 모드 배치에서 추첨, 중복 사망 콜백 직접 호출, 설정 UI 순서를 확인해 종료 코드 0이었다. 이 두 결과는 자연 전투 결과가 아니다.
