# 34일차: 20분 전환과 시험용 보스

---

## 변경 내용

- 출현기의 실제 게임 시간을 화면에 함께 사용한다. 같은 프레임에 일시정지하더라도 이미 지난 게임 시간을 보존하며, 시간 표시의 초기화는 출현 일정에 영향을 주지 않는다.
- 게임 시간 1,200초에 기존 일반 적·미처치 엘리트·적 투사체와 몸통 복구 아이템을 보상 없이 정리하고 기존 웨이브를 중단한다. 경험치 보석과 체력 회복 아이템, 이미 대기 중인 보상은 보존한다. 미확정 합성은 재료를 보존하며 닫고 다시 시작할 수 있다.
- 전환을 한 번 알리고 시험용 보스를 생성한다. 공용 무기 공격 대상과 기존 사수 이동·투사체를 재사용하며, 최대 HP·피해·속도·사격 간격·2단계 배율은 씬에서 바꿀 수 있는 임시값이다. 보스는 넉백에 면역이며 체력이 50% 이하가 되면 이동 속도와 사격 간격이 변한다.
- 실제로 등록된 보스의 사망 이벤트만 승리 상태와 시간 정지로 연결한다. 보스 HP와 간단한 승리 문구를 표시한다.

---

## 검증

- 기존 33일차 실제 Unity 씬 배치는 보스 전환 상태·이벤트가 없어 종료 코드 1이었다. 수정본에서는 게임 시간을 0초부터 32배로 누적해 1,200.003초의 단일 전환, 관리 적 40마리 정리, 보석·체력 회복 보존, 복구 아이템·적 투사체 제거, 미확정 합성 재료 보존과 재개, 실제 보스의 50% 단계와 강제 치명 피해에 따른 승리를 확인했다. Unity 종료 코드는 0이었다. 플레이어 이동·충돌과 적 행동을 통제하고 보스를 직접 공격했으므로 자연 20분 플레이는 아니다.
- 보스 단계·승리의 독립 C# 시험 4개, 기존 엘리트 일정과 전환 처리 시험 9개, 사수·적 출현 회귀 13개가 통과했다. 독립 시험은 Unity 물리나 실제 씬을 대체하지 않는다.
- 실제 Unity 씬에서 같은 프레임 일시정지 직전 경과 0.000178초의 보존, 전투 시간과 HUD 표시의 일치, 정지 유지, 표시만 초기화한 뒤 재개를 확인했다. 종료 코드는 0이었다. 정지는 게임 관리자 API를 사용한 통제 시험이다.
- 초반 웨이브 회귀에서 첫 추적자 0.350초, 포식자 60.035초, 사수 123.051초, 엘리트 240.000초를 관찰했다. 엘리트를 강제 처치한 뒤 실제 20 XP 보석, 두 번의 레벨업 선택과 한 번의 엘리트 보상 선택을 확인했고 종료 코드는 0이었다. 8배 시간 가속, 이동·전투 통제, XP 요구량 10 고정과 드롭 확률 통제를 사용했다.
- 앞선 동일 초반 회귀의 첫 실행은 레벨업 직후 같은 프레임에서 보석 객체가 조회돼 종료 코드 1이었다. 시험에 실제 획득·파괴 예약 상태와 다음 프레임 제거 확인을 추가한 뒤 재실행이 통과했으나 같은 프레임 분기는 재발하지 않아 첫 실패의 원인은 확정하지 않았다.
- Unity 배치 시작 시 에디터 Search 인덱싱 `ArgumentOutOfRangeException`이 별도로 기록됐다. 실제 제품 스크립트의 예외로 확인된 것은 아니다.

---

## 남은 작업

- 전용 보스 패턴, 경고 돌진·절단·잡몹 소환, 몸통 밀기와 자기 충돌 유예, 냉기 저항과 보스전 복구 제한은 아직 구현·검증하지 않았다.
- 세 종류의 보스와 완성된 보스 UI, 전용 엘리트 4종, 청크 맵과 장애물·특수 지역, 후반 웨이브 및 전체 20분 자연 플레이가 남아 있다. 보스의 임시 능력치와 공격 주기는 실제 플레이로 조정해야 한다.
- 배치에서 화면 가독성·보스 공격 예고·조작감은 확인하지 못했다. 사용자가 직접 Unity에서 확인할 항목이다.
