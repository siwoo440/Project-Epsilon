# 35일차: 시험 보스 부채꼴 사격

---

## 변경 내용

- 시험 보스가 가장 가까운 몸통을 향해 대칭 부채꼴 투사체를 발사한다. 1단계는 3발, HP 50% 이하 2단계는 5발이며 전체 부채각은 40도다. 이 수치는 기획 미정 임시값이며 씬에서 조정할 수 있다.
- 기존 사수 공격 경로와 실제 적 투사체, 공용 HP 피해를 재사용한다. 기존 일반 사수는 한 발만 발사하며 한 발의 방향은 기존 조준 방향과 같다.

---

## 검증

- 독립 사격 시험은 이전 코드에서 투사체 수·각도 설정이 없어 실패했고, 수정 후 보스 세 방향과 기존 사수 한 방향을 포함한 사수·출현 시험 14개가 통과했다. 엘리트 일정 시험 9개도 통과했다.
- 같은 Unity 테스트 스크립트 SHA-256 `D46C2D133CDCD6EAB0B58869A210AC51D69535897098B9EDAB5B1284E1644D23`으로 34일차 사본에서 실제 보스 사격이 한 발이라 종료 코드 1, 수정 사본에서는 일반 사수 1발, 보스 1단계 3발·2단계 5발의 대칭 각도와 실제 몸통 접촉 시 공용 HP 15 피해를 확인해 종료 코드 0이었다. 보스 출현과 사격은 시험에서 강제로 호출했고 이동과 자동 출현은 통제했다.
- 기존 실제 Unity 사수·출현 회귀도 몸통 조준·거리 유지·32:9 화면 밖 출현·강제 4분 엘리트와 카메라 이동 경계를 확인해 종료 코드 0이었다. 이 시험 역시 위치와 시간을 통제했다. Unity Editor Search 시작 인덱싱 예외는 별도로 발생했다.

## 남은 작업

- 예고 돌진과 2단계 절단, 위험 지역·잡몹 소환, 몸통 밀기 및 자기 충돌 유예, 냉기 저항은 아직 구현하지 않았다. 보스 수치와 탄막 가독성·회피 난도는 플레이 확인 후 조정해야 한다.
