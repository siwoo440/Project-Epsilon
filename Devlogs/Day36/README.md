# 36일차: 시험 보스 예고 돌진과 절단

---

## 변경 내용

- 시험 보스가 플레이어 방향을 고정해 선으로 예고한 뒤 직선 돌진한다. 예고 중 기존 사격·추적을 잠시 중단하고 돌진이 끝나면 이전 활성 상태로 복구한다. 돌진 간격·예고·지속 시간·속도는 씬에서 조정하는 임시값이다.
- 1단계 돌진 접촉은 공용 HP에 임시 피해 15를 예약하고, 2단계에서 예고한 강한 돌진은 HP를 거치지 않고 몸통 한 칸을 절단한다. 기존 물리 스텝 충돌 처리기와 전체 무적 판정을 사용하며 한 돌진에 성공 피해 또는 절단을 중복 적용하지 않는다.
- 예고를 시작할 때 공격 유형을 고정한다. 예고 중 단계가 바뀌더라도 이미 표시한 공격의 유형이 바뀌지 않는다. 게임 일시정지 중 예고와 돌진이 진행되지 않는다.

---

## 검증

- Unity 35일차 사본에서 선행 스크립트 SHA-256 `493FAEBB1510A891B344FD140889B2AD2ACBB3E8141C73FD79165AB7903AA4B4`는 돌진 행동이 없어 종료 코드 1이었다. 수정 후 같은 스크립트는 실제 예고선, 1단계 실제 접촉 HP 100→85, 2단계 실제 접촉 HP 100 유지·몸통 3→2를 확인해 종료 코드 0이었다.
- 보강 스크립트 SHA-256 `0B398950085F38821528C814D7281736A068427F2724D7747892FE146FE838C1`은 실제 예고 중 일시정지와 재개, 1단계 HP 피해, 2단계 몸통 절단, 전체 무적 중 HP와 몸통 보존을 확인해 종료 코드 0이었다. 보스를 강제 생성하고 예고 0.35초·돌진 1초·기본 속도 8로 통제했으며, 2단계에는 임시 배율 1.4가 적용됐다. 이동·일반 출현·자동 사격은 시험을 위해 정지했다.
- 최종 스크립트 SHA-256 `2698DDDB32F81EA3971ABB0EC53346710D2D99AAF13A2CB23AACE841033FCBCC`는 위 조건에 실제 보스의 몸통 선행 및 머리 접촉을 물리 콜백으로 관찰하는 사례를 추가했다. 몸통 진입 3회와 머리 진입 1회가 기록됐고 몸통은 총 1칸만 손실됐으며 Unity 종료 코드는 0이었다.
- 돌진 추가 후 실제 Unity 보스 부채꼴 사격·투사체 접촉 회귀와 32배 가속 0→1,200.004초 보스 전환·강제 처치 승리 회귀가 각각 종료 코드 0이었다. 두 시험은 이동과 적 행동 등을 통제했다. Unity Editor Search 시작 인덱싱 예외는 각 실행에서 별도로 발생했다.

## 남은 작업

- 보스의 몸통 밀기와 겹침 후 자기 충돌 유예, 위험 지역과 잡몹 소환, 냉기 저항 및 보스전 복구 제한은 구현하지 않았다. 예고선의 가독성, 이동 경로와 회피 조작감, 자연 20분 보스전은 직접 확인해야 한다.
