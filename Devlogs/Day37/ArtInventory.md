# 37일차 이미지 현황

조사 기준은 2026-11-08의 실제 `Game.unity`, 런타임 스크립트, Unity 데이터와 기획서 13번 에셋 탭이다. 그림체는 사용자가 승인한 **선명한 캐주얼 판타지 일러스트**를 기준으로 한다. 파일 존재, 게임 연결과 시각적 적합성은 각각 별도로 판단한다.

이미지 생성 전 `Assets/Art/Sprites`에는 PNG 52개가 있었다. `.unity`, `.prefab`, `.asset`, `.mat`, `.controller`, `.anim`의 GUID 참조 조사에서는 디버그 머리와 몸통 두 파일만 참조됐다. 이는 해당 직렬화 파일의 참조 조사 결과이며, 모든 가능한 외부 사용처를 확인했다는 뜻은 아니다.

## 승인된 플레이어 이미지

내장 이미지 생성 도구로 승인된 전체 플레이어 시안에서 머리·몸통·꼬리를 각각 생성했다. 이미지는 투명 PNG이며 원본 에셋을 덮어쓰지 않았다.

| 부위 | 프로젝트 파일 | 적용 범위 |
| --- | --- | --- |
| 머리 | `Assets/Art/Sprites/PlayerHead_Casual.png` | 실제 플레이어 머리 |
| 몸통 | `Assets/Art/Sprites/PlayerBody_Casual.png` | 시작 몸통과 성장으로 추가되는 몸통 |
| 꼬리 | `Assets/Art/Sprites/PlayerTail_Casual.png` | 실제 플레이어 꼬리 |

생성 지시 요약: 승인된 보라색 비늘·청록색 장식의 탑뷰 뱀을 유지하면서 각 부위를 독립적인 투명 배경 스프라이트로 만들고, 다른 조각과 글자는 제거했다. 꼬리의 첫 결과에는 몸통이 포함돼 단일 꼬리로 다시 생성했다.

3개의 부위 이미지는 색상과 방향을 유지한 상태에서 표시되도록 설정했다. 이미지가 지정되지 않은 적에는 새 플레이어 머리가 자동으로 복사되지 않도록 기존 디버그 이미지를 연결했다. 충돌체는 변경하지 않았다.

## 무기·경험치 보석·평원 바닥

내장 이미지 생성 도구로 승인된 선명한 캐주얼 판타지 화풍의 이미지를 각각 생성했다. 화염 검과 고리는 첫 시안의 가장자리 여유를 늘려 다시 생성했다. 기존 사용자 이미지 파일은 덮어쓰지 않았다.

## 확인 범위

Unity 비대화형 배치는 에셋 연결과 게임 로직을 검사한다. 실제 화면에서의 몸통 접합, 회전 중 가장자리, 배경 대비와 다양한 해상도의 가독성은 아직 직접 확인하지 않았다.
