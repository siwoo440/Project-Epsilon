# 37일차 진행 중: 사수 투사체 독 약화

---

## 변경 내용

- 독 상태 적이 발사하는 일반 사수·시험 보스 투사체에 기존 적 공격력 배율을 적용한다. 같은 부채꼴에서 발사한 투사체는 같은 피해를 사용한다.
- 투사체 피해를 이미 발사 시 고정하는 기존 구조에 맞춰 독 배율도 발사 시점에 고정한다. 기획서에는 독 상태의 발사·피격 시점 우선 규칙이 명시되지 않아 임시 정책으로 기록한다.
- 기존 근접 공격과 같은 정수 올림을 유지한다. 이에 따라 기본 피해 8에 5% 약화를 적용하면 실제 정수 피해는 여전히 8이다. 기획서의 정수 처리 방식은 확인되지 않아 별도 밸런스 결정이 필요하다.
- 실제 보스가 등록되면 보스전 상태를 기록하고, 몸통 복구 API·복구 아이템과 엘리트 복구 후보를 제한한다. 레벨업으로 적용되는 몸통 성장·복구는 그대로 허용한다. 보스전 이전부터 대기하던 다른 엘리트 보상도 유지한다.
- 냉기 시너지 ×4 이상의 감속 지속 시간을 25% 늘리고, ×6 이상의 최대 냉기 누적 이후 추가 명중 시 일반 적에 짧은 빙결을 적용한다. 보스는 같은 조건에서 빙결 대신 별도 강한 감속을 받으며, 효과 종료 후 기존 냉기 감속으로 돌아간다.
- 최대 누적 뒤 필요한 추가 명중 1회, 빙결·강한 감속 1초, 보스 이동 배율 0.5는 기획에서 수치가 확정되지 않은 임시값이며 씬에서 조정할 수 있다. 추가 명중 1회는 기획의 미정 추가 조건을 시험하기 위한 임시 선택이다.
- 보스가 접촉한 몸통을 기록된 이동 경로에서 잠시 밀어내고 다시 경로로 돌아오게 한다. 밀린 몸통에만 자기 충돌 유예를 적용하며, 같은 물리 스텝에서 자기 충돌과 보스 접촉의 순서가 바뀌어도 해당 몸통을 재확인한다. 밀림 거리 0.6, 복귀 0.4초, 유예 0.5초는 씬에서 조정 가능한 임시값이다.
- 유예 후에도 머리와 몸통이 겹쳐 있으면 자기 충돌을 적용한다. 정지한 2D 물리체가 절전 상태로 들어가 지속 접촉 콜백이 중단되는 사례를 확인해 물리 스텝에서 실제 접촉을 확인하고, 같은 스텝에 분리된 몸통은 물리 처리 후 다시 확인해 피해를 막는다.
- 보스가 플레이어 머리 위치에 원형 위험 구역을 예고하고, 예고가 끝나면 일정 간격으로 구역 안의 공용 HP에 피해를 준다. 한 구역에서 머리와 몸통이 함께 닿아도 주기마다 한 번만 피해를 예약하며, 보스 사망 시 남은 구역을 제거한다. 출현 간격 8초, 예고 1초, 지속 3초, 피해 간격 1초, 반경 1.2와 피해 10은 씬에서 조정 가능한 임시값이다.
- 보스가 기존 추적자 구성과 충돌을 재사용해 잡몹을 직접 소환한다. 동시 상한을 지키고 처치된 자리에는 다음 소환이 가능하며, 보스 처치 시 남은 잡몹을 무보상으로 정리한다. 소환 간격 12초, 동시 상한 4마리와 출현 거리 2는 조정 가능한 임시값이고, 소환 적의 무보상은 기획에 확정되지 않은 임시 정책이다.
- 평원의 빈 청크 기반을 추가했다. 플레이어 중심 3×3 범위에서 겹치는 청크를 유지하고 이탈 청크를 제거하며, 재방문 시 새 청크를 만든다. 크기 24는 씬에서 조정 가능한 임시값이다. 장애물 패턴과 특수 지역은 아직 구현하지 않았다.
- 냉기 무기 하나만 장착해도 명중 누적에 따라 기본 감속 10%·20%·30%가 적용된다. ×2의 감속 +15%는 기본 감속량에 1.15배를 곱하는 임시 해석으로 적용하며, 최대 누적과 기존 ×6 빙결·보스 저항을 유지한다. 기획의 15%가 상대 증가인지 퍼센트포인트 증가인지는 확정이 필요하다.
- 사용자가 승인한 캐주얼 일러스트 시안을 바탕으로 플레이어 머리·몸통·꼬리 이미지를 따로 생성해 실제 씬에 연결했다. 별도 꼬리 이미지가 없는 기존 설정에서는 몸통 이미지로 대체하고, 전용 이미지가 없는 적은 기존 디버그 이미지를 유지한다. 전체 조사 결과는 [이미지 현황](ArtInventory.md)에 기록했다.
- 같은 캐주얼 스타일로 추적자·측면 포식자·사수의 탑뷰 이미지를 생성하고 종류별 데이터에 연결했다. 전용 이미지가 없는 적은 기존 이미지와 색상을 유지하며, 전용 이미지가 있는 적은 추적 또는 발사 대상을 바라본다. 보상과 투사체는 기존 공용 이미지를 유지한다.
- 4분 엘리트와 평원 보스의 전용 이미지를 생성해 연결했다. 엘리트 돌진과 보스 예고 중에는 고정된 공격 방향을 바라보고, 보스 투사체는 기존 공용 이미지를 유지한다. 보스 원색과 이미지 회전은 씬 설정으로 조정한다.
- 시험 무기 6종의 이미지, 소·중·대 경험치 보석과 평원 바닥 이미지를 생성했다. 무기 이미지는 실제 장착 몸통과 시작·레벨업 후보에 표시하고, 보석 이미지는 경험치와 병합 결과에 따라 갱신한다. 바닥은 3×3 활성 청크마다 표시한다.

## 검증

- Unity 36일차 사본에서 실제 피해 21 사수의 독 미적용 투사체는 HP 100→79, 독 2단계 적용 후에도 HP 100→79였고 종료 코드 1이었다.

- 사수·출현 독립 회귀 14개와 실제 Unity 보스 부채꼴 사격·투사체 접촉 회귀가 통과했다. Unity Editor Search 시작 인덱싱 예외가 별도로 발생했다.

- 실제 냉기 명중 선행 스크립트 SHA-256 `D5166463B656000C0367C51E7A743F379D2B8A6B46ABB5FE8A51B9867C7EC33A`는 최대 누적 뒤 추가 명중에도 일반 적이 빙결되지 않아 Unity 종료 코드 1이었다. 수정본 최종 스크립트 SHA-256 `72F8F6738C2E7131F11128917969C560E949B0DDE039D4E26FBBEE25F732BC44`는 낮은 단계 감속, 고단계 추가 명중 빙결, 보스 강한 감속과 실제 이동, 지속 시간·추가 명중 설정, 일시정지 및 종료 후 기존 감속 복귀를 확인해 종료 코드 0이었다. 실제 속성 명중을 직접 호출하고 보스를 강제 생성한 통제 시험이다.
