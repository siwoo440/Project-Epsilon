# 38일차 물리·화염 무기 개발 계획

---

## 목표와 기준

기획서 12.2의 물리 6종·화염 6종을 향해 기존 시험 무기 6종을 재사용하고 추가 무기 6종을 임시 데이터로 구성한다. 기획서 11번은 48종의 이름·수치·고유 효과를 미정으로 분류하므로 새 무기명, 수치와 그림은 확정 사항이 아니다. ★3·★5 전용 효과는 42~43일차 범위이며 기존 시험 무기의 효과는 유지한다.

---

## 구현 및 검증

- [x] 기존 실제 씬 무기 시험을 확장해 새 데이터 부재를 확인한다.
- [x] 각 속성에 근접·직선·범위 임시 무기 1종씩을 추가하고 기존 자동 공격·화상·이미지 표시를 재사용한다.
- [x] 레벨업과 엘리트가 공유하는 보상 풀에 새 무기를 등록한다. 시작 무기 후보는 유지한다.
- [x] 실제 몸통의 공격 원점, 공격 간격·피해·명중 대상, 화염 화상과 보상 후보 12종을 Unity 비대화형 배치로 검증한다.
- [x] 기존 등급 효과와 보상 UI 회귀를 확인하고 결과와 미검증 사항을 기록한다.
- [x] 플레이어·일반 적·엘리트·보스의 크기를 두 배로 변경하고 몸통 간격과 경로를 조정한다.
- [x] 경험치 획득량을 유지하면서 소·중·대 보석 이미지만 세 배로 키운다.
- [x] 실제 피해를 받은 적의 일시적인 빨간 표시, 반복 피격 연장과 원래 색상 복구를 검증한다.

기존 37일차 5분 자연 전투는 266.3초 패배였으며 마지막 충돌 종류가 미기록이다. 새 무기 추가와 별도로 추후 계측·재검증이 필요하다. 37일차 Vertical Slice 완료로 간주하지 않는다.
