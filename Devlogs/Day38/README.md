# 38일차: 물리·화염 무기와 피격 표시

---

## 개발 방향

기획서 12.2의 목표는 물리·화염 무기 각 6종의 데이터와 공격 구현이다. 기획서 11번에서 48종의 실제 이름·개별 수치·★3·★5 효과는 미정으로 분류하므로, 기존 시험 무기 6종에 조정 가능한 임시 무기 6종을 더했다. 새 무기는 기존 세 공격 방식과 기존 화상 처리를 재사용하며 새로운 고유 공격이나 최종 밸런스로 확정된 것은 아니다. 전용 ★3·★5 효과의 전체 적용은 각각 42일차와 43일차 목표다.

## 크기와 피격 연출

플레이어의 머리·몸통·꼬리와 일반 적·엘리트·보스의 크기를 두 배로 조정했다. 몸통 연결을 위해 간격과 기록 경로 길이도 두 배로 바꾸었다. 캐릭터와 적 오브젝트의 크기 변경은 충돌체 크기도 바꾸므로 전투 난도와 자기 충돌에 영향을 줄 수 있다.

경험치 보석의 소·중·대 표시 크기는 각각 기존의 세 배로 변경했다. 경험치 값과 흡수·획득 거리는 바꾸지 않았다. 일반 적·엘리트·보스는 실제 양수 피해를 받으면 0.18초 동안 붉게 표시하고 기존 색상으로 복원한다. 표시 중 다시 피해를 받으면 표시 시간이 갱신된다. 치명타로 즉시 파괴되는 적의 마지막 피격 표시는 렌더링되지 않을 수 있다.

## 검증 및 남은 작업

- 실제 Game 씬의 통제 시험에서 무기 12종의 몸통 공격 원점·피해·주기·대상 수·화상과 보상 풀을 확인했다. 이동과 적 출현을 통제하고 고정 표적을 사용한 시험이다.
- 실제 플레이어·일반 적·엘리트·강제 생성 보스의 크기와 세 종류 보석 크기·경험치, 무피해 시 무변경, 피격 색상·반복 피격 연장·원래 색상 복구를 확인했다. 적 생성과 위치를 통제한 시험이다.
- 동시 충돌 우선순위, 경험치 병합, 핵심 이미지, 엘리트 보상, 몸통 성장, 기존 화염탄 등급 효과와 레벨 보상 합성 회귀도 각각 Unity 종료 코드 0이었다. 에디터 Search 시작 인덱싱 예외가 별도로 발생했다.
- 확대 적용 후 최초 자연 전투는 33.3초에 적 직접 충돌로 마지막 몸통을 잃어 종료 코드 1이었다. 시험 조종기가 이전 몸통 간격 0.58과 이전 충돌 위험 거리를 사용함을 확인해 실제 간격과 충돌체 반경을 읽도록 보정했다. 이 불일치가 단독 패배 원인인지는 확인되지 않았다.
- 보정 조종기의 실제 충돌체 거리 계산은 Unity 배치에서 통과했지만 자연 전투 재시험은 36.7초에 레벨 1로 패배해 종료 코드 1이었다. 마지막 몸통 손실은 적 직접 충돌로 기록됐다. 무작위 출현과 자동 조종을 사용하는 두 시험은 확대가 패배에 미친 영향을 단독으로 입증하지 않는다.

37일차 Vertical Slice는 여전히 미완료다. 확대된 충돌 범위의 난도와 5분 생존, 화면상 크기와 연출, 전체 20분 수동 플레이는 확인하지 못했다.
