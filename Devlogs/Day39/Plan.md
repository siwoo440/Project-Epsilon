# 39일차 냉기·전기 무기 개발 계획

---

## 목표

기획서 12.2의 냉기·전기 각 6종을 실제 보상 풀에 추가해 누적 24종의 시험 가능 구성을 만든다. 기획서 11번에서 실제 이름·수치·★3·★5 효과는 미정이므로 기존 공격과 속성 구현을 재사용한 임시 구성으로 명시한다. 기존 시작 무기 후보와 38일차 무기 12종은 유지한다.

---

## 단계

- [x] 실제 Game 씬 시험을 확장해 12개 새 무기와 보상 풀 부재를 먼저 확인한다.
- [x] 기존 공격 형태와 조정 가능한 데이터를 사용해 냉기 6종·전기 6종을 추가한다. 기존 무기 이미지는 임시 대체 이미지다.
- [x] 전기 ×4의 연쇄 대상 +1을 실제 속성 명중 시험으로 검증하고 기존 처리에 반영한다.
- [x] 냉기 감속·빙결과 전기 연쇄, 무기 장착·발사·보상 풀 및 기존 기능을 Unity 비대화형 배치로 검증한다.
- [x] 5분 자연 전투 결과와 수동 화면 미검증을 보고한다.
