# 40일차 독·폭발 무기 개발 계획

---

## 목표

기획서 12.2에 따라 독·폭발 무기를 각각 6종 추가해 기존 24종을 포함한 36종의 시험용 구성을 만든다. 무기별 이름·수치·고유 효과는 기획 미정이므로 임시 데이터로 기록하고 기존 공격 구조를 재사용한다.

---

## 작업과 검증

- [x] 실제 씬의 36종 무기·보상 풀 선행 시험으로 신규 데이터 부재를 확인한다.
- [x] 독·폭발 무기 각각 6종과 승인된 화풍의 속성 대표 이미지를 연결한다.
- [x] 독 최대 5중첩과 폭발 ×4 넉백 거리 20% 증가를 실제 명중 경로로 검증하고 누락된 부분을 수정한다.
- [x] 기존 무기·속성·보상 UI 회귀를 Unity 비대화형 배치로 실행한다.
- [x] 사용자 요청에 따라 사거리와 관계없이 최근접 적을 자동 공격하고 체력·경험치 막대를 표시한다.
- [x] 완료·미완료 항목과 자연 전투 한계를 기록한다.
