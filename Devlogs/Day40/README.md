# 40일차: 독·폭발 무기와 자동 공격

---

## 개발 방향

기획서 12.2의 목표인 독·폭발 무기 각 6종을 시험 데이터로 추가해 누적 36종의 보상 풀을 구성했다. 무기별 실제 이름·수치·고유 효과는 기획 미정이므로 조정 가능한 임시값이다. 기존 근접·직선·범위 공격과 독·폭발 속성 처리를 재사용한다.

---

## 임시 무기

| 형태 | 공격 | 피해 | 주기 | 범위 | 기본 대상 |
| --- | --- | ---: | ---: | ---: | --- |
| 검 | 근접 | 9 | 0.9초 | 1.35 | 근접 1명 |
| 창 | 직선 | 7 | 1초 | 7 | 독 2명 관통, 폭발 1회 기폭 |
| 고리 | 범위 | 6 | 1.4초 | 2.25 | 범위 내 적 |
| 단검 | 근접 | 6 | 0.55초 | 1.1 | 근접 1명 |
| 탄 | 직선 | 8 | 0.85초 | 6 | 독 1명, 폭발 1회 기폭 |
| 파동 | 범위 | 9 | 1.6초 | 2.1 | 범위 내 적 |

폭발 무기는 명중 위치 또는 범위 중심에서 주변 적에게 피해를 준다. 기본 대상은 공격 시작 방식이며 폭발의 주변 피해를 제한하는 숫자가 아니다. 독 최대 중첩을 5로 제한하고, 폭발 ×4의 넉백 거리를 기존 임시값의 1.2배로 적용했다. 보스 넉백 면역은 유지한다.

독 ×4의 방어력 10% 감소와 ×6·×8 고유 효과는 아직 구현하지 않았다. 현재 방어력 수치 대신 독 시너지 활성 시 받는 피해 1.05배를 사용하는 임시 처리다. 폭발 중심 추가 피해도 현재 기본 단계부터 적용되는 임시 처리이며, 기획의 ×6 단계 조건과 ×8 처치 후 2차 폭발은 추가 구현이 필요하다.

## 최근접 공격과 HUD

사용자 요청에 따라 자동 공격은 사거리 밖이라도 각 무기가 장착된 몸통에서 가장 가까운 적을 선택한다. 근접 공격은 선택한 적에 직접 피해를 주고, 직선 투사체는 발사 시점의 목표 방향으로 발사하며 해당 위치까지 도달할 수 있도록 최소 수명을 늘린다. 이동 중인 적을 추적하거나 반드시 명중하는 투사체는 아니다. 범위 무기는 적이 기존 범위에 있으면 몸통 중심을 유지하고, 모두 범위 밖이면 가장 가까운 적 주변을 공격한다. 무기 데이터의 범위는 범위 효과 크기 등에 계속 사용한다.

기존 HUD 텍스트를 유지하면서 체력과 경험치의 현재 비율 막대를 추가했다. 게임 상태 변경 이벤트로 막대를 갱신하고 UI 입력을 가리지 않는다.

## 생성 이미지

기본 제공 이미지 생성 도구로 기존 화염 검 이미지를 화풍 기준으로 삼아 투명 배경의 녹색 독 검과 주황색 기계식 폭발 검을 생성했다. 각각 [독 검](../../Assets/Art/Sprites/WeaponPoisonBlade_Casual.png), [폭발 검](../../Assets/Art/Sprites/WeaponExplosionBlade_Casual.png)에 저장했다. 현재 각 속성의 6개 시험 무기가 해당 속성의 대표 이미지를 공유하며, 무기별 전용 그림은 아직 없다.

## 검증과 남은 작업

- 실제 Game 씬 통제 시험에서 36종 무기의 몸통 원점·주기·명중·보상 풀과 새 이미지 연결을 확인했다. 시험 중 플레이어 이동·자연 적 출현을 중지하고 표적을 배치했다.
- 사거리 밖 근접·직선·범위 무기의 최근접 대상 공격, 쿨타임과 대상 변경, 원거리 폭발 중심, 실제 체력·경험치 이벤트에 따른 막대와 UI 입력 비차단을 확인했다. 적 위치와 플레이어 이동을 통제한 시험이다.
- 실제 독 명중의 최대 5중첩, 폭발 ×4 넉백 거리 0.75→0.9와 보스 넉백 면역을 확인했다. 화염탄 등급·레벨업 보상 합성·엘리트 보상·몸통 HUD·전기 연쇄 회귀도 각각 종료 코드 0이었다.
- 실제 경험치 획득과 레벨업 후 경험치 막대 초기화도 종료 코드 0이었다. Unity Editor Search 시작 인덱싱 예외가 별도로 발생했다.
- 36종 보상 풀과 변경된 자동 공격의 정상 속도 자연 전투는 게임 시간 67.7초에 적 직접 충돌로 패배해 종료 코드 1이었다. 60초 시점에 18처치·경험치 5·레벨 1을 기록했고, 레벨업과 5분 생존은 확인하지 못했다. 가상 입력과 자동 보상 선택을 사용하는 시험이다.

39일차 자연 전투는 76.8초에서 패배했다. 두 회차의 무작위 출현 조건이 달라 결과만으로 변경의 영향을 단독 판단할 수 없다. 화면상 막대와 이미지의 가독성은 Unity 배치에서 직접 확인하지 못했다. 37일차 Vertical Slice와 고단계 속성 효과·최종 무기별 그림·5분 및 20분 자연 전투는 미완료다.
