# 41일차 신성·암흑 무기 개발 계획

---

## 목표

기획서 12.2의 신성·암흑 각 6종을 추가해 물리·화염·냉기·전기·독·폭발과 함께 48종의 시험용 보상 풀을 만든다. 실제 무기 이름·수치·★3·★5 고유 효과는 기획 미정이며, 기존 속성·공격 구조와 새 속성 대표 이미지를 재사용한다.

---

## 작업과 검증

- [x] 실제 씬 48종 시험에서 신규 무기 부재를 먼저 확인한다.
- [x] 신성·암흑 무기 각각 6종과 생성한 대표 이미지를 데이터에 연결한다.
- [x] 실제 몸통 자동 공격과 48종 보상 풀, 기존 신성·암흑 효과를 Unity 배치에서 확인한다.
- [x] 기존 자동 공격·HUD·보상 회귀 및 자연 전투 결과와 남은 항목을 기록한다.
- [x] 사용자 요청에 따라 세 보상 카드가 화면 너비 약 70%를 차지하고 무기 이미지를 두 배로 키운다.
- [x] 일반 적·엘리트·보스의 실제 이동 속도를 절반으로 조정한다.
- [x] 레벨·경험치를 타이머 아래에 배치하고 기존 경험치 위치에 스태미나 막대를 표시한다.
