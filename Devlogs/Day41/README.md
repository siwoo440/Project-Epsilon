# 41일차: 신성·암흑 시험 무기

---

## 개발 방향

기획서 12.2의 신성·암흑 무기 각 6종을 추가해 8개 속성 각각 6종, 총 48종의 시험용 보상 풀을 구성한다. 무기별 실제 이름·수치·★3·★5 고유 효과는 기획서에서 미정이므로 48종 전체를 최종 완성 콘텐츠로 간주하지 않는다.

---

## 임시 무기 구성

신성과 암흑에 각각 검·창·고리·단검·탄·파동 6개 형태를 등록했다. 각 속성의 형태별 피해·주기·사거리는 39일차 냉기·전기 시험 무기와 같은 임시값이며, 기존 근접·직선·범위 공격과 신성·암흑 속성 처리를 재사용한다. ★3·★5 고유 효과는 42~43일차 이후 적용·검증 대상이다.

---

## 생성 이미지

기본 제공 이미지 생성 도구에 기존 화염 검을 화풍 기준으로 전달해 금빛 신성 검과 보라색 암흑 검을 투명 배경으로 생성했다. 각각 [신성 검](../../Assets/Art/Sprites/WeaponHolyBlade_Casual.png), [암흑 검](../../Assets/Art/Sprites/WeaponDarkBlade_Casual.png)에 저장했다. 해당 속성의 6개 시험 무기가 대표 이미지를 공유하며, 형태별 전용 그림은 아직 없다.

---

## 추가 요청 반영

레벨과 경험치 막대를 타이머 아래에 배치하고 레벨은 왼쪽 위, 경험치는 오른쪽 위로 정렬했다. 기존 경험치 위치에는 실제 스태미나에 따라 채워지는 막대를 추가했다. 보상 카드 세 장은 화면 너비의 약 70%를 차지하고 아이콘 크기는 48에서 96으로 확대했다.

일반 적·엘리트·보스의 자발적 이동과 돌진은 기존 속도의 절반이며, 투사체와 외부 밀림은 변경하지 않았다. 공통 배율은 `EnemyMovementRules.SpeedMultiplier`에서 조정한다.

---

## 검증과 남은 작업

- Unity 비대화형 배치에서 실제 씬의 보상 카드 배치·아이콘 크기, 최근접 공격 및 체력·경험치·스태미나 막대, 일반 적·엘리트·보스의 절반 속도, 48종 시험 무기 및 신성·암흑 효과를 확인했다. 각각 종료 코드 0이다. 플레이어·적 위치와 공격 조건을 통제한 시험이다.
- 독·폭발 속성, 레벨업 보상과 합성, 엘리트 보상, 보스 돌진, 사수, 냉기, 기존 아트 회귀도 각각 종료 코드 0이다. 보스 시험은 처음에 연속 시나리오 사이 이전 접촉이 남아 실패했고, 물리 스텝을 두어 접촉을 분리한 뒤 몸통과 머리 진입 및 절단·무적을 확인했다.
- Unity Editor Search의 시작 인덱싱 예외가 각 실행에서 별도로 발생했다. 게임 시험의 종료 코드와 구별해 기록한다.
- 적 속도 조정 후 정상 속도 자동 조종 자연 전투는 129.0초에 패배해 종료 코드 1이었다. 120초 시점에 25처치·경험치 3·레벨 1을 기록했고 자연 레벨업, 4분 엘리트 및 5분 생존은 확인하지 못했다. 가상 입력과 자동 보상 선택을 사용하는 시험이며 수동 플레이는 아니다.
- 사용자 화면에서 배치와 이미지의 가독성은 직접 확인하지 못했다. 최종 무기별 고유 효과 및 전용 이미지와 5분 자연 전투 검증은 남았다.
