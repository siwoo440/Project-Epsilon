# 42일차: 3등급 시험 효과

---

## 개발 방향

기획서의 무기별 최종 3등급 고유 효과가 정해지지 않아 48종 시험 무기에 공격 유형별 공통 임시 효과를 데이터로 연결했다. 이는 48종의 서로 다른 최종 고유 효과가 아니다.

| 공격 유형 | 3등급 임시 효과 | 조정 위치 |
| --- | --- | --- |
| 근접 | 최근접 적 2명 공격 | 무기 데이터 `gradeThreeMeleeTargetLimit` |
| 직선 투사체 | 최초 명중 지점 주변 최근접 적에게 추가 전달 | 무기 데이터 `gradeThreeTransferRange`, `gradeThreeTransferDamageMultiplier` |
| 범위 | 실제 피해 및 표시 범위 1.25배 | 무기 데이터 `gradeThreeAreaRangeMultiplier` |

직선 무기의 기본 전달 임시값은 반경 2, 피해 배율 0.5다. 기존 화염탄의 반경 2·피해 배율 1과 강철 검의 2명 공격은 유지했다. 1·2등급에는 새 효과가 적용되지 않는다. 기존 속성 효과와 합성 시스템을 재사용한다.

---

## 검증과 남은 작업

- 구현 전 3등급 범위 설정 부재를 확인한 시험은 종료 코드 1이었다. 수정 후 실제 보상 풀의 48개 무기를 각각 3등급으로 장착해 통제된 두 표적에 공격하고 데이터 설정을 확인한 시험은 종료 코드 0이었다. 근접·직선·범위 대표 무기는 2등급과 3등급 동작을 비교했다. 폭발 속성의 추가 피해가 두 표적에 영향을 줄 수 있으므로 이 시험만으로 무기별 최종 고유 효과를 입증하지 않는다.
- 기존 1등급 48종 공격·보상 풀, 화염탄 등급·화상·전달·관통, 최근접 공격과 HUD, 레벨업 합성, 신성·암흑 효과 회귀는 각각 종료 코드 0이었다. 플레이어 이동과 적 출현·표적 위치를 통제했다.
- 다른 무기의 전달을 금지하던 기존 화염탄 시험은 새 임시 기획과 달라 처음 실패했다. 해당 조건을 전달을 끈 강철 창의 시험 사본으로 바꾼 재시험에서 전달 비활성과 기존 화염탄 동작을 확인했다.
- Unity Editor Search 시작 인덱싱 예외가 별도로 발생했다. 무기별 최종 효과·수치와 전용 이미지가 필요하고, 41일차 자동 조종 자연 전투의 5분 생존 및 자연 레벨업은 아직 확인되지 않았다. 42일차 자연 전투는 별도로 실행하지 않았다.
