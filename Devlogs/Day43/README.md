# 43일차: 5등급 시험 효과

---

## 개발 방향

기획서의 무기별 최종 5등급 고유 효과가 정해지지 않아 48종 시험 무기에 공격 유형별 공통 임시 효과를 데이터로 연결했다. 이는 48종의 서로 다른 최종 고유 효과가 아니다.

| 공격 유형 | 5등급 임시 효과 | 조정 위치 |
| --- | --- | --- |
| 근접 | 서로 다른 최근접 적 최대 3명 공격 | `gradeFiveMeleeTargetLimit` |
| 직선 투사체 | 3등급 전달 피해 배율에 1.5배 적용 | `gradeFiveTransferDamageScale` |
| 범위 | 실제 피해 및 표시 범위 기본의 1.5배 | `gradeFiveAreaRangeMultiplier` |

1~4등급과 기존 3등급 효과는 유지한다. 직선 무기의 전달 거리와 배율은 발사 시 확정하며 이후 데이터 변경의 영향을 받지 않는다. 효과 및 수치는 최종 밸런스가 아니다.

---

## 검증과 남은 작업

- 구현 전 5등급 전달 배율 설정 부재를 확인한 시험은 종료 코드 1이었다. 수정 후 48개 무기를 각각 5등급으로 장착해 통제된 표적에 공격하고 데이터 설정을 확인한 시험은 종료 코드 0이었다. 대표 근접·직선·범위 무기는 4등급과 5등급 동작을 비교했다.
- 48종 3등급 공격, 화염탄 등급·화상·전달·관통, 최근접 공격과 HUD, 레벨업 합성, 신성·암흑 속성 회귀는 각각 종료 코드 0이었다. 화염탄 시험에서 5등급 발사 후 데이터 배율을 바꿔도 발사 시 배율의 전달 피해가 유지됨을 확인했다.
- 시험은 플레이어 이동과 적 출현·표적 위치를 통제했다. Unity Editor Search 시작 인덱싱 예외가 별도로 발생했다. 무기별 최종 고유 효과·수치와 전용 이미지, 5분 자연 생존 및 레벨업 확인은 남았다. 이번 일차의 자연 전투는 별도로 실행하지 않았다.
