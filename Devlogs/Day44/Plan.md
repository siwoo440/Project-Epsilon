# 44일차 캐릭터 시험 데이터와 적용 계획

---

## 기획 기준

기획서 7.1의 캐릭터는 균형형 3칸·HP 100, 기동형 3칸·HP 85, 중장형 4칸·HP 125, 합성형 3칸·HP 95, 신성 특화형 3칸·HP 100, 암흑 특화형 3칸·HP 90이다. 전원 절대 최대 20칸이며 캐릭터별 시작 무기 후보 3종과 상시 패시브 1개를 가진다. 이동·회전 보정 범위는 각각 기본 대비 ±10%·±15%다.

---

## 임시 해석

세부 보정률과 후보 목록은 미정이므로 데이터의 조정 가능한 시험값으로 둔다. 기동형은 이동 1.1·회전 1.15와 스태미나 회복 강화, 중장형은 이동 0.9·회전 0.85와 HP 피해 경감, 합성형은 보유 무기 후보 가중치 증가, 신성형은 신성 공격과 회복 효율 강화, 암흑형은 저주 대상 처치 회복 강화다. 균형형 패시브는 기본형을 유지하는 작은 스태미나 회복 보정의 시험값이다. 신성·암흑은 해당 속성 후보 가중치를 높인다.

---

## 작업

- [x] 여섯 캐릭터와 각각 중복 없는 시작 무기 후보 3종의 데이터를 만든다.
- [x] 시작 상태에서 선택한 캐릭터 데이터를 실제 몸통·공용 HP·이동·회전·스태미나·시작 무기 선택에 연결한다. 시작 무기 화면에 좌우 방향키 순환을 제공하고 전용 캐릭터·해금 화면은 후속 작업으로 남긴다.
- [x] 패시브와 무기 후보 가중치를 기존 전투·회복·후보 추첨에 연결하고, 캐릭터 이동 보정이 적 속도를 바꾸지 않도록 검증한다.
- [x] Unity 배치에서 실제 여섯 캐릭터의 시작 능력치·후보·패시브와 기본 캐릭터 회귀를 확인한다.
- [x] 사용자 요청에 따라 몸통 위 무기를 포탑으로 표현하고 각 몸통의 최근접 적을 계속 바라보게 한다.
- [x] 플레이어 몸통과 꼬리 시각 크기, 머리와 몸통의 실제 충돌 범위를 기존의 절반으로 줄이고 자연 전투 및 충돌 회귀를 검증한다.
- [x] 시험용 무기 이름을 포탑 이름으로 바꾸고 기획서와 게임 데이터를 일치시킨다.
- [x] 실제 시험 결과와 기획 미확정 항목을 기록한다.

---

## 검토 조건

- 캐릭터 적용은 런 시작 시에만 처리해 진행 중의 몸통·HP·무기와 보상을 초기화하지 않는다.
- 캐릭터를 지정하지 않으면 기본 균형형을 사용한다. 세 후보는 실제 무기 에셋이고 같은 화면에 중복되지 않는다.
- 빈 가중치·완성된 무기·시너지·회복이 불가능한 상황은 기존 선택과 회복 규칙을 유지한다.
- 자동 플레이 결과와 실제 사용자 플레이를 구별하고 기획에 없는 효과를 최종 확정으로 표시하지 않는다.
