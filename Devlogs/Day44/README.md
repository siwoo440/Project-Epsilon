# 44일차: 캐릭터 시험 데이터와 포탑

---

## 캐릭터

기획서 7.1의 시작 몸통·공용 HP와 이동·회전 보정 범위를 반영했다. 패시브 수치와 후보 무기는 기획 미정 시험값이며 캐릭터 데이터에서 조정한다. 모든 캐릭터의 절대 최대 몸통은 20이다.

| 캐릭터 | 시작 몸통 / HP | 이동 / 회전 배율 | 상시 패시브 시험값 |
| --- | --- | --- | --- |
| 균형형 | 3 / 100 | 1.0 / 1.0 | 스태미나 회복 1.05배 |
| 기동형 | 3 / 85 | 1.1 / 1.15 | 스태미나 회복 1.25배 |
| 중장형 | 4 / 125 | 0.9 / 0.85 | 공용 HP 피해 0.9배 |
| 합성형 | 3 / 95 | 1.0 / 1.0 | 장착 중인 무기의 레벨업·엘리트 후보 가중치 2배 |
| 신성 특화형 | 3 / 100 | 1.0 / 1.0 | 회복 효율 1.25배, 신성 피해 1.1배, 신성 후보 가중치 2배 |
| 암흑 특화형 | 3 / 90 | 1.0 / 1.0 | 기존 저주 적 처치 회복 발동 시 회복량 2배, 암흑 후보 가중치 2배 |

각 캐릭터에 중복 없는 고정 시작 무기 후보 3개를 연결했다. 시작 상태에서 선택한 캐릭터를 실제 몸통·슬롯·체력·이동·회전·회복 및 후보 화면에 반영하고, 시작 무기 확정 뒤 런 중에는 캐릭터를 바꾸거나 상태를 초기화할 수 없다. 기본 캐릭터는 균형형이다. 시작 무기 선택 화면의 좌우 방향키로 여섯 캐릭터를 순환하고 표시된 몸통·HP와 무기 후보를 확인할 수 있다. 현재 여섯 캐릭터는 시험용으로 모두 선택 가능하다. 전용 캐릭터 선택·해금 UI와 해금·저장은 아직 구현하지 않았으며 후속 화면에서 사용할 다음 런 선택 API를 제공한다.

## 포탑과 크기

무기 48종의 이름을 시험용 포탑 이름으로 바꾸고 기획서의 목록과 일치시켰다. 기존 무기 식별자와 공격 데이터는 유지한다. 기존 승인 화풍을 참고해 투명 배경의 공용 포탑 이미지를 생성하고 무기 데이터와 보상 화면에 연결했다. 여덟 속성은 색상으로 구분한다. 현재 48종은 한 포탑 이미지를 공유하므로 무기별 전용 형상과 아이콘은 아직 없다.

각 포탑은 자신이 장착된 몸통의 최근접 적을 매 프레임 바라본다. 몸통이 회전해도 포신의 월드 방향이 조준을 따라가며 적이 없으면 마지막 방향을 유지한다. 플레이어 몸통과 꼬리 표시 크기, 머리와 몸통의 실제 월드 충돌 반경은 이전의 절반으로 조정했다. 몸통 간격도 절반으로 줄였다. 적의 표시 크기와 적의 충돌체는 유지한다. 기동형·중장형의 플레이어 이동 배율이 적 추적 속도까지 바꾸지 않도록 적은 캐릭터 보정 전 기본 이동 속도를 기준으로 계산한다.

## 검증과 남은 작업

- Unity 6000.3.21f1 비대화형 배치에서 6개 캐릭터의 시작 몸통·HP·이동·회전·스태미나·후보와 패시브, 진행 중 캐릭터 변경 차단을 확인했다. 실제 좌우 방향키로 여섯 캐릭터를 순환하고 설정 화면이 열린 동안 입력이 차단되며 선택한 캐릭터의 무기로 시작하는 시험도 종료 코드 0이다.
- 각 몸통의 최근접 적 조준·이동 중 목표 변경·대상 없는 방향 유지, 포탑 이미지와 속성 색상, 축소된 플레이어 월드 충돌 반경·몸통·꼬리·간격을 실제 씬에서 확인했다. 시작 무기, 카드 배치, 최근접 공격·HUD, 48종 무기 공격과 5등급, 레벨업 합성·엘리트 보상·동시 충돌·보스 돌진 회귀도 종료 코드 0이다.
- 캐릭터 도입 직후 적 추적 속도가 캐릭터 이동 배율을 따라가는 결함을 실제 물리 시험에서 확인했다. 기동형에서 적 속도가 1.32로 측정된 선행 시험은 종료 코드 1이었다. 수정 후 기동형·중장형 모두 적의 기준 속도 1.2를 유지하고, 일반 적·엘리트·보스의 절반 속도를 확인해 각각 종료 코드 0이었다.
- 포탑과 크기 변경 후 캐릭터 기능 적용 전 자연 전투는 실제 게임 시간 339.3초에 종료 코드 0, 레벨 10·197처치·엘리트 보상 선택 1회를 기록했다. 당시 자동 조종기는 합성 재료 화면에서 이전 버튼을 반복했고 이후 화면이 닫혀 검증이 끝났다. 조종기의 재료 확정 버튼 선택을 고친 별도 실제 합성 시험은 종료 코드 0이었다.
- 캐릭터 기능 적용 후 다른 자연 전투는 121.9초에 패배해 종료 코드 1이었다. 120초에 26처치·레벨 1·경험치 3을 기록했다. 무작위 조건이 다른 자동 조종 결과이며 수동 플레이가 아니다. 적 속도 보완 후 마지막 자연 전투는 86.6초에 패배해 종료 코드 1이었다. 60초에 12처치·레벨 1·경험치 1을 기록했다. 두 최종 구성 시험 모두 자연 레벨업·4분 엘리트·5분 생존을 확인하지 못했다.
- Unity Editor Search 시작 인덱싱 예외가 별도로 발생했다. 기획서의 무기별 최종 등급 효과·수치, 48종 개별 포탑 그림, 전용 캐릭터·해금 화면, 해금 저장 및 사용자 수동 플레이 확인은 남았다.
