# 45일차 초반 자연 전투 검증 계획

---

## 기준과 제한

최신 기획서 12.2의 45일차는 초반 자연 전투의 적 출현·피해·포탑 사거리·경험치 획득을 기록하고 자연 레벨업, 4분 엘리트, 5분 생존을 재검증하는 작업이다. 컴퓨터 사용 금지 지시에 따라 사용자 수동 플레이는 진행하지 않고 Unity 비대화형 실제 씬 시험과 통제 시험으로 구분해 기록한다.

사용자 지시인 적 이동속도 절반과 사거리와 관계없는 최근접 적 자동 공격을 유지한다. 보석의 경험치 값, 성장 공식과 기본 조작은 임의로 변경하지 않는다. 시험 조종기의 성과와 실제 사용자의 조작 성과를 구분한다.

---

## 절차

- [x] 기존 자동 조종기의 속도·포탑 사거리 가정과 실제 런타임을 비교하고 변경 전 고정 시드 시험을 기록한다.
- [x] 실제 동작과 맞지 않는 시험 조종기 가정을 검증한 뒤 보정하고 같은 시드로 다시 시험한다. 보정은 제품 기능과 별도이며 플레이어 능력치·면역·게임 속도를 강제 변경하지 않는다.
- [x] 보석 흡수와 적 출현·피격·포탑 공격을 실제 씬 또는 통제 시험에서 확인한다. 동적 생성 보석의 획득 범위·속도·거리 조정이 가능하도록 데이터 연결을 확인하고 측정 결과를 바탕으로 추가 조정 필요성을 기록한다.
- [x] 실제 자연 전투에서 생존 시각·레벨·처치·XP·4분 엘리트·보상과 실패 원인을 기록하고 목표 미달을 명시한다.
- [x] 해당 변경에 필요한 Unity 회귀를 실행하고 차이를 기록한다. 45일차 변경만 커밋·푸시한다.

---

## 검토 항목

- 고정 시드는 무작위 순서를 통제하며 프레임 타이밍까지 완전히 재현한다는 뜻은 아니다.
- 적이 사거리 밖이어도 포탑은 최근접 적에 공격을 시도하지만 직선 탄이 이동하는 목표를 반드시 명중하는 것은 아니다.
- 자연 전투의 생존 결과는 자동 입력 정책과 무작위 조건에 영향을 받으므로 수동 플레이 및 전체 밸런스 검증으로 확대하지 않는다.
