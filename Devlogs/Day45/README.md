# 45일차 초반 자연 전투

---

## 범위와 기준

최신 기획서 12.2의 45일차는 초반 자연 전투의 출현, 피해, 포탑 공격과 경험치 획득을 확인하고 4분 엘리트와 5분 생존을 재검증하는 작업이다. 선행 44일차 커밋은 `abd1338385abffa963865a66811e5ed8ca4dd79b`다. 실제 사용자의 수동 조작은 컴퓨터 사용 금지 지시에 따라 실시하지 않았다.

Unity 6000.3.21f1의 별도 프로젝트 사본에서 게임 속도 1배, 자연 출현, 가상 A/D·Space 입력, 자동 보상 선택을 사용했다. 임의 피해, 경험치, 무적, 시간 가속은 주입하지 않았다. 시드 4501은 난수 초기 상태만 지정하며 프레임 타이밍과 이후 난수 호출 순서까지 같다는 뜻은 아니다. 기록한 처치 수는 시험 조종기가 관측한 이벤트 수다.

실제 씬의 임시값은 적 생성 간격 1.5초, 최대 40마리다. 추적자·포식자·사수·엘리트의 등장 가능 시점은 각각 0·60·120·240초, 체력은 25·35·20·160, 피해는 10·12·8·15, 경험치는 1·2·2·20이다. 경험치 2인 일반 적은 1짜리 보석 2개로 나누어 드롭한다. 적 이동속도 절반과 무제한 사거리의 최근접 적 공격은 기존 사용자 지시대로 유지했다.

---

## 확인한 원인과 변경

- 이전 자동 조종기는 적 속도를 플레이어 현재 속도의 0.8배로 예측해 실제 적별 속도 비율, 적 속도 절반과 상태 효과를 반영하지 않았다. 또 멀리 뒤처진 적을 향해 다시 접근하고 첫 포탑이 적에게 가까워지는 경로를 선호했다. 포탑은 사거리 제한 없이 공격하므로 이 조향 가정은 현재 게임 규칙과 다르다. 이것만이 과거 패배의 원인이라고 단정하지 않는다.
- 조종기에서 불필요한 적 재접근 가중치를 제거하고 적별 실제 설정과 속도 배율을 이용하도록 수정했다. 방향 예측은 단순한 머리 추적 근사이므로 사수 행동, 몸통 추적과 엘리트 돌진까지 정확히 재현하지 않는다. 제품 플레이어 조작이나 능력치는 바꾸지 않았다.
- 실제 경험치 보석의 흡수 범위·속도·획득 거리를 `PrototypeExperiencePickupSettings` 에셋으로 분리하고 게임 씬에 연결했다. 기존 기본값 2.6·6·0.22는 유지한다. 새 보석이 생성될 때 설정을 읽으며, 이미 생성된 보석은 기존 설정을 유지한다. 경험치 수량과 보석 크기는 변경하지 않았다.
- 통제 시험에서 실제 움직이는 머리에 보석이 수집되고 일시정지 중 멈추는 것을 확인했다. 자동 조종기 재접근 시험은 수정 전 실패, 수정 후 통과했다. 보석 설정 시험도 수정 전 설정 부재로 실패하고 수정 후 새 보석 이동과 경험치 보존을 확인했다.

---

## 변경 전 자연 전투

시드 4501의 기존 조종기는 156.0초에 첫 자연 레벨업과 보상 선택을 기록했다. 240초에 엘리트 출현과 피격을 관찰했으며 270초까지 엘리트 보상을 한 번 선택했다. 300.0초에 레벨 12, 잔여 경험치 1, 관측 처치 161, 몸통 14, 공용 HP 100을 기록하고 종료 코드 0이었다. 5분 레벨 12는 기획서의 시험 목표인 Lv.5~7보다 높다.

---

## 수정 후 자연 전투

같은 초기 시드 4501의 수정된 조종기는 75.1초에 첫 자연 레벨업과 보상 선택을 기록했다. 240초에 엘리트가 출현했고 241.81초에 자연 처치됐다. 270초 시점 엘리트 보상 선택은 1회였다. 300.0초에 레벨 12, 잔여 경험치 23, 관측 처치 195, 몸통 14, 공용 HP 100, 엘리트 보상 1회를 기록했으며 생존·자연 성장·엘리트 출현 시험의 종료 코드는 0이었다. 두 결과 모두 기획서의 5분 Lv.5~7 목표를 초과한다.

시드가 같더라도 조향과 프레임에 따라 이후 난수 호출이 달라지므로 두 실행의 처치 수와 레벨 차이만으로 조종기 변경의 효과를 단정할 수 없다. 레벨 목표는 소수 자동 조종 표본과 수동 플레이의 차이를 고려해 추가 측정한 뒤 조정한다.

---

## Unity에서 직접 확인할 사항

- 실제 사람이 기본 조작으로 플레이할 때 5분 생존과 레벨 5~7 목표, 보석의 시인성과 수집 느낌을 확인한다.
- 화면에서 엘리트 예고·피격·보상 카드 및 포탑 조준과 탄의 가독성을 확인한다.
- 20분 생존, 최종 보스 전환과 승리의 실제 전체 플레이를 확인한다.
- 46일차의 세 맵과 세 보스 작업에 앞서 맵별 차이와 보스 단계의 실제 플레이를 검토한다.

## 배치 회귀 결과

| 시험 | 결과 |
| --- | --- |
| 자동 조종 방향, 움직이는 머리의 보석 수집, 보석 설정과 씬 연결 | 각각 종료 코드 0 |
| 보석 병합 및 부분 그룹 | 최종 재시험과 부분 그룹 각각 종료 코드 0 |
| 레벨 보상과 합성, 사거리 무관 공격과 HUD | 각각 종료 코드 0 |
| 적 이동속도 절반, 초반 웨이브와 엘리트 보상 | 각각 종료 코드 0 |
| 48종 포탑 공격과 세 일반 적 경험치 | 종료 코드 0 |

보석 병합 경계 시험은 최초 종료 코드 1이었다. 파괴한 보석은 실제로 제거됐으며 직후 소형 보석 4개가 남았지만, 다음 검사 동안 시험 위치에서 떨어진 곳에 보석 1개가 새로 생겨 전체 개수 조건을 어겼다. 원래 시험은 출현기를 끄더라도 이미 생성된 적과 포탑은 남겨두었다. 이들을 시험 시작 시 격리한 뒤에는 같은 파괴 경계와 전체 병합 시험이 종료 코드 0이었다. 추가 보석의 생성 출처는 확정하지 않았다. 초기 실패와 수정 후 결과를 구분한다.

일부 Unity 실행에서 에디터 Search 시작 인덱싱 `ArgumentOutOfRangeException`이 별도로 기록됐다. 위 결과는 각 테스트의 자체 판정과 프로세스 종료 코드를 기준으로 했다.
