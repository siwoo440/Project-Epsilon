# 46일차 맵과 보스 구현 계획

---

## 목표와 제약

세 맵을 시작 화면에서 선택하고 각 맵의 3×3 청크, 장애물·특수 지역과 해당 맵의 시험 보스를 연결한다. 기존 평원과 보스 구성은 재사용하고 기존 이동·공격·경험치·엘리트 규칙을 보존한다. 확정되지 않은 이름과 확률, 효과·보스 수치는 임시값으로 분리한다. 수동 플레이는 컴퓨터 사용 금지 지시에 따라 수행하지 않는다.

---

## 구현 및 시험

- [x] 실제 게임 씬의 세 맵 선택, 맵 데이터, 3×3 청크와 맵별 보스 연결을 검증하는 실패 시험을 작성한다.
- [x] 기존 시작 선택과 청크·보스 구조를 확장하고 신규 맵 바닥 이미지를 연결한다.
- [x] 사전 배치 장애물 패턴과 중첩 방지 특수 지역을 구현하고 실제 피해·회복·감속·경험치 효과를 통제 시험한다.
- [x] 세 맵 보스의 출현과 50% 단계, 기존 공격 기능의 통제 시험 및 관련 회귀를 실행한다.
- [x] 데이터·출현·전투 시험 결과와 미완료 기획·화면 검증을 구분해 기록하고 커밋·푸시한다.

---

## 구현 선택

맵 프로필을 데이터 에셋으로 보유하고 시작 화면의 위·아래 키로 선택한다. 보스는 현재 시험 보스의 검증된 사격·돌진·위험·소환 구조를 재사용하되 맵 프로필의 임시 수치와 표시 색상으로 구분한다. 별도 최종 외형과 고유 패턴은 기획서상 미확정이므로 완성된 것으로 표시하지 않는다. 최초 맵은 평원을 유지한다.
