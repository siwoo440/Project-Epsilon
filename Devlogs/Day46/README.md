# 46일차 세 맵과 시험 보스

---

## 개발 방향과 기존 상태

최신 기획서의 46일차는 세 맵의 테마·청크·특수 지역 확률과 맵별 보스 데이터를 점검하고 출현과 전투 동작을 구분해 시험하는 작업이다. 기존 게임에는 평원 바닥의 3×3 청크와 사격·돌진·위험 지역·소환을 공유하는 시험 보스가 있었다. 장애물, 특수 지역과 세 맵의 실제 시작 선택은 연결되지 않았다.

---

## 추가한 시험 구성

- 시작 화면에서 위·아래 방향키로 평원, 폐허, 습지를 고른다. 시작 후에는 맵을 바꿀 수 없다. 기존 좌·우 캐릭터 선택과 무기 선택을 유지한다.
- 세 맵의 바닥, 장애물·지역 확률, 지역 반경·효과, 보스 체력·이동·사격 설정을 `Assets/Data/World`의 맵별 데이터로 관리한다. 맵별 보스는 기존 동작을 공유하며 표시 색상과 임시 체력·이동·발사 수가 다르다.
- 청크는 기존 3×3 생명주기를 유지하며, 사전 배치된 두 장애물의 위치를 맵별 확률로 생성한다. 장애물은 기존 장애물 충돌 판정을 이용한다. 특수 지역은 청크별 확률과 지역 간 최소 간격을 적용한다.
- 감속, 경험치 증가, 위험 피해와 체력 회복 지역을 추가했다. 감속과 경험치 효과는 머리 위치를 기준으로 하며 위험 지역은 머리 또는 몸통 접촉을 한 번의 피해로 처리한다. 피해는 기존 충돌 우선순위 처리기에 예약한다.
- 폐허와 습지 바닥 이미지는 기존 평원 이미지를 화풍 참고로 내장 이미지 생성 도구에서 각각 제작하고 맵 프로필에 연결했다. 장애물과 특수 지역 표시는 임시 도형이다.

---

## 임시값

| 구분 | 평원 | 폐허 | 습지 |
| --- | --- | --- | --- |
| 장애물 패턴 생성 확률 | 12% | 32% | 22% |
| 특수 지역 생성 확률 | 12% | 18% | 30% |
| 보스 HP | 600 | 700 | 650 |
| 보스 발사 간격 | 2초 | 1.8초 | 2.2초 |
| 보스 1·2단계 발사 수 | 3·5 | 3·5 | 4·6 |

지역 반경 2.5, 감속 0.7배, 경험치 1.5배, 피해 5·회복 2와 주기 2초는 모두 시험값이다. 최종 명칭, 지역 확률과 보상, 맵별 고유 보스 외형과 패턴·수치는 확정되지 않았다.

---

## 실행한 검증

Unity 6000.3.21f1의 별도 프로젝트 사본에서 시험했다. 각 맵을 따로 시작해 실제 3×3 바닥, 확률 100%로 통제한 장애물 패턴과 특수 지역, 맵별 보스 체력·출현·1단계 사격·50% 경계·2단계 사격을 확인했다. 세 시험의 종료 코드는 각각 0이다. 보스 출현과 피해, 플레이어 위치는 시험에서 통제했다.

장애물·특수 지역 확률 100% 시험에서는 9개 청크에 장애물 충돌체 18개와 떨어진 지역 9개가 생성됐고, 확률 0%에서는 생성되지 않았다. 실제 생성 장애물에 머리를 접촉시켜 공용 HP 피해와 무적도 확인했다. 네 지역의 실제 감속·경험치 보너스·위험 피해·회복, 일시정지와 효과 제거 시험도 종료 코드 0이었다.

경험치 지역의 첫 시험 구현은 경험치 1을 매번 올림해 1.5배가 실제 2배가 되는 경계 시험에서 종료 코드 1이었다. 소수 보너스를 누적하도록 수정한 후 통과했다. 작은 보석 두 개의 실제 수집과 성장 초기화도 확인했다.

시작 화면 맵·캐릭터 입력, 설정 화면 입력 우선, 기존 3×3 청크, 20분 가속 보스 전환·승리, 보스 사격·위험 구역·돌진, 적 이동속도 절반, 무제한 사거리 공격과 HUD, 기존 경험치 보석 설정·병합 회귀는 각각 종료 코드 0이었다. 보스 전환 시험은 시간을 가속하고 보스를 강제 처치한 통제 시험이다.

정상 속도의 평원 자연 전투는 난수 초기 시드 4501, 가상 입력과 자동 보상 선택으로 실행했다. 73.9초 첫 자연 레벨업, 241.66초 엘리트 처치, 엘리트 보상 선택 1회를 기록했다. 300.0초에 레벨 13, 잔여 XP 14, 관측 처치 201, 몸통 15, HP 100으로 종료 코드 0이었다. 5분 목표 Lv.5~7은 초과했다. 시드는 프레임이나 이후 모든 난수 순서까지 고정하지 않는다.

## 남은 작업과 직접 확인

- 폐허·습지 전용 보스의 고유 외형과 최종 공격 패턴은 미정이다. 현재는 공통 시험 보스에 맵별 데이터와 색상을 적용한다.
- 맵별 실제 적 출현 풀, 충분히 다양한 장애물 패턴과 위험·보상 밸런스, 최소 통로 폭의 플레이 검증이 필요하다. 특수 지역 접근 표시·미니맵은 구현되지 않았다.
- 세 맵 모두 실제 사람이 5분 이상 조작하고 맵 선택 문구, 바닥 경계, 장애물과 지역의 가독성, 보스전의 조작감을 확인해야 한다. 컴퓨터 사용 금지 지시에 따라 수동 플레이와 화면 렌더 검증은 수행하지 않았다.
- 20분 전체 자연 플레이, 보스 평균 2~4분 전투, 엘리트와 맵별 최종 보상의 균형은 별도로 검증해야 한다.
- 다음 47일차는 48종 시험 포탑의 ★3·★5 고유 효과와 최종 수치를 점검하고 확정된 항목을 순차 반영하는 작업이다.

기획서의 새 이미지 현황 탭에는 확인된 이미지 25개를 삽입했다. Google Drive PDF 내보내기는 403으로 거부되어 문서의 실제 페이지 배치는 확인하지 못했다. 일부 Unity 실행에는 에디터 Search 시작 인덱싱 예외가 별도로 기록됐다.
