# 47일차 포탑 효과·머리 크기·탄 시각화 계획

---

## 목표

48종 포탑의 속성·공격 방식·임시 등급 효과를 대조한다. 기획서 예시인 강철 근접 포탑의 ★5 주기 강타와 화염탄 포탑의 ★5 화상 처치 폭발을 시험 구현하고 다른 포탑은 공통 임시 효과를 유지한다. 미정 수치와 구현 상태를 확정 사양과 구분한다.

머리와 몸통의 최대 표시 크기를 각각 1 Unity 단위로 맞추되 실제 머리 변환과 충돌체는 보존한다. 직선 투사체에 별도 탄 이미지를 표시하고 근접·범위 공격에는 몸통에서 목표까지 날아가는 시각 효과를 추가한다. 근접·범위 피해는 기존 즉시 판정을 유지한다.

---

## 절차

- [x] 각 포탑 데이터·등급 효과를 검토하고 두 고유 효과의 발동·종료·중복 경계를 테스트한다.
- [x] 강철 근접 ★5의 4회마다 1.5배 강타와 화염탄 ★5의 화상 적 처치 반경 2·피해 0.5배를 데이터의 시험값으로 구현한다. 두 예시 외 포탑은 기존 임시 효과를 유지한다.
- [x] 실제 씬에서 머리 이미지와 몸통의 최대 표시 크기를 각각 1로 맞추고 기존 충돌 크기 보존을 확인한다.
- [x] 기존 직선 탄의 실충돌을 유지하면서 포탑 속성 색상 탄을 표시하고, 기존 즉시 공격에 시각 전용 비행 연출을 적용한다.
- [x] 고유 효과, 머리, 투사체, 48종 기존 공격·합성·속성 회귀를 비대화형 Unity에서 검증한다. 미확정 효과와 수동 화면 검증을 기록한다.
- [x] 47일차 파일만 커밋하고 원격에 푸시한다.
