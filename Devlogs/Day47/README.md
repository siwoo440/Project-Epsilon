# 47일차 포탑 효과와 탄 표시

---

## 방향과 기존 상태

기획서의 47일차는 48종 포탑의 공격·속성과 ★3·★5 효과를 점검하고 확정된 고유 효과를 순차적으로 반영하는 작업이다. 46일차까지 48종은 속성 8개별 6종, 공격 유형별 16종이며 ★3·★5는 대부분 공격 유형별 공통 시험 효과였다. 무기별 최종 이름·수치·효과는 기획서상 미확정이다. 실제 보상 풀 48종의 현재 값과 구현 상태는 `TurretInventory.md`에 정리했다.

---

## 추가한 ★5 시험 효과

| 포탑 | 기획 예시 | 이번 시험 구현 |
| --- | --- | --- |
| 강철 근접 | 일정 횟수마다 넓은 강타 | 일반 공격은 최근접 2명, 네 번째 공격은 첫 대상 중심 반경 2에 피해 1.5배 |
| 화염탄 | 화상 적 처치 시 작은 화염 폭발 | ★5 화염탄에 맞아 화상 중인 적이 죽으면 반경 2에 해당 공격 피해의 0.5배 |

위 수치와 세부 동작은 시험값이며 최종 기획 확정이 아니다. 강타 횟수는 장착 슬롯별로 관리하고 재장착할 때 초기화한다. 사거리와 관계없이 최근접 적을 선택하며 강타 중심은 해당 적의 위치다. 화염탄이 적을 화상 입히기 전에 한 번에 처치한 경우나 화상 만료 뒤에는 폭발하지 않는다. 중복 명중은 폭발 한 번으로 처리하며 폭발 피해로 인한 연쇄 폭발은 시험 규칙상 차단한다. 화상 지속 피해로 처치한 경우에도 발동한다. 강철의 기존 ★5 세 번째 동시 대상과 화염탄의 기존 ★5 전달 피해 1.5배는 해당 두 포탑에서만 고유 시험 효과로 교체했다. 다른 포탑의 기존 공통 효과와 ★3 기능은 유지한다.

## 머리·몸통과 탄

머리와 몸통의 최대 표시 크기를 각각 약 1 Unity 단위로 조정했다. 이미지 픽셀당 단위만 변경해 비율을 유지했으며 실제 머리와 몸통 객체의 스케일·충돌체 반경은 보존했다.

내장 이미지 생성 도구로 `Assets/Art/Sprites/TurretProjectile_Prototype.png`를 생성했다. 프롬프트: 기존 포탑을 화풍 참고로 한 탑뷰 캐주얼 포탑 탄 한 개, 위쪽을 향한 흰색·은색 몸체와 청록색 가장자리, 속성색 적용이 가능한 선명한 외곽, 투명 배경, 포탑·문자·추가 물체 없음. 기획서의 생성 이미지 표에도 추가했다.

직선 포탑은 별도 탄 이미지를 실제 이동하는 공격 투사체의 자식 표시기로 사용한다. 원래 투사체 스케일과 충돌 반경은 바꾸지 않았다. 근접·범위 포탑은 장착된 몸통에서 최근접 적 방향으로 이동하는 시각 전용 탄을 보여 준다. 이 두 공격의 피해는 기존처럼 즉시 적용되므로 시각 탄 도착 시점과 피해 시점이 일치하지 않는다. 게임 일시정지 중 시각 탄은 멈춘다.

## 통제 시험

Unity 6000.3.21f1의 별도 프로젝트 사본에서 실행했다. ★5 고유 효과 시험은 최초에 설정 부재로 실패했고, 구현 후 강철의 주기·범위·장착 초기화, 화염탄의 화상 처치·만료·중복·비화상 즉사·연쇄 차단·지속 피해 처치와 실제 발사 후 화상 폭발을 통과했다.

실제 씬에서 머리·몸통 표시 크기 1과 기존 충돌체, 근접·범위 시각 탄의 이동과 일시정지, 실제 직선 탄 이동·이미지·원래 충돌체·명중을 확인했다. 48종의 ★1·★3·★5 통제 공격, 화염탄 전달·화상, 레벨 보상과 합성, 동시 충돌 우선순위 회귀는 각각 종료 코드 0이었다. 48종 ★5 기존 회귀는 최초 강철의 공통 3대상 조건에서 실패했으며, 전용 효과를 가진 두 포탑의 새 규칙을 구분하도록 기대값을 보완한 뒤 통과했다.

## 남은 작업

- 48종 각각의 최종 ★3·★5 효과·수치·전용 이미지와 실제 사람이 조작할 때의 전투 균형은 확정되지 않았다.
- 근접·범위 포탑의 탄은 현재 시각 전용이어서 실제 피해가 탄의 도착보다 먼저 적용된다. 실제 투사체로 바꾸려면 명중 판정과 공격 종류별 밸런스 설계·검증이 필요하다.
- Unity 화면의 이미지 크기, 탄의 시인성과 명중 연출은 컴퓨터 사용 금지 지시에 따라 직접 보지 않았다.
- 기획서의 이미지 표는 탄을 포함해 이미지 26개를 확인했으며 문서의 실제 페이지 배치 검증은 수행하지 않았다.

## 정상 속도 자연 전투

난수 초기 시드 4501, 평원, 가상 A/D·Space 입력과 자동 보상 선택으로 진행했다. 83.4초에 자연 레벨업, 242.78초에 4분 엘리트 처치, 이후 엘리트 보상 선택 1회를 확인했다. 게임 시간 300.0초에 레벨 13, 잔여 경험치 8, 관측 처치 184, 몸통 15, 공용 HP 100으로 종료 코드 0이었다. 5분 목표 Lv.5~7은 초과한다. 이는 자동 조종 한 회의 결과이며 사람의 플레이나 모든 프레임의 결정적 재현은 아니다. 강철 ★5와 화염탄 ★5의 발동은 별도 통제 시험으로 확인했다.
