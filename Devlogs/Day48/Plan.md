# 48일차 영구 성장 구현 계획

---

## 목표와 기존 상태

48일차는 진화 코어 지급, 생존·기동·전투·성장 네 계열, 맵·캐릭터·포탑 해금, 메타 자동 저장과 재시작을 검증한다. 현재 입력 설정만 저장되며 메타 저장·성과 집계·재도전 연결은 없다. 진행 중 런은 저장하지 않는다.

---

## 설계와 시험

- [x] 독립 메타 저장과 코어·노드 비용·무료 초기화·저장 실패 및 중복 지급을 먼저 검증한다. 기존 사용자 입력 설정과 저장 데이터는 건드리지 않는다.
- [x] 정상·패배·포기 성과의 생존 120초당 1, 적 100마리당 1, 엘리트당 1, 최종 보스 처치 5를 실제 출현·종료 이벤트에 연결한다. 보상 없는 정리·소환 적은 별도 처리한다.
- [x] 네 계열 각 일반 2개와 최종 1개, 5단계 비용 3·5·8·12·18 및 최종 25를 적용하고 런 시작 능력치·경험치·재선택에 연결한다. 정확한 선행 단계는 각 이전 노드 1단계의 시험값으로 둔다.
- [x] 첫 런 종료 후 성장 화면, 평원 첫 승리의 폐허·임시 캐릭터, 폐허 첫 승리의 습지, 속성 단계별 임시 포탑 해금을 연결한다. 대상과 속성 단계는 조정 가능한 시험 설정으로 구분한다.
- [x] 메타 진행과 해금의 실제 재시작·재실행·격리 저장, 기존 핵심 전투와 기존 설정 회귀를 Unity 비대화형으로 확인한다. 테스트에는 실제 사용자 프로필과 다른 프로젝트 이름을 사용한다.
- [x] 미완료 UI·밸런스 및 수동 플레이 범위를 기록하고 48일차 파일만 커밋·푸시한다.
