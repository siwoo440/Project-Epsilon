# 48일차 개발 결과

---

## 개발 방향

기획서의 영구 성장에 맞춰 한 판의 성과를 진화 코어로 저장하고, 다음 판의 능력치와 맵·캐릭터·포탑 해금에 연결한다. 게임 진행 중간 저장은 포함하지 않는다.

---

## 구현 내용

- 생존 120초당 1개, 일반 적·엘리트 100처치당 1개, 엘리트 1마리당 1개, 최종 보스 처치 5개의 코어를 승리·패배·포기 시 지급한다. 보스 소환 적과 보상 없이 정리된 적은 제외한다.
- 동일한 런의 보상 중복을 막고 입력 설정과 별도 키에 자동 저장한다. 저장 실패 시 결과를 메모리에 보존하고 재시작 전에 재시도한다. 읽을 수 없거나 필드가 빠진 저장은 덮어쓰지 않는다.
- 생존·기동·전투·성장의 총 12개 노드, 일반 노드의 5단계 비용 3·5·8·12·18, 최종 노드 비용 25, 무료 전체 초기화를 연결한다. 전체 최대 성장 비용은 468개다.
- 체력, 회복, 마지막 몸통 이동, 회전력, 스태미나, 긴급 소모 감소, 피해, 공격 속도, 3등급 이상 피해, 경험치, 보석 흡수 범위, 런당 1회 레벨업 후보 재선택에 성장 효과를 적용한다.
- 첫 런 종료 후 시작 화면에 시험용 성장 메뉴가 나타난다. 일시정지의 포기와 종료 화면의 재도전으로 성과 저장과 다음 런을 연결한다.
- 평원 보스 처치로 폐허와 시험 캐릭터, 폐허 보스 처치로 습지를 해금한다. 속성 포탑 조건 충족 시 해당 시험 포탑을 저장·해금한다.
- 경험치 보너스의 부동소수점 오차로 100 XP의 3%가 2 XP로 절삭되던 문제를 수정했다. 작은 보석의 소수 보너스도 누적한다.

---

## 임시 결정

기획서에 해금 캐릭터, 포탑, 시너지 기준 수, 성장 노드별 선행 단계의 구체 값이 없으므로 확정값으로 간주하지 않는다. `Assets/Data/Progression/PrototypeMetaUnlockConfig.asset`의 대상은 기동형 캐릭터와 속성별 시험 포탑 8종이며, 속성 무기 2개를 시험 기준으로 둔다. 선행 단계는 앞선 각 노드의 1단계다. 기획 확정 시 데이터와 선행 조건을 조정한다.

---

## 비대화형 검증

Unity 6000.3.21f1에서 제품 이름을 `Project-Epsilon-Day48-Isolated`로 변경한 별도 프로젝트 사본을 사용했다. 실제 사용자의 기존 PlayerPrefs를 초기화하거나 수정하지 않았다.

- `AutomatedDay48MetaVerification.Run`: 실제 일반·엘리트·보스 소환 적과 최종 보스, 코어 지급, 중복 방지, 손상·누락 저장 보존, 저장 실패, 해금, 씬 재시작 통과.
- `AutomatedDay48FreshProcessVerification.Run`: Unity 프로세스를 새로 시작한 뒤 실제 저장의 코어와 해금 복원 통과.
- `AutomatedDay48EffectsVerification.Run`: 12개 노드, 최대 비용 468과 환불, 실제 피해·공격 대기·회복·이동·스태미나·경험치·1회 재선택 통과.
- `AutomatedDay48StartStatsVerification.Run`: 실제 시작 씬에서 성장 구매 후 체력·스태미나 갱신과 무료 환불 후 복원 통과.
- 실제 지역 효과, 47일차 포탑 효과, 엘리트 보상 버튼, 시작 캐릭터 입력, 통제된 적 처치·경험치·레벨업·무기 장착·전투 재개 회귀 통과.
- `Day45NaturalCombat` 자동 조종, 시드 4501, 정상 게임 속도와 임시 해금만 적용한 격리 저장에서 300.0초 생존, 자연 처치 199회, 레벨 13, 엘리트 확인과 보상 선택 1회. 사람의 수동 플레이 결과는 아니다.
- Unity Editor Search 초기 인덱싱에서 별도의 `ArgumentOutOfRangeException`이 발생했으며 위 테스트의 제품 기능은 각각 종료 코드 0이다.

## 직접 확인과 후속 작업

- 실제 게임 화면에서 성장 메뉴의 해상도별 가독성·버튼 입력, 포기와 재도전, 잠긴 대상의 안내와 해금 연출을 확인한다. 배치 모드는 시각 품질이나 사람의 조작감을 보장하지 않는다.
- 실제 새 저장에서 첫 판 종료, 포인트 구매·무료 초기화, 재시작 및 앱 재실행 흐름을 수동 확인한다.
- 성장 메뉴는 기능 검증용 IMGUI이며 최종 UI·아이콘·해금 안내·보상 연출 및 밸런스 조정이 남아 있다. 49일차는 기획서의 UI·연출 방향에 따라 진행한다.
