# 49일차 구현 계획

---

## 범위와 구조

49일차는 기존 게임 씬에서 메인 메뉴 → 캐릭터 → 맵 → 기존 시작 포탑 선택 → 전투 → 일시정지·결과·재도전의 실제 흐름을 연결한다. 기존 캐릭터·맵 데이터, 시작 포탑 패널, 입력 설정, 영구 성장 서비스와 저장을 재사용한다. 런 도중 저장과 50일차 VFX·튜토리얼은 추가하지 않는다.

- `RunFrontendController`: 기존 씬에 생성되는 Unity UI, 단계별 접근 제어, 실제 캐릭터·맵과 잠금 설명, 수동 일시정지·결과 표시 및 메뉴 이동.
- `SettingsMenuController`: 기존 입력 설정 화면 연결과 음량·화면 모드·해상도·화면 흔들림 설정의 별도 영구 저장. 흔들림 이펙트는 아직 없으므로 값만 저장한다.
- `StartingWeaponSelection`, `SnakeWeaponMergeController`, `GameManager`: 단계별 입력과 ESC 우선순위를 연결하고 기존 흐름 및 보상 정지 소유권을 유지한다.
- `MetaProgressionController`: 실제 결과 화면에 생존 시간·처치·획득 코어·해금 변화와 저장 실패를 전달한다.

---

## 검증 순서

- [x] 격리 Unity 사본에서 전용 메뉴·선택 단계 부재를 보여 주는 실패 시험을 먼저 실행한다.
- [x] 실제 버튼을 눌러 6개 캐릭터와 세 맵의 표시·선택·잠금을 확인하고 기존 포탑 선택으로 출격한다.
- [x] ESC 합성 취소 우선, 수동 정지·설정·재개·포기와 결과·재시작 및 저장 실패 처리를 검증한다.
- [x] 기존 캐릭터 능력과 포탑 후보, 전투·보상·메타 저장 회귀를 Unity 비대화형 배치에서 검사한다.
- [x] 직접 확인하지 않은 시각·해상도·조작감과 미구현 흔들림 효과를 기록한 뒤 49일차만 커밋한다.
