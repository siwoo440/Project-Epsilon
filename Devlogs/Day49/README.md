# 49일차 개발 결과

---

## 개발 방향

기획서의 전용 화면 흐름에 맞춰 메인 메뉴 → 캐릭터 선택 → 맵 선택 → 시작 포탑 선택 → 전투 → 결과·재도전을 연결한다. 6종 캐릭터의 기존 시험 패시브와 무기 후보, 맵과 해금, 전투 및 저장을 재사용한다.

---

## 구현 내용

- 메인 메뉴에 시작·영구 성장·설정·종료를 연결하고, 생성한 `MenuBackground_Casual.png`를 배경으로 적용했다. 기존 승인 캐릭터 그림체를 참조했으며 이미지가 버튼 입력을 가리지 않는다.
- 6종 캐릭터의 능력치·패시브·시작 포탑 후보와 기존 실제 머리·몸통을 표시한다. 캐릭터별 고유 외형은 아직 없으므로 기존 공용 외형을 사용한다.
- 세 맵의 실제 바닥·장애물·특수 지역·보스 정보를 표시하고, 잠긴 캐릭터와 맵의 시험용 해금 조건을 안내한다. 평원 보스 처치 뒤 해금된 캐릭터와 폐허를 실제로 선택할 수 있다.
- 기존 시작 포탑 선택을 별도 출격 단계에 연결하고, 그 이전 화면에서는 뒤쪽 포탑 입력을 차단한다.
- 수동 일시정지에 계속·설정·포기·메인 메뉴를 연결한다. 합성 화면에서는 ESC가 합성 취소를 먼저 처리하며 설정 화면 뒤의 전투는 재개하지 않는다. 레벨업·엘리트 보상의 일시정지와 수동 일시정지를 구분한다.
- 결과에 실제 생존 시간·일반 및 엘리트 처치·획득 코어·새 해금·저장 상태를 표시한다. 저장 실패 시 결과를 유지하고 재시도하며, 재도전은 선택 캐릭터와 맵을 보존한다.
- 기존 키 변경 화면을 재사용하고 음량·해상도·창 모드·화면 흔들림 강도를 입력 설정 및 메타 진행과 별도 키에 저장한다. 초기 해상도와 창 모드는 현재 화면을 표시하며 사용자가 변경하기 전 임의로 바꾸지 않는다.
- 재도전 시 먼저 적용한 맵을 늦게 실행된 기본 맵 초기화가 덮어쓰던 문제를 수정했다.

## Unity 비대화형 검증

Unity 6000.3.21f1의 별도 `Project-Epsilon-Day48-Isolated` 사본에서 실행했으며 실제 사용자 PlayerPrefs는 초기화하지 않았다.

- `AutomatedDay49FrontendVerification.Run`: 전용 메뉴, 생성 배경과 실제 캐릭터·맵 미리보기, 6종 후보와 잠금·해금, 설정 저장과 손상 원본 보존, ESC 합성 취소 우선 및 설정 중 정지, 포기·코어·속성 해금 결과, 저장 실패와 재시도, 폐허·캐릭터 보존 재도전과 메인 메뉴 복귀 통과. 저장 실패 시나리오는 의도된 오류 로그 2건을 발생시켰다.
- 캐릭터 6종 데이터·실제 패시브·시작 후보, 방향키 선택과 설정 입력 우선순위, 엘리트 보상, 47일차 포탑 효과, 48일차 성장 및 메타 저장·재시작, 통제된 전투 성장 회귀는 각 종료 코드 0이다.
- Unity Editor Search 초기 인덱싱의 `ArgumentOutOfRangeException`이 별도로 발생했다. 49일차 5분 자연 전투와 사람의 수동 플레이는 실행하지 않았다. 48일차의 5분 시험 결과를 현재 변경의 통과 결과로 사용하지 않는다.

## 한계와 직접 확인

- 화면 흔들림 강도는 저장하지만 실제 카메라 흔들림 효과는 아직 없다. 사운드 에셋과 50일차 VFX·튜토리얼도 이 일차 범위 밖이다.
- Unity 비대화형 시험은 장면과 버튼 이벤트·가상 키 입력을 검사한다. 사람의 조작감, 한글 글꼴, 실제 화면 비율별 가독성, 마우스 클릭 위치, 화면 모드 전환은 에디터 또는 실행 빌드에서 직접 확인해야 한다.
- 기획서 `15. 생성 이미지 현황` 표에 새 배경 이미지와 적용 상태를 삽입하고 데이터와 이미지 객체를 읽어 확인했다. 문서 PDF 내보내기가 403으로 거부되어 실제 페이지 배치는 확인하지 못했다.
- 해금 대상 캐릭터·포탑과 조건 수는 48일차의 조정 가능한 시험값을 유지한다. 아직 게임 도중 저장은 없다.
