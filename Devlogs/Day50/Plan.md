# 50일차 전투 기록 계획

---

## 목표와 구조

기존 전투를 유지하며 선택적으로 활성화되는 로컬 JSON 기록을 추가한다. 런 시작 조건, 난수 시드, 고정 물리 간격, 시간별 레벨·획득 XP·처치·몸통·체력·포탑과 실제 피해 원인을 기록한다. 입력과 프레임 조건이 다르면 같은 시드만으로 같은 전투가 보장되지 않음을 명시한다.

- `RunTelemetry`: 선택 실행 옵션과 기록 상태, 안전한 시간 표본, 고유 파일 저장.
- `SnakeExperience`와 실제 충돌 처리기: 실제 반영된 획득 경험치와 확정된 피해 원인 전달. 무적·취소된 충돌은 피해로 집계하지 않는다.
- 기존 게임 관리자: 런 시작·종료 시점에만 기록기를 연결한다. 기록 실패가 전투와 영구 성장 저장을 막지 않는다.
- `AutomatedDay50RecordingVerification`: 격리된 Unity 사본에서 시드·기록·피해·죽음 경계 및 JSON 파일을 검증한다.
