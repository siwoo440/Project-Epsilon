# 51일차 초반 전투 계획

---

## 목표

실제 씬의 초반 적 생성, 포탑 자동 공격, 경험치 획득과 접촉 피해를 동일한 기본 조건의 서로 다른 난수 시드에서 관찰한다. 5분 생존과 레벨 5~7은 시험 목표이며, 자동 조종 표본과 사람이 조작한 결과를 구분한다.

---

## 순서

- [x] 49일차 출격 화면을 기존 자연 전투 조종기와 연결한다.
- [x] 새로 격리한 저장 프로필과 시드 3개로 변경 전 자연 전투를 실행한다.
- [x] 실제 획득량·피해 원인·몸통·보상과 5분 결과를 비교한다.
- [x] 수치 수정이 근거에 부합하는지 판단하고 변경 시 같은 조건에서 재검증한다.
- [x] 한계와 남은 수동 확인을 기록한다.
- [ ] 51일차를 커밋·푸시한다.
