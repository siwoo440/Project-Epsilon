# 52일차 엘리트 전투 검증

---

## 개발 내용

기존 적 출현기, 엘리트 돌진, 경험치 드롭과 보상 처리기를 재사용했다. 4분 실제 출현 검증에 예고선, 예고 후 목표 이동에도 유지되는 돌진 방향, 실제 돌진 이동 및 종료 확인을 추가했다. 오래된 엘리트 보상 단위 시험의 대체 형식을 현재 의존성에 맞춰 복구했다. 단위 시험의 포탑 추첨은 기본 캐릭터의 균등 추첨 대체이며 특화 캐릭터의 가중 추첨 검증은 아니다.

---

## 자연 전투

Unity 6000.3.21f1의 격리 사본과 별도 저장 프로필에서 시드 5201, 평원, 균형형, 영구 성장 0단계로 실행했다. 정상 게임 속도, 자연 적 출현, 가상 이동 입력과 보상 자동 선택을 사용했으며 무적·경험치·능력치·시간 배율은 주입하지 않았다. 사용자의 작업 중 `Game.unity` 사본을 사용했다.

게임 시간 300초에 레벨 13, 누적 획득 경험치 263, 전체 처치 198, 몸통 15칸, 체력 100을 기록했다. 4분 엘리트가 출현해 게임 시간 242.09초에 자연 처치됐고 엘리트 보상 선택 1회가 기록됐다. Unity 종료 코드는 0이었다. 첫 자연 레벨업은 78.0초였다. 이 표본은 자동 조종 1회이며 사람의 수동 플레이를 뜻하지 않는다. 엘리트가 빠르게 처치돼 이 표본만으로 예고와 돌진 전 과정을 확인할 수 없다.

---

## 통제 시험

출현 시계를 직접 변경하지 않고 게임 시간을 8배로 진행한 시험에서 첫 엘리트는 출현기 기준 240.000초에 한 번 관측됐다. 게임 시간을 정상 속도로 돌리고 공격 시작 시각과 위치를 통제해 예고선, 방향 고정, 돌진 이동과 대기 상태 복귀를 확인했다. 강제 처치 후 경험치 20 보석 1개, 연속 레벨 보상 2회, 대기 중이던 엘리트 보상 1회와 게임 재개를 확인했고 종료 코드는 0이었다. 위치와 공격 시각, 자동 공격·충돌 및 드롭 확률을 통제한 시험이다.

별도 강제 출현 시험은 출현기 시간을 240초로 설정하고 강제 처치해 포탑 보상 선택·장착과 재개를 확인했다. 종료 코드는 0이었다. `dotnet run --project Tests/EliteRewards/EliteRewards.csproj`도 보상 후보·회복·복구·교체·합성 등 기존 단위 시험을 통과했다.

엘리트 이미지와 고정 돌진 방향 검사 및 실제 2D 충돌 우선순위 검사는 각각 종료 코드 0이었다. 충돌 검사는 통제한 돌진 단계에서 엘리트 절단과 장애물의 우선 처리, 무적과 다른 충돌을 확인했다.

통제 시험 초기 실행은 사수 투사체가 비활성 충돌 처리기를 우회해 체력을 바꿔 시험 초기값 확인에 실패했다. 제품을 변경하지 않고 해당 시험에서 머리·몸통 충돌체를 비활성화해 보상 경합 조건을 고정한 뒤 재실행했다. 별도 Unity 사본의 최초 준비 실행은 초기화 제한 시간 초과로 종료됐으며 이후 재실행 결과를 기록했다. 일부 Unity 실행에서 Editor Search 초기화 예외가 기록됐다.

## 직접 확인할 사항

엘리트 예고선의 가독성, 실제 조작 중 회피 가능성, 보상 카드 배치와 초반 난이도는 Unity에서 직접 플레이하며 확인해야 한다. 1회의 자동 조종 결과만으로 밸런스를 확정할 수 없다.
