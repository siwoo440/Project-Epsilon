# 54일차 긴 몸통과 장애물 무적 검증

---

## 수정 내용

무적이 끝날 때 머리가 장애물 안에 남아 있으면 장애물 경계의 안전한 위치로 이동하도록 했다. 단일 경계 후보가 다른 장애물에 막히면 주변 안전 위치를 탐색한다. 이동한 뒤 0.3초 동안 장애물 재접촉 피해만 무시하며, 적 직접 충돌에는 이 유예를 적용하지 않는다. 무적 중 이미 장애물을 벗어났으면 위치를 바꾸거나 유예를 시작하지 않는다.

단일 장애물은 실제 2D 충돌체 간 최소 분리 거리를 사용한다. 여러 장애물에서 이 후보가 막히면 반경 8 유닛까지 32방향을 탐색하고 안전 경계를 보정한다. 복수 장애물에서는 수학적으로 절대 최단 위치를 보장하지 않으며, 검색 범위 안에 안전한 위치가 없으면 기존 위치를 유지하고 경고를 기록한다. 실제 맵의 아주 큰 장애물과 복잡한 밀집 배치는 추가 검증이 필요하다.

---

## 실행한 검증

Unity 6000.3.21f1 격리 사본에서 실제 2D 물리 충돌과 통제된 20칸 몸통을 사용했다. 자기 충돌과 장애물 동시 접촉, 네 방향 적 동시 접촉의 단일 손실, 좁은 통로 직진, 벽 피해와 무적, 양쪽 벽 사이의 안전 위치 이동을 확인했다. 단일 장애물에서는 실제 최소 분리 거리와 이탈 위치를 비교했다. 이탈 직후 벽 피해만 유예하고 적 접촉은 적용되는지, 0.3초 후 벽 피해가 다시 적용되는지 확인했다. 이미 이탈한 경우에는 위치와 재접촉이 불필요하게 바뀌지 않았다. 최종 충돌 회귀의 Unity 종료 코드는 0이었다.

합성 화면의 실제 70% 게임 속도, 방향 유지 직진, 단계별 ESC 취소와 재료 보존, 보상 합성 중 기존 무적과 적 접촉, 피해에 의한 중단·패배를 별도 Unity 배치에서 검증했다. 보스 밀림의 몸통별 유예와 4분 엘리트 출현·보상 회귀도 각각 종료 코드 0이었다. 자연 전투 10분 측정은 이 수정 이전에 수행했으며, 수정 후 자연 전투는 후속 통합 검증 대상이다.

수정 전 시험에서는 무적이 끝난 뒤에도 머리가 장애물 안에 남았다. 첫 수정은 인접한 두 벽 사이에서 이탈 방향이 반복되어 실패했다. 안전 후보를 실제 물리 겹침으로 확인하는 수정 후 통과했다. 시험용 몸통을 멀리 배치했다가 재생성할 때 자기 충돌이 섞이는 문제는 시험 간 경로와 몸통을 초기화해 분리했다. 일부 실행에서 Unity Editor 검색 색인 초기화 예외가 기록됐다.

---

## 직접 확인할 사항

긴 몸통으로 실제 통로를 조작할 때의 움직임, 장애물에서 빠져나오는 모습, 0.3초 유예 체감과 화면 가독성은 Unity에서 직접 확인해야 한다. 통제된 충돌체·위치 시험은 실제 사용자의 수동 플레이를 대신하지 않는다.
