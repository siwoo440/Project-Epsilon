# 55일차 0~10분 통합 검증 계획

54일차 장애물 이탈 수정을 포함한 동일 게임 설정으로 격리된 자연 전투 세 번을 실행한다. 정상 시간, 가상 이동 입력과 보상 자동 선택을 사용하고 10분 도달 횟수, 자연 레벨업, 4·8분 엘리트 및 실제 합성 결과를 구분해 기록한다.

기존 조종기에 선택적 자동 합성을 추가한다. 같은 포탑·같은 등급 쌍이 있을 때 실제 합성 화면 API로 진입하고 후보 버튼을 사용하며, 성공과 취소를 각각 기록한다. E 키 입력은 별도 통제 시험에서 확인한다. 설정을 사용하지 않은 기존 조종기 동작은 유지한다. 재료 구성, 수치 주입 및 가속을 사용한 통제 시험과 자연 전투 결과를 혼동하지 않는다.
