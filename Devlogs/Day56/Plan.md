# 56일차 10~15분 전투 검증 계획

기존 자연 조종기의 관찰 한도를 15분으로 늘리고 5·10·15분 상태를 따로 기록한다. 정상 속도, 가상 이동·보상 선택·선택적 자동 합성을 사용하며 12분 엘리트와 전투 중 적·몸통·미수집 보석 상태를 관찰한다. 패배나 제한 시간 종료도 실패 결과와 부분 기록으로 남긴다.

엘리트 일정은 별도 시간 가속 통제 시험으로 재검증한다. 자동 조종 한 표본만으로 체감 난이도를 확정하지 않으며 실제 플레이와 밀집도 확인이 남은 부분을 구분한다.

기획서의 일반 적 출현 간격·상한·능력치 배율이 기존 고정 설정과 다른 점을 확인했다. 0·5·10·15분 구간을 조정 가능한 데이터로 구성하고 엘리트는 일반 적 상한에 포함하지 않는다. 명시적으로 확정된 20분 최종 보스 전환은 유지한다. 5·10·15분 신규 적 종류와 정확한 종류별 비율은 별도 개발 대상이다.
