# 56일차: 10~15분 전투와 출현 구간

기획서의 0·5·10·15분 일반 적 출현 간격, 최대 수, 체력과 공격력 배율을 별도 데이터로 구성했다. 엘리트는 일반 적 상한에서 제외하며, 출현 시 기존 일반 적을 제거하지 않는다. 20분 최종 보스 전환은 사용자의 확정 방향을 따른다.

15분 자연 전투는 실제 게임 씬과 정상 시간 배율에서 가상 입력 및 보상 선택을 사용한 자동 조종 시험이다. 새 출현 설정을 적용하기 전 1회는 15분에 생존해 레벨 22, 처치 594, 엘리트 보상 선택 3회, 합성 7회를 기록했다. 10~15분의 미수집 보석은 30초 간격 11회 표본에서 96~141개였다. 이 숫자는 화면 내 밀도가 아닌 씬 전체 활성 보석 수다.

수정 후 동일 시드의 별도 15분 자동 전투도 생존했다. 15분에 레벨 24, 누적 경험치 1,049, 처치 828, 엘리트 처치 3, 몸통 20, 체력 100, 합성 5회를 기록했다. 10~15분의 30초 간격 표본 11회에서 씬 전체 미수집 보석은 208~341개였고, 10초 간격 몸통 표본 31회의 성장 최대 대비 현재 몸통 유지율은 모두 100%였다. 두 실행은 프레임과 전투 전개가 달라 이 차이만으로 변경의 인과관계를 판단하지 않는다. 한 표본과 자동 조종만으로 실제 조작 난이도나 밸런스를 확정할 수 없다.

## 실행한 검증

- Unity 배치: 구간 데이터가 없는 기존 상태에서 경계 시험의 실패를 확인하고, 수정 후 0·5·10·15분 경계와 실제 일반 적 생성 능력치, 엘리트 원본 능력치 보존을 통과했다.
- Unity 배치: 시간 가속과 적 행동 통제 조건에서 4·8·12·16분 엘리트 일정, 일반 적 상한 분리, 보상과 경험치 순서를 통과했다.
- Unity 배치: 엘리트 외부 제거 후 대기 출현과 무보상 처리를 통과했다.
- Unity 배치: 실제 1.3초 출현 간격에서 초반 3종 해금, 4분 엘리트 돌진과 강제 처치 이후 레벨·엘리트 보상을 통과했다.
- Unity 배치: 시간 가속과 적 행동 통제 조건에서 합성 중 20분 보스 전환, 기존 적 정리, 2단계 진입과 강제 처치 후 승리를 통과했다. 처음에는 시험 재료를 장착한 포탑의 자동 공격이 보석 수를 바꿀 수 있어 시험 조건을 수정했다.
- Unity 배치: 실패 시 중단 표본이 기록되는지 별도의 강제 실패 조건으로 확인했다. 해당 과정의 Unity 종료 코드 1은 의도된 결과다.
- Unity 시작 로그에 편집기 검색 인덱스 예외가 발생했다. 위 시험 결과는 각 시험의 별도 종료 코드와 결과 로그를 기준으로 기록했다.

## 남은 사항

5분 쇠똥구리, 10분 노린재, 15분 잠자리와 기획서의 시간대별 종류 비율은 아직 구현하지 않았다. 따라서 구간별 수치 적용과 별개로 기획된 적 구성 전체가 완료된 상태는 아니다. 실제 플레이 조작과 체감 난이도도 확인이 필요하다.
