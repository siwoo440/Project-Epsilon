# 57일차: 15~20분 생존 관찰

자연 전투 조종기의 목표 시간을 20분까지 확장했다. 5·10·15·20분 표본을 각각 실제 시점에 기록하고, 20분 목표에서는 실제 최종 보스 전환도 확인한다. 생존 도달은 보스 처치와 별도 결과다.

---

## 실행한 검증

- Unity 배치: 20분 목표 인수가 기존 조종기에서 5분으로 처리되는 실패를 확인하고, 수정 후 1,200초로 적용됨을 확인했다.
- Unity 배치: 시간과 성장·엘리트 관찰 조건을 강제로 통제해 5·10·15·20분 표본이 각 경계에서 한 번씩 기록되고 보스 전환이 일어나는지 확인했다. 자연 전투 결과는 아니다.
- 기록 요약기: 실제 통제 시험 로그를 읽었고, 별도로 만든 가상 표본에서 20분 요약과 15분 표본 누락 거부를 확인했다.
- 정상 속도 자동 전투 1회에서 20분 보스 전환에 도달했다. 가상 입력·자동 보상 선택·자동 합성을 사용했고, 보스 출현 직후 시험이 종료되어 보스 처치는 검증하지 않았다.
- 해당 실행은 20분에 레벨 27, 누적 경험치 1,660, 처치 1,251, 엘리트 처치 4, 합성 8, 몸통 20, 체력 100을 기록했다. 16분 엘리트의 자연 처치는 게임 시간 약 960.86초에 기록됐다.
- 15~20분의 30초 간격 표본 11회에서 씬 전체 동시 적은 0~1마리, 미수집 보석은 288~415개였다. 10초 간격 몸통 표본 31회의 성장 최대 대비 현재 몸통 유지율은 모두 100%였다. 전체 피해 기록은 적 투사체 7회와 장애물 2회였다.

---

## 남은 사항

15분 잠자리와 시간대별 적 종류 비율은 미구현이며 실제 사람의 조작과 보스 처치 검증도 남았다. 적과 보석 수치는 한 번의 자동 조종과 시점별 표본이므로 실제 화면 밀도나 전체 밸런스로 확정할 수 없다. 20분 보스 전환은 사용자의 확정 방향으로 유지한다.
