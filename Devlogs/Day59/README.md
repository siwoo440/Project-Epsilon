# 59일차: 보스전 연속 관찰

기존 20분 생존 시험은 그대로 종료하고, `-epsilonFightBoss`를 지정한 시험만 보스전 이후까지 계속하도록 자동 조종기를 확장했다. 이 옵션은 20분 표본을 보존하고 실제 보스 2단계, 보스 처치와 승리 결과 화면을 확인한다. 보스전이 120초 이상 이어지거나 플레이어가 패배하면 성공으로 표시하지 않는다.

---

## 실행한 검증

- Unity 배치: 시간과 보스 피해를 통제한 시험에서 수정 전 조종기가 보스전 전에 종료하는 것을 확인했다. 수정 후 실제 2단계 진입, 강제 보스 처치와 승리 결과 화면까지의 연속 처리를 통과했다.
- 실제 기록 검증: 위 통제 시험에서 5·10·15·20분 표본과 승리 종료 표본이 각각 한 번 기록됐다. 강제 시간 이동과 강제 피해를 사용한 결과다.
- Unity 배치: 보스전 옵션이 없는 20분 생존 시험의 기존 종료 동작을 통제 조건에서 재검증했다.
- 시간 가속·무적·능력치 변경·강제 처치 없는 정상 속도 자동 전투 1회에서 게임 시간 1,203.358초에 2단계 보스를 처치하고 승리 화면에 도달했다. 실제 사람의 입력 대신 가상 조향, 보상 선택과 합성을 사용했다. 20분 표본은 레벨 27·몸통 20·체력 100이었고, 종료 표본에 보스 처치 1회가 기록됐다.
- 보스전은 이 표본에서 약 3.36초로 기획서의 임시 목표 2~4분보다 짧았다. 한 번의 자동 조종 결과이므로 원인과 적정 수치는 추가 검토가 필요하다. 이 실행은 61일차 보석 집계와 62일차 후보 추첨 수정 이전에 시작했다.

---

## 남은 사항

5·10·15분 신규 적과 종류별 비율은 여전히 미구현이며 사람의 직접 조작과 시각 검증도 남았다. 새 포탑 후보 규칙을 적용한 보스전과 여러 시드의 체감 난이도를 확인해야 한다.
