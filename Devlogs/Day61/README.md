# 61일차: 보석 수집률과 성장 기록

기획서의 경험치 요구량은 시작값 10, 레벨별 1.12배이며 실제 씬 설정도 같다. 기존 자동 전투의 5분 레벨은 56일차 수정 후 Lv.13, 57일차 Lv.12로 기획서의 임시 목표 Lv.5~7보다 높았다. 기획서의 Lv.20 목표는 30분 기준으로 적혀 있어 확정된 20분 보스 규칙에 맞춘 재검토가 필요하다.

기존 기록의 획득 경험치는 지역·영구 성장 보너스를 포함하고 보석 생성 총량을 기록하지 않아 수집률을 산출할 수 없었다. 선택적 전투 기록에 생성 보석 원본 경험치와 수집 보석 원본 경험치를 별도로 추가했다. 보석 자동 병합은 새 보석 생성이나 수집으로 중복 기록하지 않는다. 기존 기록은 수집률을 ‘기록 없음’으로 표시한다.

---

## 실행한 검증

- Unity 배치: 실제 소형 보석 5개와 대형 보석 1개 생성, 소형 보석 병합, 부분 수집과 레벨업 수집의 집계 및 동기 표본을 통과했다. 수정 전에는 집계 필드가 없음을 확인했다.
- Unity 배치: 자동·부분 보석 병합, 기록 비활성 실행과 기존 전투 기록 회귀를 통과했다.
- Python 단위 시험: 기존 기록의 미측정 표시, 분모가 0인 경우, 정상 수집률과 잘못된 집계 거부를 확인했다.
- 새 집계를 적용한 정상 속도 5분 자동 전투 1회에서 생성 보석 원본 경험치 352 중 229를 수집해 65.1%를 기록했다. 레벨 12, 처치 216, 몸통 14, 체력 100이었다. 이 실행은 62일차 후보 추첨 수정 전이다. 종전 59·60일차 전투는 새 집계 이전에 시작했으므로 이 수집률을 제공하지 않는다.

---

## 남은 사항

여러 시드와 사람의 조작에서 수집률과 성장 결과를 확인한다. 적 추가와 종류별 비율, 무한 사거리 자동 공격이라는 확정 조작 조건, 보석 회수 경로가 밸런스에 미치는 영향은 별도로 비교해야 한다. 시험 수치와 20분 목표 레벨은 임의로 변경하지 않았다.
