# 62일차: 포탑 후보 집중 추첨

첫 번째 보상 카드에 최다 보유 포탑 종류를 40% 확률로 집중하며, 나머지 경우와 다른 카드는 기존 가중치를 사용한다. 같은 포탑 종류는 등급을 합산하고 동률은 균등 추첨한다. 이미 5등급을 보유한 종류와 같은 화면의 중복 종류를 제외한다.

실제 48종 데이터와 1만 2천 회 추첨의 Unity 배치 시험, 독립 규칙 시험과 기존 레벨업·엘리트 보상·합성 회귀 시험을 통과했다. 20분 종료와 충돌하는 기존 28~30분 5등급 목표는 변경하지 않았으며, 자연 플레이의 5등급 도달률은 별도 검증이 필요하다.
