# 선택 화면과 전투 씬 분리

메뉴와 캐릭터·맵·시작 포탑 선택은 실제 메뉴 및 준비 씬에서 표시하고, 선택 배경에 기존 일러스트를 불투명하게 배치한다. 게임 씬을 직접 재생하면 일시적인 검은 화면으로 전투 화면을 가린 뒤 메뉴 씬으로 이동한다. 배치 시험의 직접 전투 진입은 명시적 시험 인자로만 허용한다.

Unity 배치에서 메뉴, 준비, 선택, 전투와 결과 씬의 이동 및 준비 씬에 게임 화면이 없는 상태를 검증했다. 별도의 기존 시작 포탑 단위 시험은 제거된 HUD 설정 버튼을 전제로 작성되어 실패하며, 실제 씬 이동 회귀 시험은 통과했다. 편집기에서 배경의 가독성과 전환 모습을 직접 확인해야 한다.
