# 63일차: 분 단위 적 능력치 증가

기존 5분 기준의 체력·공격력 배율 사이를 선형 보간하고, 완료된 분을 기준으로 일반 적과 엘리트에 적용한다. 20분 기준 임시 배율은 체력 1.55배, 공격력 1.12배다. 신규 개체와 이미 출현한 개체에 같은 배율을 적용하며, 생존 중인 개체의 현재 체력 비율을 유지한다. 원본 데이터와 이동 속도, 5분 단위 출현 간격과 상한은 유지한다. 최종 보스 소환 일반 적에도 같은 일반 적 배율이 적용된다.

숫자는 기존 출현 설정 데이터에서 조정한다. 20분 전환에서는 기존 전투 적이 제거되므로 20분 기준은 직전 분 사이의 보간 및 보스 소환 일반 적에 사용한다. 실제 난이도와 장시간 플레이 체감은 별도 검토가 필요하다.

시드 6301의 정상 속도 5분 자동 전투에서 226처치, 레벨 13, 누적 경험치 278, 엘리트 보상 선택 1회, 합성 3회, 몸통 15칸과 HP 100을 기록했다. 생성된 원본 보석 경험치 365 중 278을 수집했다. 가상 이동·선택·합성을 사용했으며 수동 플레이나 여러 시드의 밸런스 검증은 아니다.

실제 강철 근접 포탑을 단일 대상에 명중시키는 통제 시험에서 ★1 두 개는 물리 2단계, 공격 간격 0.8초 기준 두 발 피해 22와 계산 DPS 27.5였다. 공격력 강화로 ★2 한 개를 만든 뒤 물리 단계가 즉시 0으로 감소했고, 한 발 피해 13.125와 계산 DPS 16.406을 기록했다. 다수 적, 생존력, 다른 강화 선택 및 실제 플레이 결과는 별도다.
