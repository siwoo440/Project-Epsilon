# 64일차: 복합 속성 반응

기획서의 여섯 조합을 실제 공격에 연결했다. 화염·독은 반응 전용 지속 피해, 냉기·전기는 추가 피해와 감속, 물리·폭발은 범위 피해와 넉백을 적용한다. 신성·화염은 범위 피해, 암흑·독은 반응 전용 공격·방어 약화, 신성·암흑은 추가 피해와 공용 체력 회복을 적용한다. 관련된 두 상태 또는 표식을 소비하며 다른 상태는 유지한다.

여러 재료가 반응 가능할 때는 최초 적용 시점이 가장 오래된 재료를 선택하고, 같은 시점에는 기획서의 속성 순서를 따른다. 같은 상태의 지속시간 갱신은 최초 순서를 유지하며, 전파된 암흑 저주도 반응 재료로 기록한다. 전기 연쇄의 추가 대상도 반응 판정을 한다. 반응 피해는 사망 이벤트를 유지하되 화상 처치 폭발을 연쇄시키지 않는다.

반응 피해·표식 지속시간·범위·감속·약화·회복량은 실제 `WeaponAttributeCombatEffects`의 조정 가능한 임시값이다. Unity 배치에서 6종 양방향, 재료 소비, 우선순위와 동률, 전파 저주, 전기 연쇄, 약화 만료, 공용 HP 회복, 보스 빙결 및 넉백 면역을 확인했다. 독립 규칙 시험과 기존 화상·독·빙결·신성·암흑 회귀도 통과했다. 실제 수동 플레이, 여러 빌드의 밸런스와 장시간 부하는 아직 검증하지 않았다.

시드 6401의 정상 속도 5분 자동 전투에서 218처치, 레벨 13, 엘리트 보상 선택 1회, 합성 6회, 몸통 15칸과 HP 100을 기록했다. 가상 이동·선택·합성을 사용한 한 회차이며 수동 플레이는 아니다.
