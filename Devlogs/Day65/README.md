# 65일차: 시작 포탑별 5분 성장 비교

정상 속도, 시드 6401, 개방 평원, 기본 캐릭터와 자동 이동·보상 선택·합성을 사용해 시작 포탑만 바꾼 두 회차를 비교했다. 두 시험은 격리된 저장 프로필에서 직접 게임 진입 옵션으로 실행했다.

| 시작 포탑 | 5분 레벨 | 처치 | 획득 경험치 | 원본 보석 수집 | 몸통 | 체력 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 강철 근접 포탑 | 14 | 231 | 306 | 306 / 374 | 16 | 100 |
| 강철 관통 포탑 | 13 | 218 | 269 | 268 / 348 | 15 | 100 |

두 회차 모두 4분 엘리트 보상을 선택했다. 근접은 합성 4회, 관통은 합성 6회였다. 자동 조작은 난수 분기와 선택에 영향을 주므로 동일 시드여도 이후 적과 보상 흐름이 완전히 같지는 않다. 각 포탑의 한 회차이며 다중 시드, 장시간 생존·DPS와 직접 조작 비교 전에는 밸런스 결론을 내리지 않는다.
