# 세 맵 장애물과 환경 요소: 에셋·배치 기반

첨부된 개별 PNG 33개를 평원·폐허·습지별 `Resources/MapElements` 폴더에 가져왔다. Unity 가져오기 설정은 단일 스프라이트, 중앙 피벗, 256픽셀당 1유닛, 투명 알파와 밉맵 비활성이다. 장애물은 해당 맵의 이미지를 사용하고 이미지보다 작은 별도 충돌 범위와 기존 장애물 피해·무적 처리를 사용한다.

기존 청크 생성기를 확장해 장애물 개수와 위치를 난수로 정하고, 청크 중앙과 경계에 연결된 통로를 확보한다. 장애물 확률·최소/최대 개수·통로 폭·플레이어 주변 보호 거리는 기존 맵 프로필에서 조정한다. 맵별 32개 시드로 이미지 연결·설정 적용·통로와 머리 주변 보호를 검사했고 실제 Game 씬에서 청크 생성 및 장애물 피해·무적도 확인했다.

현재 확률과 개수는 기존 임시값을 보수적으로 유지한다. 기획서의 장애물 밀도 4~7%, 12~16%, 7~11%는 아직 실측·조정하지 않았다. 20칸 뱀의 실제 회전·탈출과 다수 적 및 보스전의 실제 화면 확인은 완료된 것으로 보지 않는다. 20분 보스 규칙은 사용자 확정을 유지한다.

평원 바위 엄폐와 폐허 엄폐 잔해에 기존 장애물의 투사체 차단 속성을 연결했다. 실제 생성된 평원 엄폐물에서 포탑·적 투사체의 물리 차단, 일반 장애물의 투사체 통과, 평원·폐허 이미지별 엄폐 설정과 기존 장애물 피해·무적을 Unity 배치로 확인했다. 화염탄 관통·전달 등 독립 시험도 통과했다.

## 맵별 상호작용

- 평원: 바람길, 꽃가루, 회복 꽃밭, 보석 꽃길과 개미굴을 기존 이동·경험치·체력·일반 적 생성에 연결했다. 꽃길 보석은 해당 구역 진입 시 분산 생성된다. 개미굴은 5분부터 경고 후 기존 추적자를 순차 생성하며 일반 적 상한과 정상 경험치를 사용한다.
- 폐허: 방전 바닥, 인접 회로 스위치, 보급 창고와 일시 붕괴 잔해를 연결했다. 붕괴 예고가 끝날 때 머리 또는 몸통이 범위 안에 있으면 잔해 생성을 취소한다. 방전과 붕괴는 보스전 동안 일시 중지하는 안전 가정을 사용한다.
- 습지: 진흙 비중첩 감속, 독성 포자, 지형 감속만 무시하는 수초 다리와 일회성 정화 꽃을 연결했다. 얕은 수로와 징검돌은 안전 연결 통로의 비충돌 바닥 이미지다.
- 장식은 충돌체가 없고 적·탄환·위험 예고보다 아래에 표시한다. 개미굴 흙무더기를 개미굴 주변에 함께 묶어 배치하는 기능과 최종 이미지 크기의 시각적 조정은 남았다.

모든 효과 시간과 피해량은 기존 `PrototypeMapProfile` 및 세 맵 데이터에서 조정한다. 기획서에서 값이 정해지지 않은 개미굴 예고 1초·소환 간격 0.5초, 스위치 인접 거리 12유닛, 맵 보석 3개×경험치 1과 보급 회복 5는 시험용 가정이다. 정화 꽃은 현재 밟고 있는 감속 지형에서 벗어날 때까지 해당 지형 감속을 해제하는 가정을 사용한다. 보석과 꽃·창고의 1회 사용 및 장치 대기는 같은 런의 청크 재생성 후에도 유지한다.

## 검증과 한계

Unity 6000.3.21f1의 별도 프로젝트 복사본에서 실제 세 맵 선택과 청크, 맵별 32개 생성 시드, 장식과 이미지, 안전 통로 수학 검사, 장애물 충돌·무적 및 투사체 엄폐를 확인했다. 평원 이동·꽃가루, 습지 감속·다리·정화, 일회성 회복·보석·보급, 방전·포자 예고와 피해·무적, 스위치 비활성·대기, 개미굴의 일반 적 상한 및 경험치 드롭, 플레이어가 남아 있을 때의 붕괴 생성 취소와 잔해 만료를 실제 씬의 통제 배치 시험으로 확인했다. 경험치 보석 독립 시험도 11개 통과했다.

시험은 사람이 화면을 보고 조작한 플레이를 대신하지 않는다. 붕괴 예고 종료 때 몸통이 남아 있는 경우, 20칸 몸통의 실제 연속 회전과 탈출, 150마리 부하, 적 공격 감속과 수초 다리의 조합, 경고 가시성과 장시간 보스전은 직접 확인하지 못했다. 초반 5분 자동 전투 결과는 별도 로그에서 확인한다. 기존 Unity 에디터 Search 인덱싱 `ArgumentOutOfRangeException`이 배치 초기화 중 기록됐으며 제품 코드의 예외로 확인된 것은 아니다.

`EnemySpawnAim`과 `EliteSchedule`의 독립 .NET 시험은 `EnemyWaveSettings`, `EnemyWaveStage`, `ProjectEpsilon.Recording` 모의 구성이 빠져 컴파일되지 않았다. 해당 실제 코드 참조는 이번 수정 전 커밋에도 있었으며, 두 독립 시험은 실패로 기록한다. 실제 Unity 씬의 개미굴 생성과 정상 경험치 드롭 시험은 별도로 통과했다.

평원 실제 Game 씬에서 시드 6601, 시간 배율 1, 자동 이동·선택 입력으로 게임 시간 300초를 관찰했다. 결과는 생존, 적 처치 218회, 레벨 13, 남은 경험치 31, 레벨 선택 18회, 엘리트 확인 및 보상 선택 1회, 몸통 15칸, HP 100이었다. 자동 합성 시도는 없었다. 이 시험 시작 이후 추가한 습지 안전 수로 위치, 개미 소환 위치 재탐색과 사용한 보상의 재생성 표시 수정은 별도의 통제 배치로 검증한다.
