# 67일차: 맵 배치와 긴 몸통 안전성

기획서 67일차의 세 맵 청크·장애물·통로·특수 지역을 기존 청크와 충돌 구조에서 검토했다. 평원의 개미굴 흙무더기는 이전에는 독립 무작위 장애물로만 생성됐고, 개미굴과 인접한다는 보장이 없었다. 기존 장애물 생성 경로를 재사용해 개미굴 주변에 흙무더기를 배치하되 입구·중앙 및 청크 경계 통로를 비우고 머리·몸통·꼬리나 기존 장애물과 가까우면 생략한다.

장애물을 별도로 생성하지 않는 조건에서 128개 시드를 시험했다. 수정 전에는 개미굴에 흙무더기가 없어 실패했고, 수정 후 출현한 개미굴 28개에서 통로와 입구의 간격을 확인했다. 머리 위치 및 기존 장애물과 겹친 후보를 생략하는 검사와 실제 Game 씬의 붕괴 예고 중 몸통 보호도 통과했다.

---

## 맵별 충돌 면적 표본

실제 맵 설정과 각 맵 512개 시드의 청크에서 장애물 `BoxCollider2D` 면적을 합산하고 전체 청크 면적으로 나눈 결과다. 머리 주변 보호를 시험용으로 적용하지 않은 표본이며 특수 지역의 원형 범위는 포함하지 않는다.

| 맵 | 충돌 사각형 면적 비율 | 장애물이 있는 청크 | 실제 특수 지역 |
| --- | ---: | ---: | --- |
| 개방 평원 | 0.033% | 76/512 | 바람길·개미굴·회복·보석·꽃가루 |
| 폐허 회랑 | 0.082% | 178/512 | 붕괴·보급·방전·스위치 |
| 변이 습지 | 0.053% | 114/512 | 포자·진흙·다리·정화 |

기획서의 4~7%, 12~16%, 7~11% 밀도는 그림과 실제 충돌 중 면적 기준이 명확하지 않다. 위 충돌체 합계와 동일한 지표라고 단정하지 않고, 충돌체 확대나 장애물 수 변경을 보류했다. 장식·스프라이트의 시각 면적과 실제 플레이 체감은 이 측정에 포함되지 않는다.

## 검증과 한계

Unity 6000.3.21f1 비대화형 배치에서 맵별 지역 생성, 32개 시드의 안전 통로, 기존 20칸 충돌·무적·탈출 회귀와 머리·몸통이 붕괴 예고 구역에 남은 경우를 시험했다. 별도 실제 씬 시험에서는 맵마다 청크당 장애물 세 개를 강제하고 연결된 몸통 20칸을 실제 경로로 이동시켜, 직각 회전과 마지막 몸통의 통로 이탈을 확인했다. 적과 특수 지역을 끄고 회전을 코드로 통제했으므로 사용자가 직접 조작한 결과는 아니다.

150마리와 보스 공격이 동시에 있는 장면의 성능·경고 가시성, 장애물 이미지의 최종 크기, 실제 맵 밀도 기준과 장시간 체감 검증은 남았다. Unity 배치 초기화의 에디터 Search 인덱싱 `ArgumentOutOfRangeException`은 계속 기록됐으며 제품 코드 오류로 확인되지 않았다.
