# 68일차: 맵별 보스 시험 설정

세 맵의 보스는 기존에 공통 사격·돌진·위험 구역·소환 동작을 사용했다. 맵별 데이터에는 체력·이동속도·사격 간격·발사 수만 있었고 공격력과 예고·지속·재사용 간격 등은 Game 씬의 공통 설정에 있었다. 기존 보스 구성과 20분 전환은 유지하면서 이 공통 임시값을 각 맵 데이터에서 조정할 수 있게 연결했다.

| 항목 | 평원 | 폐허 | 습지 |
| --- | ---: | ---: | ---: |
| 체력 | 600 | 700 | 650 |
| 이동 배율 | 0.75 | 0.65 | 0.70 |
| 사격 간격 | 2초 | 1.8초 | 2.2초 |
| 1·2단계 발사 수 | 3·5 | 3·5 | 4·6 |

세 맵의 추가 설정은 기존 씬과 같은 시험값이다. 투사체·돌진 피해 15, 돌진 간격 6초·예고 1초·지속 0.8초·속도 8, 2단계 이동 1.25배·사격 간격 0.75배·돌진 속도 1.4배, 위험 구역 간격 8초·예고 1초·지속 3초·피해 10, 소환 간격 12초·상한 4마리를 사용한다. 위험 피해 간격·반경과 소환 거리도 맵 데이터에 두었다.

---

## 실제 씬 통제 시험

변경 전 시험은 맵별 보스 피해 설정이 없어 실패했다. 변경 후 Unity 6000.3.21f1 배치에서 세 맵을 각각 선택하고 시험용 설정을 메모리에서 바꿔 실제 1·2단계 사격, 돌진 예고·지속·이동 거리, 위험 반경·예고·반복 피해, 소환 거리·간격·상한을 확인했다. 플레이어와 적의 자동 이동·공격을 통제한 시험이며 설정 자산을 저장하지 않았다.

돌진 거리 시험의 첫 기대값은 기존 적 이동속도 0.5배를 빠뜨려 실패했다. 실제 측정값 1.75는 시험한 속도 7·지속 0.5초에 0.5배를 적용한 결과와 일치했으며, 제품 이동속도를 변경하지 않고 시험 기대값을 수정했다.

기존 20분 전환·강제 보스 처치 승리, 돌진·절단·무적, 위험 구역, 소환·상한 및 부채꼴 사격의 Unity 회귀도 통과했다. 20분 전환 시험은 시간 가속과 플레이어·적 행동 통제를 사용했다. 이 시험에서 외부 충돌 처리기를 의도적으로 비활성화한 동안 적 투사체의 처리기 누락 경고가 기록됐다. Unity 에디터 Search 인덱싱 예외도 배치 시작 시 계속 기록됐다.

## 남은 항목

수치는 확정 밸런스가 아니다. 폐허의 양방향 사격·구획 봉쇄와 습지의 포자 위치 변화 등 맵별 고유 패턴은 아직 구현하지 않았다. 세 맵 보스의 실제 플레이 난도, 화면상 예고 가시성, 보스전 평균 소요 시간과 고밀도 적·투사체 상황도 별도로 확인해야 한다.
