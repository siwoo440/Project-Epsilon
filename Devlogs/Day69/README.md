# 69일차 개발 기록

기존 보스 전투를 재사용해 맵별 패턴과 메뉴 흐름을 보완하고, 합성을 선택 화면 없는 즉시 처리로 변경했다.

---

## 변경 사항

- 폐허 보스는 같은 발사 수의 부채꼴을 전후 양방향으로 발사하고 사각형 구획을 예고한다.
- 습지 보스의 돌진 예고는 이동하는 머리를 따라가며, 돌진 시작 시 방향을 확정한다. 포자 위험의 예고·활성 색상을 구분한다.
- 폐허·습지 보스의 2단계 위험 구역 출현 간격을 맵 데이터에서 조정한다. 기본 배율 0.7은 기획 확정값이 아닌 시험값이다.
- 분리된 메뉴·준비·결과 씬에 화면용 카메라를 만들고, 맵을 이미지가 큰 카드로 표시한다.
- 기존 전투 화면의 시험 조작 문구를 숨기고 설정 화면에 실제 입력을 표시한다.
- 메인 메뉴 뱀의 머리가 아래를 향하는 새 배경을 만들고 메뉴 버튼을 오른쪽에 배치한다.
- E 입력으로 몸통 순서의 첫 번째 동일 포탑·동일 등급 쌍을 바로 합성한다. 기존 첫 재료의 강화는 유지하되 신규 공통 강화는 추가하지 않는다. 보상 포탑 합성도 같은 규칙을 사용한다.

---

## 실행한 검증

- Unity 6000.3.21f1 격리 배치에서 메인·준비·전투·결과 씬 카메라와 전환, 맵 카드 계층, 설정 안내와 기존 HUD 안내 숨김을 확인했다.
- 각 맵의 실제 보스를 시험값으로 구성해 사격, 경고·돌진, 구획과 포자 위험, 반복 피해, 소환과 두 번째 단계 간격을 각각 검증했다. 실제 플레이어와 적의 행동을 통제했다.
- 가상 키보드의 E 입력에 따른 즉시 합성, 속성 갱신, 엘리트 보상의 단일 소비와 연속 레벨업 보상 전환을 Unity 배치로 확인했다. 최초 키 입력 시험은 시험용 입력 설정 복원 오류로 중단됐고 시험 코드를 수정해 재실행했다.
- Unity 시작 중 Search 인덱싱 예외가 기록됐지만 위의 각 시험은 종료 코드 0으로 완료됐다.

---

## 남은 검증

- 세 맵의 실제 보스전에서 장애물과 위험 구역이 만드는 안전 통로, 기존 방전 장치의 보스전 중지, 경고 가독성 및 150마리 부하를 검증해야 한다.
- 기존 합성 선택 화면을 가정하는 과거 배치 스크립트는 현재 규칙에 맞게 갱신해야 한다.
- 화면 배치와 이미지의 실제 표시 품질은 Unity 에디터에서 직접 확인해야 한다.
