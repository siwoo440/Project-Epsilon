# 70일차 캐릭터·콘텐츠 점검

여섯 캐릭터의 시작 능력과 영구 성장 비용을 검증하고, 5분에 등장할 일반 적 쇠똥구리를 기존 전투와 출현 체계에 추가했다. 콘텐츠 완성 판정은 아직 보류한다.

---

## 구현과 확인

- 여섯 캐릭터의 시작 몸통·체력·이동·회전·스태미나, 시작 포탑과 패시브를 실제 씬에서 확인했다.
- 영구 성장 메뉴에 모든 단계를 구매하는 데 남은 코어를 표시한다. 비용은 기존 단계별 비용을 사용하며 신규 상태 기준 468코어다.
- 메인 메뉴의 기존 오른쪽 버튼과 중복되던 왼쪽 영구 성장 버튼을 독립 화면에서 숨겼다. 이전 단일 씬의 버튼은 유지한다.
- 쇠똥구리는 5분부터 일반 적으로 출현한다. 기본 체력 30, 피해 14, 이동 배율 0.85, 공격 주기 2.4초, 경험치 2와 0.6초 돌진 예고를 맵과 별개의 웨이브 데이터에서 조정한다. 돌진 지속 0.6초와 속도 3배는 임시값이다.
- 일반 돌진은 엘리트 전용 몸통 절단을 사용하지 않는다. 기존 공용 HP, 직접 충돌, 분 단위 능력치 증가, 경험치 드롭과 적 상한을 재사용한다.
- 범위 공격 도중 연쇄 처치로 활성 대상 목록이 바뀔 때 발생한 예외를 수정했다. 중첩 공격마다 독립 목록을 재사용하고 새 적 설정도 전투 기록에 포함한다.
- 0~5분과 5~10분에 기획서의 적 출현 가중치를 적용한다. 아직 구현되지 않은 적의 가중치는 합산하지 않으므로 10분 이후의 실제 비율은 기획서 원표와 다르다.
- 기존 적과 같은 화풍의 쇠똥구리 이미지를 생성하고 적 이미지 표에 실제 파일명과 함께 기록했다.

---

## 검증

- Unity 격리 배치에서 여섯 캐릭터의 실제 시작 설정과 패시브를 통과했다.
- 영구 성장의 초기 비용, 구매·저장 복원·실패·무료 초기화·전체 구매를 배치로 확인했다. 비용 시험은 기능 추가 전 실패하고 추가 후 통과했다.
- 쇠똥구리의 5분 경계, 출현 비율 표본, 예고·돌진, 몸통 비절단, 시간별 체력, 경험치 보석 두 개와 예고 재질 정리를 통제 배치로 확인했다.
- 일반 웨이브 경계와 소급 능력치 회귀가 통과했다. 엘리트 일정 시험은 최초 가속 실행에서 통제되지 않은 피해로 중단됐으며, 실제 충돌 처리기와 임시 무적을 사용한 통제 조건에서 4·8·12·16분 일정과 보상을 다시 검증했다.
- 첫 5분 자동 조작 시험은 생존·레벨업·엘리트 보상까지 도달했으나 범위 공격 예외 두 건이 있어 정상 통과로 판정하지 않았다. 수정 후 연쇄 제거·중첩 반응·새 대상 생성·예외 복구 배치가 통과했다.
- 오류 감시를 켠 재시험은 게임 시간 300초에 자연 처치 215회, 레벨 11, 몸통 13칸으로 종료됐다. 4분 엘리트의 자연 처치와 보상 선택 1회를 확인했으며 전투 중 오류는 감지되지 않았다. 가상 입력을 사용한 단일 배치 결과다.
- Unity Editor Search 인덱싱 예외는 배치 시작 중 기록됐다. 메뉴와 문서 표의 실제 렌더링은 직접 확인하지 않았다.

---

## 남은 작업

- 일반 적은 현재 4종, 엘리트는 1종이다. 기획서 목표인 일반 적 8종·엘리트 4종에 미달하며 남은 행동과 이미지를 구현해야 한다.
- 사용자 확정 보스 전환은 20분이다. 기획서의 20분·25분 신규 적 및 30분 생존 기준은 이 방향과 충돌하므로 시간을 임의 변경하지 않았다.
- 20분 보스 승리의 기본 코어는 생존 10개와 보스 5개로 15개다. 처치·엘리트 보상이 추가되므로 평균 해금 속도는 자연 플레이 기록 없이 확정할 수 없다.
- 3맵 보스전 안전 통로, 고밀도 부하, 직접 조작과 실제 화면 표시를 추가로 검증해야 한다.
