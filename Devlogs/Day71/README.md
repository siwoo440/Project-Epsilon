# 71일차: 이미지와 실제 데이터 연결 대조

## 확인 결과

| 구분 | 확인 결과 | 남은 작업 |
| --- | --- | --- |
| 포탑 | 48개 데이터와 보상 목록의 이미지 연결 확인, 실제 그림은 `WeaponTurret_Casual.png` 1종 공유 | 개별 포탑 시각 구분 |
| 캐릭터 | 6개 캐릭터의 시작 포탑 후보와 해당 이미지 연결 확인 | 캐릭터별 실제 화면 확인 |
| 맵 바닥 | 3개 맵 프로필의 바닥 Sprite 연결 확인 | 실제 화면과 해상도별 표현 확인 |
| 맵 요소 | 33개 PNG가 Unity Sprite로 가져와짐 | 플레이 중 배치, 충돌 범위, 경고 표시 확인 |
| 신규 이미지 | 메뉴 배경과 쇠똥구리 원본을 기획서 13.6, 13.3에 각각 반영 | 실제 화면 확인 |
| 이전 무기 이미지 | 무기 시안은 존재하지만 48개 기본 포탑은 공용 이미지를 사용 | 새 포탑 형태의 이미지 제작·적용 |

기획서 15탭에 실제 연결 상태와 확인 한계를 표로 추가했다. 기획상 파일명과 다른 파일명은 미구현의 증거가 아니며, UI와 효과 일부는 코드로 생성된다. 기획서의 이미지 표는 구조적으로 다시 읽어 확인했고 문서 화면 렌더링은 확인하지 못했다.

## 배치 검증

- Unity 6000.3.21f1, 격리된 프로젝트 복사본, `AutomatedDay71AssetAudit.Run`: 통과.
- 기본 포탑 48개 및 보상 목록 일치, 고유 포탑 이미지 1개, 캐릭터 6개, 맵 3개, 맵 요소 Sprite 33개를 확인했다.
- 이 검사는 데이터 참조와 가져오기 설정을 확인하며 화면 품질, 장애물 배치, 시각적 가독성이나 직접 플레이를 검증하지 않는다.
- 일반 적 8종 중 4종, 엘리트 4종 중 1종만 구현되어 있다. 보스전의 혼잡 상황 탈출 및 성능 검증도 남아 있다.
