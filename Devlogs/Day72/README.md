# 72일차: 기획서 기준 포탑별 이미지 연결

## 적용 내용

- 기획서 13.2탭의 포탑별 장착 시안 48개를 확인해 각 포탑 데이터에 연결했다.
- 강철 기본 3종과 화염 기본 3종은 각 기획 시안을 참조해 다시 생성했다. 나머지 42종은 기획서에 삽입된 해당 원본 시안을 사용했다.
- 48개 포탑에 각각 다른 장착 그림과 UI 아이콘을 연결했다. 몸통은 장착 그림을, 시작 선택·오른쪽 패널·보상 카드는 UI 아이콘을 사용한다.
- UI 아이콘 38종은 기획서 원본을 사용한다. 접근이 거부된 10종은 해당 포탑의 기획서 장착 시안을 참조해 재생성했다.
- 재생성 아이콘: 냉기 속사 근접, 독 범위·근접·직사, 폭발 직사·파동, 신성 속사 근접·파동, 암흑 직사·파동.
- 별도 아이콘이 없는 기존 포탑 데이터는 장착 그림을 대체 아이콘으로 사용한다. 아이콘 가져오기 최대 크기는 512로 설정했다.
- 원본에 이미 속성 색이 들어 있으므로 몸통과 UI에서 추가 색상 곱셈을 제거했다. 탄과 공격 효과에 쓰는 속성 색상은 유지한다.
- 기획서 13.2와 15탭에 재생성·원본·UI 공유 상태를 구분해 기록했다. 문서 화면 자체의 시각 검증은 하지 않았다.

## 검증

- Unity 6000.3.21f1의 격리된 복사본 배치에서 포탑 48개, 서로 다른 장착 그림 48개와 아이콘 48개, 데이터 참조, 단일 Sprite 가져오기, 중앙 피벗, 원본 색상 설정을 확인했다.
- 실제 전투 씬 배치에서 몸통 위 이미지, 오른쪽 패널 교체·합성, 보상 카드 그림, 기본 이미지와 보석·바닥 연결을 확인했다.
- 48개 포탑 데이터와 보상 목록, 실제 몸통 위치, 피해·쿨타임·상태 이상·투사체 명중·초기 적의 경험치 회귀 검사가 통과했다.
- 플레이 모드 배치 시작 시 Unity Editor Search의 `ArgumentOutOfRangeException`이 기록됐다. 스택은 Unity Editor 검색 색인에 있으며, 해당 배치의 게임 검사는 통과했다.

## 남은 확인

- Unity 화면에서 48종의 작은 표시 크기, 뱀 몸통과의 겹침, 회전 중심 및 밝은 색 배경에서의 가독성을 직접 확인해야 한다.
- 각 포탑의 공격 표현 구분은 남았다.
- 일반 적 8종 중 4종과 엘리트 4종 중 1종만 구현되어 있고, 보스전 혼잡 상황·부하 시험도 남았다.
