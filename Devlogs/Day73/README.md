# 73일차: 사격 예고와 경고 표시 순서

## 변경 내용

- 기존 적의 빨간 피격 점멸과 엘리트·보스 돌진 예고를 확인해 재사용했다.
- 일반 사수가 발사 전 목표 방향을 주황색 선으로 표시한다. 예고 시작 시간은 적 설정의 `projectileWarningDuration`이며 기본 시험값은 0.35초다.
- 예고 방향은 실제 몸통 목표를 따라가고, 길이는 목표까지 거리와 투사체의 최대 이동 거리 중 짧은 쪽이다. 발사 시점과 공격 간격은 바꾸지 않았다.
- 넉백 중에는 이전 사격 예고를 숨기고, 넉백이 끝나 예고 구간이 남아 있으면 다시 표시한다. 행동 비활성화 시에도 예고를 숨긴다.
- 일반 적과 보스의 돌진·위험 구역 예고를 포탑 이미지보다 위의 정렬 순서로 표시한다. 보스의 기존 부채꼴 사격에는 일반 사수 예고를 추가하지 않는다.

## Unity 배치 검증

- 실제 전투 씬 사수의 예고 방향 갱신, 투사체 도달 거리, 발사 후 숨김, 공격 간격 유지, 넉백 및 비활성 정리: 통과.
- 쇠똥구리 예고·피해·경험치와 재질 정리, 일반 적·엘리트·보스 이미지 방향: 통과.
- 보스 부채꼴 투사체, 돌진 예고·일시정지·피해·절단, 위험 구역 예고·주기 피해·제거: 통과.
- 보스 돌진선과 위험 구역 선의 정렬 순서가 포탑보다 높은지 확인했다. 실제 혼잡한 화면에서의 가독성은 확인하지 못했다.
- 플레이 모드 배치 시작 시 Unity Editor Search의 `ArgumentOutOfRangeException`이 기록됐다. 해당 배치의 게임 검사는 통과했다.

## 남은 작업

- 기획서의 적별 이동·공격·피격·사망 애니메이션 파일과 별도 VFX 이미지는 제작하지 않았다.
- 일반 적 4종과 엘리트 3종의 미구현분, 다수 적과 보스가 겹치는 실제 화면의 가독성·성능 검증이 남았다.
