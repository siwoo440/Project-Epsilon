# 74일차: 긴 경험치 수치의 HUD 겹침 방지

## 수정 내용

- 레벨과 경험치는 같은 화면 영역에서 각각 왼쪽·오른쪽 정렬을 사용한다. 큰 수치를 표시하면 두 문구가 서로 겹치는 문제를 확인했다.
- 두 문구가 같은 영역을 공유할 때만 필요한 만큼 경험치 글자부터 축소하고, 그래도 공간이 부족하면 레벨 글자도 축소한다. 최소 크기는 원래 크기와 14 중 작은 값이다.
- 일반 수치가 돌아오면 원래 크기로 복원한다. 경험치 게이지의 전체 너비와 현재 비율은 변경하지 않는다.
- 서로 다른 영역에 배치된 레벨·경험치 글자의 크기는 변경하지 않는다.

## 검증

- Unity 6000.3.21f1 격리 복사본에서 긴 수치의 기존 겹침을 재현했다. 필요 너비 486.046, 사용 가능 너비 420이었다.
- 수정 후 같은 시험은 필요 너비 376.927, 사용 가능 너비 420으로 통과했다. 경험치 50% 채움, 전체 막대 너비, 일반 수치 복귀 시 기본 글자 크기를 확인했다.
- 몸통 우측 패널, 보상 카드, 캐릭터·맵 선택과 전투·결과 씬 전환 회귀 검사가 통과했다.
- 씬 전환 시험의 첫 실행은 기존 배치 저장소의 맵 해금 기록 때문에 실패했다. 별도 제품명의 새 격리 저장 공간으로 실행해 통과했다.
- Unity 비대화형 실행은 1920×1080 인자를 주어도 실제 화면 크기로 640×480을 보고했다. 따라서 이 결과는 1920×1080 시각 검증이 아니다.
- 플레이 모드 배치 시작 시 Unity Editor Search의 `ArgumentOutOfRangeException`이 기록됐다. 해당 게임 검사는 통과했다.

## 남은 작업

- 실제 1920×1080 게임 화면에서 글자 크기·겹침·아이콘과 메뉴 가독성을 직접 확인해야 한다.
- 적별 애니메이션, 별도 VFX, 일반 적과 엘리트의 미구현분 및 혼잡 상황 성능 검증이 남았다.
