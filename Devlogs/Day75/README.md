# 75일차: 첫 플레이 튜토리얼과 이후 개발 일정

## 변경 내용

- 첫 전투 시작 시 기존 메뉴 흐름을 이용해 8단계 안내를 표시한다. 회전·자기 충돌·몸통 체력·자동 공격·몸통 포탑·즉시 합성·속성·가속을 설명한다.
- 현재 설정된 회전·가속 키와 방향키를 안내한다. 마지막 단계는 20분 생존 후 최종 보스 처치를 안내한다.
- 안내 중 전투를 일시정지한다. 이전·다음·건너뛰기와 ESC를 지원하고 완료 상태를 별도 설정 키에 저장한다.
- 설정의 다시 보기에서 안내를 연 경우 기존 설정 화면으로 돌아가며, 기존 수동 일시정지를 안내가 임의로 해제하지 않는다.
- 현재 구현은 버튼으로 읽는 안내 페이지다. 조작이나 전투 행동을 직접 수행해야 다음 단계로 넘어가는 실습형 조건은 구현하지 않았다.
- 기획서 12탭의 이후 일정을 검사·배포 전용 일차 없이 75~85일차 기능 개발로 재편했다. 개미귀신 15분, 장수풍뎅이 18분 출현은 확정 방향이며 79일차 구현 예정이다. 변경된 출현 비율은 미확정이다.

## Unity 배치 검증

- 8개 안내 페이지, 실제 키와 합성·보스 문구, 완료 저장, 건너뛰기, 설정에서 다시 보기, ESC와 기존 일시정지 유지: 통과.
- 별도 Unity 프로세스 재시작 후 완료된 안내의 자동 재표시 방지: 통과.
- 실제 메인 메뉴 → 캐릭터·맵·포탑 선택 → 첫 전투 안내 → 건너뛰기 → 전투 진입: 통과.
- 최신 즉시 합성, 엘리트 보상, 연속 레벨업과 독립 씬 전환 회귀 검사: 통과.
- 이전 `AutomatedLevelRewardMergeVerification`은 삭제된 합성 선택 화면과 70% 게임 속도를 기대해 실패했다. 현행 규칙은 `AutomatedInstantMergeVerification`으로 확인했다. 이전 시험의 나머지 사례를 현재 규칙으로 이관하는 작업은 남았다.
- 배치 시작 시 Unity Editor Search의 `ArgumentOutOfRangeException`이 기록됐다. 위에서 통과로 표시한 게임 검사는 각각 성공 종료했다.

## 직접 확인할 내용

- 안내 화면의 실제 가독성·입력과 1920×1080 배치를 Unity에서 직접 확인해야 한다.
- 현재 튜토리얼은 안내문을 읽는 방식이므로 직접 조작을 연습하는 단계와 별도 안내 이미지·음성은 아직 없다.
