# 76일차: 전투 효과음

- 포탑 공격, 플레이어 피격, 몸통 손실, 합성, 레벨업, 엘리트 출현, 보스 전환 이벤트에 임시 효과음을 연결했다.
- 음원, 개별 음량, 반복 재생 간격은 `GameplaySoundSettings` 에셋에서 조정하며 기존 전체 음량 설정을 유지한다.
- 효과음 일곱 개는 코드로 생성한 임시 합성음이다. 실제 청취나 최종 믹스는 완료하지 않았다.
- 컴포넌트 비활성화 시 이벤트 구독을 해제하며, 씬 전환 시 이벤트 대상을 다시 찾는다.

## Unity 비대화형 배치

- `AutomatedDay76GameplaySoundVerification`: 실제 이벤트 일곱 종류, 동일 프레임 공격음 제한, 전체 음량 값 유지, 비활성화 후 구독 해제 통과. 재생 요청을 검증했으며 실제 청취를 대체하지 않는다.
- `AutomatedInstantMergeVerification`: 즉시 합성, 속성 시너지, 보상과 연속 레벨업 흐름 통과.
- `AutomatedDay75TutorialVerification`: 최초 안내, 건너뛰기, 설정 다시 보기, 저장과 일시정지 소유권 통과.
- `AutomatedSceneSeparationVerification`: 메뉴, 준비, 전투와 결과 씬 흐름 통과.
- 안내와 씬 회귀 검사는 처음에 격리 저장 이름과 실행 인자를 잘못 지정해 실패했으며, 올바른 조건으로 재실행해 통과했다.
- 배치 시작 과정에서 기존 Unity 검색 데이터베이스의 `ArgumentOutOfRangeException`이 기록됐다. 위 시험들은 해당 로그가 있는 상태에서 완료됐으며 원인은 별도 확인이 필요하다.

## 남은 사항

- 실제 스피커나 헤드폰으로 음량·반복감·음질 확인 및 최종 음원 교체.
- 씬 전환 후 효과음 재연결과 일시정지 중 청감은 직접 플레이에서 추가 확인.
- 메뉴·맵·보스 배경음은 77일차 범위.
