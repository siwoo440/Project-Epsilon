# 77일차: 메뉴·맵·보스 배경음

- 메뉴·준비·결과, 평원·폐허·습지 전투, 보스 전환에 반복 배경음을 연결했다.
- 실제 맵 선택과 보스 출현 이벤트를 사용하며 장면별 음원과 배경음 음량은 데이터 에셋에서 교체·조정한다. 기존 전체 음량 설정을 유지한다.
- 메뉴에 오디오 수신기가 없는 경우 기존 카메라 또는 생성된 화면 카메라에 수신기를 연결한다.
- 다섯 곡은 코드로 생성한 임시 합성음이다. 실제 청취와 최종 작곡은 완료하지 않았다.

## Unity 비대화형 배치

- `AutomatedDay77MusicVerification`: 평원 기본 선택, 선택 번호를 재현한 폐허·습지 음악, 실제 보스 전환, 실제 메뉴·준비 씬 음악과 수신기, 반복 설정, 저장된 전체 음량 유지 통과.
- `AutomatedDay76GameplaySoundVerification`: 공격·피격 등 기존 효과음 이벤트 통과.
- `AutomatedSceneSeparationVerification`: 메인 메뉴·준비·전투·결과 씬 흐름 통과.
- 확장한 음악 검사의 첫 실행은 화면 준비 전 버튼을 조회하고 실제 관리자 정리 경로를 거치지 않아 실패했다. 기존 씬 전환 경로와 화면 준비 대기를 사용해 재실행한 결과 통과했다.
- 플레이 모드 시작 시 기존 Unity 검색 데이터베이스 `ArgumentOutOfRangeException`이 기록됐다. 시험은 해당 로그가 있는 상태로 완료됐으며 원인은 별도 확인이 필요하다.

## 남은 사항

- 직접 청취를 통한 음질·음량·장면 전환 확인과 최종 곡 교체.
- 장면 변경 시 부드러운 음량 전환은 아직 구현하지 않았다.
- 폐허와 습지는 배치에서 맵 선택 번호를 직접 설정해 음원 매핑을 확인했으며, 해금부터 출격까지의 수동 청취는 진행하지 않았다.
