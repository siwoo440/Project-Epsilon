# 78일차: 노린재와 잠자리

- 기획서의 원본 이미지와 기본 능력치를 사용해 기존 웨이브·적 전투·경험치 보상에 노린재(10분)와 잠자리(15분)를 추가했다. 기존 전체 적 이동 속도 절반 규칙을 유지한다.
- 노린재는 2.8초 간격으로 3초 지속되는 감속 지대를 생성한다. 반경 1.3과 이동 배율 0.8은 기획서에 구체값이 없어 데이터에 둔 임시값이다. 중첩 지대는 가장 강한 감속만 적용하며, 지형 전용 면역은 적 감속을 해제하지 않는다. 보스 전환 시 지대는 정리된다.
- 잠자리는 기존 트리거 이동과 몸통 접촉 피해·공용 체력·충돌 우선순위 및 경험치 보상을 재사용한다. 신규 적별 애니메이션은 아직 없다.
- 10~15분과 15~20분 출현 가중치는 기존 기획서 값을 사용했다. 개미귀신·장수풍뎅이 시점 변경에 따른 가중치는 미확정이며 79일차에 별도로 처리한다.

## Unity 비대화형 배치

- `AutomatedDay78EnemyVerification`: 10분·15분 경계, 실제 가중치 추첨, 원본 이미지, 노린재 지대 생성·지속 시간 설정·중첩·지형 면역 구분·보스 전환 정리, 잠자리 트리거 구성·몸통 접촉 피해·경험치 설정 통과. 시간 경계와 지속 종료는 테스트에서 시각을 조정해 확인했다.
- `AutomatedDay70BeetleVerification`: 5분 쇠똥구리·추첨·예고·경험치 회귀 통과. 기존 검사는 추가 적이 한 종류라고 가정해 처음 실패했고 조건을 수정한 뒤 재실행했다.
- `AutomatedEnemyWaveStagesVerification`: 출현 구간·분 단위 능력치와 기존 생존 적 갱신 통과.
- `AutomatedDay46ZonesVerification`: 지형 감속·경험치·위험·회복·일시정지 회귀 통과.
- 플레이 모드 시작 시 기존 Unity 검색 데이터베이스 `ArgumentOutOfRangeException`이 기록됐다. 시험은 해당 로그가 있는 상태로 완료됐으며 원인은 별도 확인이 필요하다.

## 남은 사항

- 자연 플레이에서 10분과 15분 출현, 다수 적과 중첩된 지대의 시인성·성능, 장시간 플레이 밸런스 확인.
- 실제 해금된 세 맵에서 잠자리 이동 경로와 장애물 통과를 직접 확인. 배치는 트리거 구성과 몸통 피해를 확인했으며 실제 경로 전체를 재현하지 않았다.
- 노린재·잠자리 전용 애니메이션 및 79일차 개미귀신·장수풍뎅이와 가중치 정리.
