# 79일차: 개미귀신과 장수풍뎅이

- 사용자 확정 시각에 따라 개미귀신은 15분, 장수풍뎅이는 18분부터 등장한다. 기존 20분 보스 전환, 적 이동 속도 절반 및 분 단위 체력·공격력 성장은 유지한다.
- 기획서 원본 이미지를 사용하고 기존 적 출현, 피해, 처치·경험치 보상을 재사용한다.
- 개미귀신은 기존 사수의 예고·투사체 경로로 세 발을 부채꼴 발사한다. 3발·전체 40도는 문서에 구체값이 없어 데이터에 둔 시험값이다. 예고에는 중앙과 양쪽 경계를 표시한다.
- 장수풍뎅이의 넉백 거리 배율 0.5는 조정 가능한 시험값이다. 일반 적의 기존 거리와 보스 완전 면역은 유지한다.
- 출현 시점 변경 후의 비율은 사용자 답변에 따라 각 8%를 적용하고 병정개미 비율에서 차감했다. 15~18분 병정개미는 24%, 18~20분은 16%다. 확정 밸런스가 아니다.

## Unity 비대화형 배치

- `AutomatedDay79EnemyVerification`: 15분·18분 경계, 원본 스프라이트, 실제 사격 3발과 부채각, 중앙·양쪽 경고와 발사 후 제거, 장수풍뎅이 부분 저항, 기존 씬 적의 넉백과 완전 면역, 경험치 설정, 15~20분 매 분 성장 유지 통과. 출현 시각은 시험에서 조정했다.
- `AutomatedDay78EnemyVerification`: 노린재·잠자리 출현, 감속·몸통 피해 회귀 통과.
- `AutomatedDay73ShooterWarningVerification`: 기존 사수 예고 회귀 통과.
- `AutomatedPhysicalExplosionReactionVerification`: 물리·폭발 반응과 기존 넉백 회귀 통과.
- `AutomatedEnemyWaveStagesVerification`: 기존 웨이브 경계와 분 단위 능력치 갱신 회귀 통과.
- 플레이 모드 시작 시 기존 Unity 검색 데이터베이스 `ArgumentOutOfRangeException`이 기록됐다. 시험은 해당 로그가 있는 상태로 완료됐으며 원인은 별도 확인이 필요하다.

## 남은 사항

- 자연 플레이의 15·18분 출현, 발사 예고 가시성·공격 회피, 장수풍뎅이 저항 체감과 다수 적 성능 확인.
- 출현 비율·사격 수와 각도·넉백 저항률의 플레이 기반 조정과 전용 애니메이션 제작.
- 80일차 전용 엘리트 개발.
