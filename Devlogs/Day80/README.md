# 80일차: 원거리 봉쇄형·소환형 엘리트

81일차부터 8·12분 회차는 전용 후보와 강화형을 시험 확률로 선택한다.

- 기존 8분 회차에 원거리 봉쇄형, 12분 회차에 소환형을 연결하고 기획서의 원본 이미지를 적용했다. 기존 4분 돌진형, 엘리트 동시 상한·대기열·선택 보상·20 경험치 보석 및 20분 보스 전환을 유지한다.
- 상세 패턴과 출현 풀은 기획서에서 미정이므로 회차와 능력치는 시험안이다. 원거리형은 3발·60도·0.6초 예고이며, 소환형은 6초 간격·최대 3마리·거리 2다. 모두 데이터에서 조정한다.
- 기존 보스 소환 코드를 재사용하며, 엘리트가 소환한 적은 무보상이고 일반 적 상한에 포함된다. 소환형 처치 또는 보스 전환 시 남은 소환 적을 제거한다.
- 79일차 일반 적 출현 비율은 이후 사용자 답변에 따라 개미귀신과 장수풍뎅이 각각 8%를 유지하고 병정개미 비율에서 차감한다.

## Unity 비대화형 배치

- `AutomatedDay80EliteVerification`: 4분 기존 엘리트, 8분 회차 대기·출현, 12분 두 번째 엘리트, 실제 사격, 일반 적·소환자별 상한, 무보상 소환, 엘리트 사망 보상과 소환 정리, 보스 전환 정리 통과. 일정은 시험에서 시각을 조정했다.
- `AutomatedBossSummonVerification`: 기존 보스 소환·상한·일시정지·승리 시 정리 통과.
- `AutomatedDay79EnemyVerification`: 15·18분 일반 적, 사격, 넉백·성장 회귀 통과.
- `AutomatedDay73ShooterWarningVerification`: 기존 사수 예고 회귀 통과.
- `AutomatedEnemyHalfSpeedVerification`: 일반 적·기존 엘리트 돌진과 보스의 절반 속도 회귀 통과.
- 플레이 모드 시작 시 기존 Unity 검색 데이터베이스 `ArgumentOutOfRangeException`이 기록됐다. 시험은 해당 로그가 있는 상태로 완료됐으며 원인은 별도 확인이 필요하다.

## 남은 사항

- 자연 플레이의 8·12분 엘리트 출현, 다수 적과 경고 가시성, 소환 위치·난이도·성능 확인.
- 전용 패턴·회차·수치 최종 설계와 전용 애니메이션 제작.
- 81일차 몸통 압박형과 일반 적 강화형 엘리트.
