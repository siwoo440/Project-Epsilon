# 81일차: 몸통 압박형과 일반 적 강화형

- 16분 회차의 전용 후보에 가장 가까운 몸통을 추적하고 접촉 시 공용 체력에 피해를 주는 압박형을 추가했다. 기획서 원본 이미지를 사용하며, 기본 체력·피해·속도와 접촉 주기 1.5초는 조정 가능한 시험값이다.
- 4분 첫 돌진형은 고정하고, 8·12·16분 각 회차에서는 현재 해금된 일반 적 강화형을 25% 시험 확률로 선택한다. 해당 확률에 대한 사용자 답변을 기다리는 동안 적용한 임시안이다. 그 외에는 기존 전용 회차를 사용한다.
- 일반 적 8종의 기획서 강화형 이미지를 적용했다. 원본의 추적·사격·돌진·감속·넉백 저항을 유지하며 기본 체력 3배·공격력 1.5배를 적용한 뒤 기존 분 단위 성장을 적용한다. 강화 배율도 시험값이다.
- 강화형은 기존 엘리트 수 제한, 원거리 정리 제외, 선택 보상 및 대형 경험치 보석을 재사용한다. 일반 적의 원본 데이터는 변경하지 않는다.

## Unity 비대화형 배치

- `AutomatedDay81EliteVerification`: 강화형 확률을 시험에서 0으로 설정하고 16분 전용 후보의 출현·최근접 몸통 추적·공용 체력 피해 통과.
- `AutomatedDay81EnhancedVerification`: 원본 이미지 8종, 종류별 기본 행동과 강화 배율, 실제 사격·돌진 예고·감속 지대·넉백 저항, 시간별 능력치, 엘리트 상한·선택 보상·대형 보석, 4분 고정과 후속 강화형 강제 선택 통과. 확률 25% 자체의 장기 분포는 측정하지 않았다.
- `AutomatedDay80EliteVerification`: 강화형 확률을 시험에서 0으로 설정하고 기존 8·12분 전용 회차, 소환과 보상 회귀 통과.
- `AutomatedDay79EnemyVerification`, `AutomatedDay70BeetleVerification`, `AutomatedBossSummonVerification`: 기존 일반 적, 쇠똥구리, 보스 소환 회귀 통과.
- 플레이 모드 시작 시 기존 Unity 검색 데이터베이스 `ArgumentOutOfRangeException`이 기록됐다. 시험은 해당 로그가 있는 상태로 완료됐으며 원인은 별도 확인이 필요하다.

## 남은 사항

- 자연 플레이에서 출현 분포, 몸통 추적의 회피 가능성, 8종 강화형의 난이도·성능 및 경고 가시성 확인.
- 출현 확률과 강화 배율의 사용자 답변 및 플레이 결과 반영.
- 82일차 적·보스 이동·공격·피격·사망 애니메이션.
