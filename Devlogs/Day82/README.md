# 82일차: 적·보스 임시 모션

- 기존 정적 적·엘리트·보스 스프라이트에 공통 이동·공격 모션을 연결했다. 표시용 자식 스프라이트만 변형해 기존 충돌체 크기와 물리 이동·회전을 유지한다.
- 실제 사격, 접촉, 돌진, 감속 지대, 보스 소환·위험 구역 이벤트에서 공격 모션을 시작한다. 기존 빨간 피격 표시와 화상 색상은 원래 표시기에서 시각 자식으로 동기화한다.
- 실제 처치 이벤트에서 충돌체·전투 대상이 없는 짧은 사망 표시를 생성한다. 기존 적 제거, 경험치와 엘리트 보상은 지연하지 않는다.
- 공통 임시 모션이며 기획서의 적별 전용 프레임·`.anim` 에셋을 제작한 것은 아니다.

## Unity 비대화형 배치

- `AutomatedDay82MotionVerification`: 표시·충돌체 분리, 이동·공격 표시, 비활성화 후 복구, 빨간 피격과 화상 색상 동기화, 일시정지, 즉시 처치와 보상, 무충돌 사망 표시, 실제 사수 발사와 보스 돌진·소환·위험 구역 모션 통과.
- `AutomatedSizeAndHitVerification`, `AutomatedEnemyArtVerification`: 기존 크기·빨간 피격 복구·적과 보스 이미지 및 방향 회귀 통과.
- `AutomatedDay81EnhancedVerification`, `AutomatedDay80EliteVerification`: 강화형과 전용 엘리트 출현·행동·보상 회귀 통과.
- `AutomatedFirePoisonReactionVerification`, `AutomatedBossSummonVerification`: 화염·독 반응과 기존 보스 소환 회귀 통과.
- 시험 코드를 처음 작성했을 때 형식 변환 컴파일 오류가 발생해 수정했고, 이후 실제 모션 부재를 재현한 뒤 구현 및 재검증했다.
- 플레이 모드 시작 시 기존 Unity 검색 데이터베이스 `ArgumentOutOfRangeException`이 기록됐다. 시험은 해당 로그가 있는 상태로 완료됐으며 원인은 별도 확인이 필요하다.

## 남은 사항

- 실제 화면에서 이동·공격·피격·사망 모션의 크기와 속도, 보스전 표시 순서 및 다수 적 환경의 성능 확인.
- 기획서의 적별·보스별 전용 프레임과 `.anim` 에셋, 보스 2단계 전용 모션 제작.
- 83일차 속성·반응 VFX.
