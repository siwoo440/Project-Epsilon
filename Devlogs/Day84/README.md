# 84일차: 맵별 보스 이미지와 장애물 보호

- 기획서의 폐허·습지 보스 원본 이미지를 각각 맵 데이터에 연결했다. 평원은 기존 보스 이미지를 유지한다. 원본 색상을 유지하며, 이미지가 지정되지 않은 맵은 씬의 기본 보스 이미지로 되돌아간다.
- 일반 장애물의 무작위 생성에도 기존 개미굴 흙무더기의 몸통·꼬리 보호 거리 1.5를 공통 적용했다. 현재 몸통 위치를 보호하는 규칙이며 앞으로의 모든 이동 경로에서 탈출을 보장한다는 뜻은 아니다.
- 기획서의 현행 규칙과 충돌하던 30분 보스 문구를 20분으로 고치고, 15·18분 적의 각 8% 출현과 병정개미 비율 차감 기준을 반영했다. 과거 30분 성장 목표는 확정 수치로 바꾸지 않고 과거 시험안으로 구분했다.

## Unity 비대화형 배치

- `AutomatedDay84ObstacleVerification`: 수정 전 실제 몸통 위에 장애물이 생성되는 실패를 확인한 뒤, 몸통·꼬리 보호와 빈 위치의 정상 생성을 통과했다.
- `AutomatedDay84BossArtVerification`: 세 맵의 실제 보스 생성, 원본 색상, 맵 그림 교체 및 기본 그림 복원과 탄환 그림 보존을 각각 통과했다.
- `AutomatedRandomMapLayoutVerification`: 맵별 32개 난수와 통로·장애물 배치 통과.
- `AutomatedAntHillLayoutVerification`: 개미굴 28곳의 주변 배치 통과.
- `AutomatedMapLongBodyTraversalVerification`: 세 맵에서 몸통 20칸의 통제된 한 번의 회전·이탈 통과.
- `AutomatedDay46MapsVerification`: 평원의 실제 보스 사격·돌진·위험 구역과 단계별 설정 통과.
- `AutomatedMapTimedHazardsVerification`: 60초 외부 대기 제한에 도달해 결과를 얻지 못했다. 통과로 간주하지 않는다.
- Unity 시작 시 기존 검색 데이터베이스 `ArgumentOutOfRangeException`이 기록됐다. 원인은 별도 확인이 필요하다.

## 남은 사항

- 폐허·습지 보스 패턴과 위험 구역의 회귀 시험, 실제 이미지 방향·크기와 경고 표시의 화면 확인.
- 자연 플레이에서 긴 몸통과 고밀도 적·보스 상황의 출구 및 성능 확인. 특정 통제 회전만으로 모든 경로의 안전을 보장할 수 없다.
- 20분 기준의 레벨·포탑 성장 목표는 확정되지 않았다.
