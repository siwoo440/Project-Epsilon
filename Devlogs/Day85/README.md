# 85일차: 캐릭터 선택 초상화

- 기획서의 여섯 캐릭터 선택 초상화 원본을 각 캐릭터 데이터에 연결했다. 선택한 캐릭터가 바뀌면 선택 화면의 초상화도 바뀐다.
- 초상화가 지정되지 않은 기존 캐릭터는 공통 머리·몸통 미리보기를 유지한다. 기획서에서 미확정인 전투 중 머리·몸통·꼬리 변형은 추가하지 않았다.
- 캐릭터의 시작 능력치, 패시브, 해금 조건과 시작 포탑은 기존 구현을 유지했다.

## Unity 비대화형 배치

- `AutomatedDay85CharacterPortraitVerification`: 독립 저장에서 기동형을 해금하고 여섯 캐릭터의 실제 버튼 선택과 기획서 초상화 연결을 통과했다. 수정 전에는 초상화 연결 누락으로 실패했다.
- `AutomatedCharacterRuntimeVerification`, `AutomatedCharacterDataVerification`: 여섯 캐릭터의 시작 수치·패시브·시작 포탑 후보와 전투 중 변경 차단을 통과했다.
- `AutomatedCharacterInputVerification`: 독립 저장에서 폐허만 해금된 상태로 전체 맵 순환을 기대하는 시험이 실패했다. 해당 실행은 통과로 간주하지 않는다.

## 남은 사항

- 실제 화면에서 초상화 크기, 위치와 정보 영역의 겹침을 확인해야 한다.
- 캐릭터별 전투 외형은 머리·몸통·꼬리 변형 범위가 확정된 뒤 적용한다.
