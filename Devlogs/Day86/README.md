# 86일차: 황충떼와 낙석

- 세 맵의 기존 청크 관리자에 공통 위험 이벤트를 연결했다. 황충떼와 낙석은 번갈아 발생하며 보스전에서는 예고와 진행 중 위험을 정리하고 새로 발생하지 않는다.
- 첫 출현 90초, 간격 90초, 예고 3초는 맵 데이터에서 조정하는 시험값이다. 황충은 폭 8, 속도 12, 피해 10을 사용한다. 경고선과 충전 게이지 뒤 생성 이미지 10마리가 두 줄로 직선 이동한다.
- 낙석은 화면에 보이는 안전 후보를 예고한 뒤 0.7초 하강하고 반경 2에 피해 10을 준다. 기존 맵 장애물 이미지와 충돌 처리를 재사용해 최대 3개의 잔해를 만든다. 생성 순간 플레이어와 통로에 겹치는 잔해는 생략한다. 안전 후보가 없으면 해당 출현을 생략하고 다음 간격에 다시 시도한다.
- 실제 충돌 피해는 기존 공용 HP, 무적, 보호막과 물리 충돌 우선순위를 재사용한다. 공격·낙석의 위치와 수치는 최종 밸런스가 아니다.
- 기획서 13.4 맵·환경 에셋 표에 황충 이미지와 파일명을 추가하고 6. 맵 시스템에 시험값을 기록했다. 기획서 문서 구조에서 이미지와 표 내용을 확인했으며 실제 인쇄 배치는 확인하지 못했다.

## 생성 이미지

- `Assets/Resources/WorldEvents/LocustSwarm_Casual.png`: 기본 제공 imagegen 사용. 프롬프트: 기존 장수풍뎅이 스프라이트의 선명한 캐주얼 화풍을 참고한 투명 배경 탑뷰 비행 황충 한 마리, 위쪽을 향한 머리와 펼친 날개, 게임에서 여러 마리로 배치 가능한 완전한 실루엣, 글자·배경 없음.

## Unity 비대화형 배치

- `AutomatedDay86WorldHazardsVerification`: 실제 게임 씬의 맵 위험 관리자와 두 위험 시작 경로 통과. 구현 전에는 관리자 누락으로 실패했다.
- `AutomatedDay86WorldEventsPlayVerification`: 세 맵 각각에서 경고 게이지·일시정지·황충 10마리·피해·기존 무적·낙석 착탄 피해·잔해 3개·몸통과 안전 통로 보호·보스 전환 정리를 통과했다. 화면 밖 낙석 예고 실패를 재현해 화면 안 후보를 선택하도록 수정한 뒤 세 맵에서 재시험했다.
- `AutomatedDay86EventScheduleVerification`: 실제 전투 씬에서 시험용으로 시간을 단축해 두 위험의 자동 교대를 확인했다. 실제 90초 또는 5분 자연 플레이는 실행하지 않았다.
- `AutomatedCollisionPriorityVerification`, `AutomatedRandomMapLayoutVerification`, `AutomatedDay85CharacterPortraitVerification`: 기존 충돌 우선순위, 맵별 무작위 배치와 캐릭터 선택 회귀 통과.
- Unity 시작 시 기존 검색 데이터베이스 `ArgumentOutOfRangeException`이 기록됐다. 원인은 별도 확인이 필요하다.

## 남은 사항

- 실제 화면에서 예고선과 게이지의 위치·크기, 황충 무리 및 낙석 하강의 시인성과 화면 이동 중 경고 위치를 확인한다. 배치 실행은 화면 시각 검증을 대체하지 않는다.
- 장시간 자연 전투와 적이 많은 상황에서 출현 빈도·피해·회피 가능성·성능을 확인한다. 예고 시작 시 착탄 중심의 화면 포함만 확인했고, 이동 중 경고선 전체가 계속 보인다는 보장은 없다.
