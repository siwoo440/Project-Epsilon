# 88일차: 황충떼 이동 방향 예고

- 황충떼가 이동하기 전 기존 경고판에 전투 화면 기준 이동 방향을 표시한다. 카메라 회전과 화면 비율을 반영하며 카메라 또는 방향이 없을 때는 기존 기본 경고를 표시한다.
- 긴 방향 문구가 경고판에 맞도록 기존 글자의 자동 크기 조정을 켰다. 황충의 경로·마릿수·속도·피해와 경고 시간은 유지한다.

## Unity 비대화형 배치

- `AutomatedDay88LocustWarningVerification`: 실제 게임 씬에서 네 방향, 회전된 카메라, 대각선, 카메라·방향 부재와 글자 크기 조정 설정을 통과했다. 변경 전에는 이동 방향과 글자 크기 조정이 각각 누락되어 실패했다.
- `AutomatedDay87RockfallWarningVerification`: 낙석의 화면 밖 8방향과 황충 경고 전환 회귀를 통과했다.
- `AutomatedDay86WorldEventsPlayVerification`: 평원의 황충·낙석 경고, 피해, 무적, 안전 잔해와 보스 전환 회귀를 통과했다.
- Unity 시작 시 기존 검색 데이터베이스 `ArgumentOutOfRangeException`이 기록됐다. 원인은 별도 확인이 필요하다.

## 남은 사항

- 실제 화면에서 한국어 글꼴, 경고판의 방향 문구와 자동 크기 조정 결과를 확인한다. 배치 실행은 화면 시각 검증이 아니다.
