# 90일차: 맵 진입 후 시작 포탑 선택

- 캐릭터와 맵을 선택한 뒤 게임 씬에 진입하며, 선택한 맵의 청크를 먼저 표시한다. 시작 포탑을 고르는 동안 실제 게임 상태와 시간은 정지한다.
- 기존 레벨업 카드와 시작 후보 검증·장착 처리를 재사용한다. 포탑을 선택하면 첫 몸통에 장착하고 전투를 시작한다.
- 게임 씬의 시작 포탑 선택에서는 이전 화면으로 돌아가는 버튼을 만들지 않고, 맵과 캐릭터를 바꾸는 방향키를 차단한다. 시작 전에 데이터가 잘못되면 출격 화면에 오류를 표시한다.
- 결과 화면의 재도전은 직전 캐릭터·맵을 유지하고 게임 씬의 시작 포탑 카드로 진입한다. 저장 실패 시 재도전 예약을 취소하고 결과 화면을 유지한다.
- 기획서 14번 탭의 화면 흐름과 12번 탭의 개발 기록을 갱신했다.

## Unity 비대화형 배치

- `AutomatedDay90MapStartingSelectionVerification`: 실제 분리 씬에서 폐허 맵과 중장형 선택, 맵 배경과 공용 포탑 카드, 시간 정지, 방향키·ESC와 뒤로 가기 차단, 포탑 장착과 동일 조건 재도전을 통과했다. 구현 전에는 준비 씬에서 다음 화면으로 이동해 실패했다.
- `AutomatedSceneSeparationVerification`, `AutomatedCharacterInputVerification`: 기존 분리 씬 전환과 단일 씬 시작 입력 회귀를 통과했다.
- `AutomatedFocusedRewardVerification`: 기존 48종 포탑 후보와 보상 추첨 회귀를 통과했다.
- `AutomatedRewardLayoutVerification`: 기존 보상 카드 그룹, 이미지 크기와 정예 보상 전환을 통과했다.
- `AutomatedDay75SeparateSceneTutorialVerification`: 독립 저장 공간에서 새 시작 포탑 선택 후 첫 플레이 안내와 전투 재개를 통과했다.
- Unity 시작 시 기존 검색 데이터베이스 `ArgumentOutOfRangeException`이 기록됐다. 원인은 별도 확인이 필요하다.

## 남은 사항

- 실제 게임 화면에서 맵 배경과 시작 카드의 가독성, 해상도별 위치, 첫 플레이 안내가 나타나는 순서를 확인한다. 비대화형 배치의 UI 상태 확인은 실제 화면 확인이 아니다.
