# 91일차: 시작 선택의 맵 배경 표시

- 분리 씬에서 맵에 진입한 뒤 시작 포탑을 선택할 때 공용 카드 패널의 배경 불투명도를 최대 65%로 조정한다. 수치는 패널에서 조정할 수 있는 시험값이며, 원래 배경이 더 투명하면 기존 값을 유지한다.
- 선택 종료나 패널 비활성화, 일반·정예 보상 화면 전환 시 원래 불투명도를 복원한다. 카드·글자와 기존 단일 씬 시작 화면은 변경하지 않았다.
- 기획서 12번과 14번 탭에 적용 방식과 실제 화면 확인 필요 사항을 기록했다.

## Unity 비대화형 배치

- `AutomatedDay90MapStartingSelectionVerification`: 실제 폐허 맵 진입, 시작 배경 불투명도, 일반·정예 보상 전환과 시작 화면 재진입 시 배경 조정, 포탑 선택 후 원래 배경 복원 및 재도전을 통과했다. 변경 전에는 시작 배경이 맵을 거의 가리는 상태로 실패했다.
- `AutomatedRewardLayoutVerification`, `AutomatedDay86WorldEventsPlayVerification`: 기존 보상 카드 구성과 황충·낙석 전투 회귀를 통과했다.
- Unity 시작 시 기존 검색 데이터베이스 `ArgumentOutOfRangeException`이 기록됐다. 원인은 별도 확인이 필요하다.

## 남은 사항

- 실제 화면에서 맵 배경의 밝기, 카드와 한글 글자의 대비, 다양한 해상도의 가독성을 확인한다. 비대화형 배치는 화면의 시각 품질을 확인하지 않는다.
