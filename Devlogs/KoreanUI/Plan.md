# 51-C 화면 한국어 정리 계획

---

## 범위

메인 메뉴·출격 준비·전투 HUD·설정·레벨업·합성·엘리트 보상·보스·결과에 실제로 표시되는 영문 문구와 맵 표시 이름을 한국어로 바꾼다. 물리 키를 식별하는 A·D·E 등 단일 문자는 유지하고 키 이름과 동작 설명은 한국어로 표시한다. 에셋 GUID와 저장용 ID, 프로그램 식별자는 변경하지 않는다.

---

## 검증

- [x] 실제 화면별 활성 글자 검사에서 기존 영문을 재현한다.
- [x] 화면 문구와 맵 표시 이름을 수정하고 기존 한글 지원 글꼴을 연결한다.
- [x] 메인 메뉴·설정·출격·전투·보상·합성·결과 화면과 기존 키 입력을 배치 검증한다.
- [x] 직접 시각 확인이 필요한 글자 크기·잘림·시스템 글꼴 한계를 기록한다.
