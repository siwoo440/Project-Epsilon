# 51-C 화면 한국어 정리

메인 메뉴, 출격 준비, 설정, 전투 HUD, 레벨업과 엘리트 보상, 합성, 보스, 결과 화면의 표시 문구를 한국어로 바꿨다. 맵과 적의 표시 이름도 정리했으며 데이터 ID와 에셋 GUID는 유지했다. A·D·E 같은 실제 키 문자는 유지하고 키 이름과 설명을 한국어로 표시한다.

씬에 저장된 기존 HUD 문구는 실행 시 한국어로 바꾸고 한글 글꼴을 연결한다. 이를 통해 작업 중 별도로 수정된 `Game.unity`는 덮어쓰지 않는다. 기존 설정 버튼과 속성 중복 표시는 51-B에서 제거했으며 설정은 메뉴와 일시정지 화면에서 연다.

---

## 실행한 검증

- Unity 6000.3.21f1 비대화형 격리 사본: 메뉴, 설정, 키 설정, 출격, 전투 HUD, 레벨업, 엘리트 보상, 합성, 일시정지, 결과의 활성 UI 글자와 글꼴 연결 검사 통과. 고정 영문이 두 글자 이상인 활성 문구를 검사했으며 실제 입력 키 한 글자는 허용했다.
- Unity 씬 이동, 저장 실패, 재도전, 설정, 캐릭터 입력, HUD, 보상 화면 배치, 합성 선택과 연속 레벨업 회귀 검사 통과. 캐릭터 입력 검사는 격리 프로필에 해금 조건을 구성한 뒤 실행했다.
- 기존 .NET `BodyHUD`와 `StartupCollision` 시험은 현재 시험용 Unity 대체 형식에 `RectTransform` 등이 없어 컴파일되지 않았다. Unity 실제 씬 기반 HUD 회귀는 별도로 통과했다.
- Unity 배치 시작 시 Unity Editor 검색 색인 초기화에서 `ArgumentOutOfRangeException`이 기록됐으나 위 Unity 시험들은 각각 종료 코드 0과 성공 결과를 반환했다.

## 직접 확인할 사항

Unity 에디터나 실행 빌드에서 각 해상도에 따른 한글 표시, 글자 잘림과 카드·우측 패널의 실제 모양을 확인해야 한다. 배치 검사는 글꼴 참조를 확인했지만 글리프의 렌더링 품질까지 확인하지 않았다. 시스템의 맑은 고딕 또는 대체 글꼴 설치 여부에 따라 표시가 달라질 수 있다.
