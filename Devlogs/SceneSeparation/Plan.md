# 화면별 씬 분리 계획

---

## 화면 흐름

기획서 14.1의 메인 메뉴 → 캐릭터 선택 → 맵·시작 포탑 선택 → 전투 → 결과 흐름을 실제 씬으로 분리한다. 일시정지·레벨업·합성·엘리트 보상은 진행 중인 전투 상태를 유지해야 하므로 전투 씬의 패널로 유지한다.

- `MainMenu`: 시작, 영구 성장, 설정과 종료.
- `Preparation`: 해금 상태를 반영한 캐릭터·맵·시작 포탑 선택.
- `Game`: 선택한 데이터로 실행하는 기존 전투와 전투 중 패널.
- `Results`: 실제 승패·성과·저장 상태, 재도전과 메뉴 복귀.

---

## 보존할 조건

선택한 에셋과 맵을 씬 경계에서 정확히 전달하고, 패배·승리 후 실제 성과 저장이 실패하면 기존 성과를 잃지 않는다. 직접 `Game` 씬을 여는 기존 개발·배치 흐름도 유지한다. 기존 씬의 GUID와 사용자가 별도로 변경한 파일은 보존한다. 현재 빌드 설정의 누락된 SampleScene 항목은 실제 빌드 흐름과 별도로 확인한다.

---

## 검증 순서

1. 기존 단일 씬과 별도 씬의 경계·선택 데이터·저장 경로를 재확인했다.
2. 실제 메뉴 → 준비 → 전투 → 결과 → 재도전·메뉴 복귀를 Unity 배치의 버튼 이벤트로 검증했다.
3. 해금된 선택 전달, 보상·충돌 우선순위, 저장 실패와 직접 Game 씬 실행 회귀를 검사했다.
4. 테스트 결과와 Unity에서 직접 확인할 화면 표시를 문서화한다.
