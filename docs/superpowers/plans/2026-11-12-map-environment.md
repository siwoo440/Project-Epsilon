# 세 맵 장애물과 환경 요소 구현 계획

**목표:** 기존 청크·이동·충돌·적 출현·경험치·체력 시스템에 33개 개별 스프라이트와 맵별 지형 및 상호작용을 연결한다.

**구조:** `PrototypeChunkMap`과 `PrototypeMapProfile`을 확장하고 기존 `PrototypeSpecialZone`, 충돌·체력·적 출현·보석 경로를 재사용한다. 청크 경계와 내부에 연결된 안전 통로를 예약하고, 장애물과 상호작용은 맵별 데이터의 임시값으로 조정한다. 사용자 원본 씬과 기존 미커밋 변경은 건드리지 않는다.

**검증:** Unity 6000.3.21f1 비대화형 배치에서 실제 스프라이트 가져오기, 여러 시드의 경로 및 시작 보호, 맵별 효과의 시간·무적·중복·보상, 적 상한 및 기존 전투 회귀를 확인한다. 표시 품질·몸통 20칸 조작감·장시간 부하는 별도로 구분한다.

- [x] 33개 PNG를 맵별로 가져오고 2D 스프라이트 설정과 알파를 확인한다.
- [ ] 청크 간 안전 통로와 시작 지점을 보호하는 무작위 패턴을 기존 청크에 연결했다. 몸통 20칸의 실제 회전과 탈출은 남았다.
- [ ] 충돌 범위를 그림과 분리하고 기존 장애물 피해·무적 및 투사체 엄폐를 배치 검증했다. 20칸 이탈과 실제 조작 시험은 남았다.
- [ ] 평원의 바람길·개미굴·꽃가루·회복·보석을 기존 이동·적·경험치·체력에 연결했다. 개미굴 주변 흙무더기 묶음 배치는 남았다.
- [ ] 폐허의 붕괴·방전·스위치·창고를 연결하고 주요 예고·틱·상한을 통제 시험했다. 몸통 통과 중 붕괴와 보스전의 실제 화면 확인은 남았다.
- [ ] 습지의 진흙·포자·다리·정화와 비충돌 안전 수로를 연결했다. 적 공격 감속과 수초 다리의 조합 시험은 남았다.
- [ ] 세 맵의 생성·재방문·장식 순서와 보스 설정을 배치 검증했다. 실제 장시간 보스전, 150마리 부하, 경고의 화면 가시성과 20칸 회전은 남았다.

## 판단과 한계

기획서의 30분 보스 표기는 사용자 확정 20분 규칙과 충돌하므로 기존 20분 전환을 유지한다. 청크 제거 후 재방문 재생성은 허용되지만 런당 일회 보상은 좌표와 요소 식별자로 별도 유지해야 한다. 시안의 시각 품질과 충돌체 세부 모양은 Unity 화면 확인 전 확정하지 않는다.
