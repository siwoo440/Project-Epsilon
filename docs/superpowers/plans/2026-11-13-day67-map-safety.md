# 67일차 맵 안전성과 개미굴 배치 계획

목표: 기존 청크 생성과 충돌 처리를 유지하면서 평원 개미굴 주변의 흙무더기를 연결하고 세 맵의 안전성을 추가 검증한다.

- [x] 장애물 없는 청크에서 개미굴 흙무더기 누락을 실패 시험으로 재현하고 통로와 입구 간격을 검증했다.
- [x] 기존 장애물 객체·충돌 규칙을 재사용해 안전한 후보에만 흙무더기를 생성한다. 플레이어와 다른 장애물의 안전 여유가 부족하면 생성하지 않는다.
- [x] 20칸 몸통에 대한 실제 Unity 통제 회전·이탈, 기존 충돌 회귀와 붕괴 잔해의 몸통 보호 여부를 확인했다. 직접 조작 검증은 남았다.
- [x] 세 맵의 실제 무작위 배치·지역·기존 충돌 회귀를 실행하고 장애물 충돌 사각형 면적의 표본을 기록했다. 보상은 기존 위험 요소 회귀에서 확인했다.

맵 수치와 보스 출현 시각은 확정하지 않는다. 이전에 수정된 씬과 솔루션은 보존한다.
