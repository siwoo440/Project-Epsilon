# 68일차 보스 설정 데이터 계획

목표: 세 맵의 기존 공통 시험 보스에 적용되는 공격력과 2단계·돌진·위험 구역·소환 임시값을 맵 데이터에서 조정하고 현재 기본 동작을 유지한다.

- [x] 실제 맵 보스 경로에서 맵별 공격 설정 부재를 실패 시험으로 재현했다.
- [x] 기존 `PrototypeMapProfile`에 장면의 임시값을 추가하고 `PrototypeBossEncounter.ApplyProfile`에 연결했다. 신규 보스 시스템은 만들지 않았다.
- [x] 세 맵의 실제 보스 사격·돌진·위험 구역·소환·2단계와 기존 20분 전환 회귀를 Unity 비대화형 배치로 검증했다.
- [x] 임시 보스별 패턴·설정과 확정되지 않은 수치, 고유 패턴의 남은 작업을 기록했다.

사용자가 확정한 20분 보스 전환과 기존 미커밋 씬·솔루션 변경을 유지한다.
