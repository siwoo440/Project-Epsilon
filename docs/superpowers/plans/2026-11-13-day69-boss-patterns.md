# 69일차 맵별 보스 패턴 계획

목표: 기존 공통 보스·투사체·경고·충돌·승패 경로를 재사용해 세 맵의 기획상 공격 차이를 검증한다.

- [ ] 폐허 보스의 양방향 투사체를 실제 선택 맵과 두 페이즈에서 실패 시험으로 재현한 뒤 구현한다.
- [ ] 폐허의 예고된 구획형 위험과 습지의 구분 가능한 포자 위험을 기존 위험 구역에 연결하고, 과도한 전역 봉쇄를 만들지 않는 시험용 크기를 유지한다.
- [ ] 습지 돌진은 예고 중 머리를 추적하고 실제 돌진 시작 시 방향을 고정한다. 예고선과 실제 방향이 일치하는지 시험한다.
- [ ] 폐허·습지 2단계의 지역 공격 간격을 시험용 데이터로 조정하고, 보스 처치·패배·절단·저항의 기존 경로를 회귀 검증한다.

양방향 탄 수는 각 방향에 기존 부채꼴 탄 수를 적용하는 임시안이다. 구획 형태, 포자 표시, 추적 방식과 2단계 간격 배율은 확정 밸런스가 아니며 실제 플레이 검증 전 가정으로 기록한다. 20분 전환과 기존 사용자 씬 변경을 유지한다.
