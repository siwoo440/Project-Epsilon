# 70일차 캐릭터·콘텐츠 점검

- 여섯 캐릭터의 실제 시작 능력치·패시브·포탑 후보와 해금을 격리된 Unity 배치로 점검한다.
- 실제 비용표에서 계산한 전체 성장 비용과 남은 비용을 구매·저장·초기화 시험으로 확인한다.
- 현재 실제 콘텐츠를 집계하고 완성되지 않은 일반 적·엘리트·맵별 보스의 작업을 명시한다.
- 기획서의 5분 쇠똥구리는 기존 일반 적 출현과 피해·경험치 경로를 재사용하고 별도 데이터로 조정한다.
- 쇠똥구리의 예고 돌진은 일반 피해만 적용하며 엘리트의 몸통 절단을 발생시키지 않는다.
- 자연 전투에서 확인된 범위 공격 중 연쇄 처치 예외를 수정하고 중첩 공격·대상 제거를 재현한다.
- 추가 적도 런 시작 시의 실제 전투 기록에 포함한다.

사용자가 확정한 보스 전환은 20분이다. 기획서의 20분·25분 신규 적과 30분 목표는 이 방향과 충돌하므로 시간을 임의로 변경하거나 완성으로 판정하지 않는다.
