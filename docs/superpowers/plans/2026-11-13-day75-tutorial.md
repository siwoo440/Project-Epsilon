# 첫 플레이 튜토리얼 구현 계획

> **실행:** 기존 Unity 화면과 입력을 재사용하고 각 동작을 배치에서 검증한다.

**목표:** 첫 전투 시작 시 기획서의 8단계 안내를 표시하고 건너뛰기와 다시 보기를 제공한다.

**구조:** 기존 `RunFrontendController`의 별도 화면 단계로 안내를 구성한다. 최초 자동 안내는 기존 게임 일시정지를 소유하며, 설정에서 다시 보는 경우 기존 화면과 정지 상태로 돌아간다. 완료 표식은 별도 PlayerPrefs 키에 저장한다.

**환경:** Unity 6000.3.21f1, 기존 UI와 Input System, 격리된 비대화형 배치.

**제약:** 20분 최종 보스, 즉시 합성, 실제 사용자 키 설정과 기존 사용자 씬을 유지한다. 튜토리얼 중 ESC는 안내를 닫고 설정에서 연 경우 기존 정지 상태를 유지한다.

- [x] 최초 진입, 단계 진행, 건너뛰기, 재생, 저장과 ESC의 실패 사례를 추가한다.
- [x] 기존 화면과 입력 우선순위에 튜토리얼을 연결한다.
- [x] 기존 시작·일시정지·설정·보상 흐름과 함께 배치로 확인한다.
- [x] 기획서 및 75일차 기록에 완료 범위와 남은 직접 화면 확인을 적는다.
