# 전투 효과음 연결 계획

**목표:** 공격·피격·몸통 손실·레벨업·합성·엘리트·보스 출현에 교체 가능한 임시 효과음을 연결한다.

**구조:** 기존 포탑 등급 이벤트, 체력·몸통·레벨 이벤트와 출현기의 알림을 재사용한다. 전투 관리자에 수명과 구독을 연결하고 별도 데이터 에셋에서 음량과 반복 간격을 조정한다. 기존 `AudioListener.volume` 설정을 유지한다.

**제약:** 음원은 임시 합성음으로 표시하며 최종 믹스로 취급하지 않는다. Unity 비대화형 배치에서는 소리의 실제 청취 품질을 확인할 수 없다.

- [x] 실제 이벤트·중복 제한 및 전체 음량 연결을 배치로 확인한다.
- [x] 임시 효과음과 조정 가능한 데이터 에셋을 만들고 실제 이벤트를 연결한다.
- [x] 비활성화 시 구독 해제와 기존 전투·씬 흐름을 확인한다.
- [x] 결과와 직접 청취가 필요한 항목을 개발 기록과 기획서에 구분한다.
- [ ] 씬 전환 후 오디오 재연결 및 일시정지 중 청감을 직접 플레이로 확인한다.
