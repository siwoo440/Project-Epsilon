# 87일차 낙석 경고 방향 구현 계획

목표: 낙석 예고 중 카메라가 이동해 착탄 지점이 화면 밖으로 나가더라도 플레이어가 경고판에서 방향을 확인한다.

- 기존 맵 위험 관리자와 경고판을 사용하고, 카메라 뷰포트 기준 네 방향과 대각선을 한국어로 표시한다. 착탄 지점이 화면에 다시 들어오면 기본 문구로 복귀한다.
- 실제 게임 씬을 사용하는 독립 배치 시험에서 화면 안팎, 여덟 방향, 일시정지와 황충 경고를 확인한다. 실패 재현 후 구현하고 86일차 회귀 시험을 실행한다.
- 위험의 위치·시간·피해와 장애물 배치 규칙을 변경하지 않는다. 화면의 실제 글꼴·겹침은 별도 시각 확인 대상으로 남긴다.
