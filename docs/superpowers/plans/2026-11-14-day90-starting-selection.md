# 90일차 맵 진입 후 시작 포탑 선택 구현 계획

- 출격 준비 화면에서 맵 선택을 마치면 선택 캐릭터와 맵을 보존해 게임 씬으로 이동한다. 게임은 시작 상태에서 정지하고 실제 선택 맵의 청크와 기존 레벨업 포탑 카드를 보여준다.
- 시작 포탑 선택 중 이전 화면 버튼과 맵·캐릭터 변경 키를 차단한다. 기존 후보 검증과 선택, 첫 몸통 장착과 실제 게임 시작을 재사용한다.
- 재도전은 직전 캐릭터와 맵으로 게임 씬에 들어가 시작 포탑 카드를 다시 표시한다. 저장 실패 시 결과 화면에 남긴다.
- 실제 씬 전환 배치에서 맵·캐릭터 보존, 맵 배경, 정지 상태, 뒤로 가기 차단, 선택 후 시작과 재도전을 확인한다. 기존 레벨업·튜토리얼 및 위험 요소 회귀를 확인한다.
